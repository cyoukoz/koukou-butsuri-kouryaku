組み合わせCC：落下するコイル＋コンデンサー＋ばね＋摩擦＋ドップラー＋開管の共鳴

問題：質量 0.10 kg のコイル（1辺 0.50 m の正方形、高さ 0.50 m）を、紙の裏向きの一様な磁場（B = 2.0 T）の上から静かに落とす。コイルにはコンデンサー（C = 0.10 F）がつながっている。コイルが磁場に入りきったあと、磁場の中を 1.5 m 落ちて、下のばね（k = 50 N/m）に当たる。ばねに当たっているあいだ、コイルには動摩擦力 0.50 N がはたらく。磁場は十分に広く、コイルがばねに当たるときも、はね返りの頂点でも、コイル全体が磁場の中にある。したがって、ばねに当たってからは、コイルを貫く磁束は変わらず、起電力は生じない。重力加速度は g = 10 m/s² とする。

コイルには振動数 f0 = 497 Hz の音源がのっている。観測者は地面にいて、落ちてくるコイルの音を聞く。地面のそばには、長さ L = 0.34 m の開管（両端が開いた管）が置かれている。音速は V = 340 m/s とする。

この問題は、単体モデルの組み合わせです。BQ「落下するコイル＋コンデンサー＋ばね＋摩擦」と BE「ドップラー＋開管の共鳴」を組み合わせた問題です。橋渡しになる量は「速さ」です。

単体モデルのページ：BQ 落下するコイル＋コンデンサー＋ばね＋摩擦 ｜ BE ドップラー＋開管の共鳴 ｜ AY 落下するコイル＋コンデンサー＋エネルギー ｜ Q18 ドップラー効果 ｜ Q14 定常波

  1. ① 磁場に入るとき：加速度は 5.0 m/s² のまま、入りきり 2.2 m/s
  2. ② 磁場の中とばね：5.9 m/s で当たり、縮み 0.27 m
  3. ③ ドップラーと共鳴：入りきりの音 500 Hz が管の f1 と一致する
  4. ④ 罠：音源の 497 Hz は共鳴しない
  5. ⑤ 変えたら：C・B・f0・L・閉管で共鳴は変わるか

① 磁場に入るとき：加速度は 5.0 m/s² のまま

コイルが磁場に入ると、起電力 ε = BLv が生じてコンデンサーに電気がたまる。電気がたまる速さは速さに比例するので、磁気の力は加速度に比例する。つまり、コンデンサーは「重さ」としてふるまう。余分な重さは m_extra = B²L²C = 2.0² × 0.50² × 0.10 = 0.10 kg になる。実効質量は m_eff = 0.10 + 0.10 = 0.20 kg になり、加速度は a = mg/m_eff = 1.0/0.20 = 5.0 m/s² で一定になる。重力 1.0 N のうち、磁気の力 0.50 N が上向きにはたらく。

入りきったときの速さは v1 = √(2ah) = √(2 × 5.0 × 0.50) ≈ 2.2 m/s、入るまでの時間は t1 = v1/a ≈ 0.45 s になる。起電力は ε = BLv = 2.0 × 0.50 × 2.2 ≈ 2.2 V、電気量は Q = CV ≈ 0.22 C、コンデンサーのエネルギーは U = ½CV² ≈ 0.25 J、運動エネルギーは KE = ½mv² ≈ 0.25 J になる。電流は I = CBL·a = 0.50 A になる。

コイルの右上の赤い点が音源（497 Hz）です。観測者は地面にいて、コイルが近づいてくる音を聞きます。近づくとき、聞こえる音は f′ = f0 × V/(V − v) で高くなります。入りきったときの速さは 2.2 m/s なので、音は f′ = 497 × 340/(340 − 2.2) ≈ 500 Hz（厳密には 500.3 Hz）になります。

② 磁場の中とばね：5.9 m/s で当たる、縮み 0.27 m、押し返し 5.4 m/s

入りきるまでに重力がした仕事は mgh = 1.0 × 0.50 = 0.50 J だ。このうち、半分の 0.25 J が運動エネルギーになり、残りの半分 0.25 J がコンデンサーにたまる。抵抗がある場合とちがって、熱にはならない。エネルギーはぴったり合う。

コイルが磁場に入りきると、コイルを貫く磁束は変わらなくなるので、起電力は 0 になり、磁気の力も 0 になる。だから、磁場の中では自由落下する。ばねに当たるときの速さは v2 = √(v1² + 2g × 1.5) = √(5.0 + 30) ≈ 5.9 m/s、磁場の中を落ちる時間は t2 = (5.9 − 2.2)/10 ≈ 0.37 s になる。運動エネルギーは ½mv2² = 1.75 J になる。落としはじめてからばねに当たるまで 0.82 s かかる。

ばねの角振動数は ω = √(k/m) = √(50/0.10) ≈ 22 rad/s になる。縮むとき、摩擦は上向きにはたらくので、つり合いのずれは x_eq1 = (mg − f)/k = (1.0 − 0.50)/50 = 0.010 m になる。最大の縮みは x_max = x_eq1 + √[x_eq1² + (v/ω)²] ≈ 0.27 m になる。ばねの力は k·x_max = 50 × 0.27 ≈ 14 N になる。圧縮にかかる時間は 0.072 s だ。

戻るとき、摩擦は下向きにはたらくので、つり合いのずれは x_eq2 = (mg + f)/k = 0.030 m に変わる。押し返しの速さは v_return = ω√[(x_max − x_eq2)² − x_eq2²] = 22 × √(0.245² − 0.030²) ≈ 5.4 m/s になる。戻りに 0.076 s かかる。摩擦熱は 0.27 J、押し返しの運動エネルギーは 1.5 J になる。はね返りの高さは 1.5 m になる。落としはじめてからはね返りの頂点まで 1.5 s かかる。

③ ドップラーと共鳴：入りきりの音 500 Hz が管の f1 と一致する

コイルは地面の観測者に近づきながら落ちるので、聞こえる音は f′ = f0 × V/(V − v) で高くなります。はじめは 497 Hz で、入りきったときは 500 Hz（厳密には 500.3 Hz）、ばねに当たるときは 506 Hz（厳密には 505.8 Hz）になります。ばねに当たって速さが 0 になると、音は 497 Hz に戻ります。押し返されて上がるときは、コイルは観測者から遠ざかるので、音は f′ = f0 × V/(V + v) で低くなり、はね返りの速さ 5.4 m/s のときは 489 Hz（厳密には 489.2 Hz）になります。はね返りの頂点では、また 497 Hz に戻ります。

地面のそばには、長さ L = 0.34 m の開管があります。開管の振動数は f_n = n·V/(2L) で、f1 = 340/(2 × 0.34) = 500 Hz、f2 = 1000 Hz、f3 = 1500 Hz です。入りきったときの音は、厳密には 500.3 Hz で、有効数字 3 けたでは 500 Hz となり、管の f1 と一致します。だから、磁場に入りきる瞬間だけ、管が共鳴します。着地の 506 Hz、はね返りの 489 Hz、折り返し点の 497 Hz は、管の振動数と一致しないので共鳴しません。

うなりも確かめられます。動かない 497 Hz の音源と比べると、着地の音とのうなりは 505.8 − 497 = 8.8 Hz で最大になります。

④ 罠：音源の 497 Hz は共鳴しない

罠が 3 つあります。1 つ目は、音源そのものの振動数 497 Hz は、管のどの振動数とも一致しないことです。管の振動数は 500 Hz、1000 Hz、1500 Hz で、497 Hz はどれとも合いません。コイルが止まっているときに聞こえる音は共鳴しません。

2 つ目は、共鳴するのは磁場に入りきる一瞬だけだということです。着地の音は一番速いので共鳴しそうに見えますが、506 Hz で、管の f1 = 500 Hz とは一致しません。速さが変われば、音の高さも変わるのです。

3 つ目は、はね返りの音を「着地と同じ 506 Hz」と思うことです。はね返りではコイルは観測者から遠ざかるので、音は低くなって 489 Hz になります。速さは 5.4 m/s で着地の 5.9 m/s より遅いことも、音が低くなる理由の 1 つです。

コンデンサーの罠も確かめておきましょう。抵抗がつながっていたら、コイルは終端速度 5.0 m/s で落ちます。そのときの音は f′ = 497 × 340/(340 − 5.0) ≈ 504 Hz になり、管の f1 = 500 Hz とは一致しません。自由落下なら、入りきりの速さは 3.2 m/s で、音は 502 Hz になり、やはり共鳴しません。

⑤ 変えたら：C・B・f0・L・閉管で共鳴は変わるか

C = 0.40 F なら、余分な重さは 0.40 kg、実効質量 0.50 kg、加速度 2.0 m/s² になる。入りきり 1.4 m/s、ばねに当たるとき 5.7 m/s になる。入りきりの音は f′ = 497 × 340/(340 − 1.4) ≈ 499 Hz になり、有効数字 3 けたでは 499 Hz で、管の f1 = 500 Hz とは一致しないので共鳴しません。着地の音も 505 Hz で合いません。最大の縮みは 0.26 m、押し返しは 5.2 m/s になります。

B = 1.0 T なら、余分な重さは 0.025 kg、実効質量 0.125 kg、加速度 8.0 m/s² になる。入りきり 2.8 m/s、ばねに当たるとき 6.2 m/s になる。入りきりの音は f′ = 497 × 340/(340 − 2.8) ≈ 501 Hz になり、管の f1 とは一致しないので共鳴しません。着地の音も 506 Hz で合いません。最大の縮みは 0.29 m、押し返しは 5.7 m/s になります。

管の長さを L = 0.68 m にすると、f1 = 250 Hz、f2 = 500 Hz になります。入りきりの音 500 Hz は f2 と一致するので、やはり共鳴します。管の長さを L = 0.17 m にすると、f1 = 1000 Hz になり、入りきりの音とは一致しないので共鳴しません。

音源の振動数を f0 = 440 Hz にすると、入りきりの音は 443 Hz、着地の音は 448 Hz になり、管の振動数とは一致しないので共鳴しません。閉管（片端が閉じた管）にすると、振動数は 250 Hz、750 Hz、1250 Hz になり、入りきりの音 500 Hz とは一致しないので共鳴しません。

ばね定数を k = 100 N/m にすると、最大の縮みは 0.19 m、押し返しは 5.6 m/s になります。入りきりの速さは変わらないので、入りきりの音は 500 Hz のままで、やはり共鳴します。はね返りの音は 489 Hz のままです。

まとめ

落下するコイル＋コンデンサー＋ばね＋摩擦（加速度 5.0 m/s²、入りきり 2.2 m/s、ばねに当たるとき 5.9 m/s、最大の縮み 0.27 m、押し返し 5.4 m/s、はね返り 1.5 m）に、ドップラー効果と開管の共鳴を組み合わせました。音は入りきり 500 Hz（厳密には 500.3 Hz）、着地 506 Hz（厳密には 505.8 Hz）、はね返り 489 Hz で、入りきりの一瞬だけが管の f1 = 500 Hz と一致して共鳴します。音源そのものの 497 Hz は共鳴しません。橋渡しになった量は「速さ」でした。
