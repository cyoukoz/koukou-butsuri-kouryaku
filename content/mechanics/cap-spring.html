組み合わせ問題J：コンデンサ＋ばね

問題：水平に置いた平行平板コンデンサがある。左の極板は固定、右の極板（質量 m = 0.50 kg、面積 S = 0.020 m²）はばね（ばね定数 k = 50 N/m）につながっている。電池で Q = 0.20 μC まで充電してから、電池を切り離す。はじめの極板間隔は d = 5.0 mm とする。真空の誘電率は ε₀ = 8.85×10⁻¹² F/m とする。(1) 極板間にはたらく静電引力と、つり合いのばねの伸びを求めよ。(2) 極板を少しずらして離すと、どんな振動をするか。周期を求めよ。(3) d を半分の 2.5 mm にすると、静電容量・電圧・静電エネルギーはどう変わるか。静電気力のはたらきと比べよ。(4) 電池につないだまま（V 一定）で d を半分にするとどうなるか。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v1.8、capSpring 型）が下の JSON データから計算して描く。横方向は 16 px/mm、力の矢印は 200 px/N で描く。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。ここでは、電池を切り離す前と後、そして「何が一定か」で切る。場面をつなぐのは、静電引力 F だ。

時間系（どの極板か）橋渡し量この場面で解くこと
充電して切り離すコンデンサ（Q 一定）静電引力 F ≈ 0.11 Nつり合いの伸び 2.3 mm（ステップ①）
つり合い位置のまわり極板＋ばね合力 = −k×（つり合いからのずれ）単振動、周期 約 0.63 s（ステップ②）
d を半分にするコンデンサ（Q 一定）電荷 QC は 2 倍、V は半分、U は半分（ステップ③）
V 一定の対比コンデンサ（V 一定）電圧 V引力は 4 倍になり、ばねでは支えきれない（ステップ④）

コンデンサの問題では、まず「何が一定か」を確かめる。電池につないだままなら電圧 V が一定、切り離したら電荷 Q が一定だ。静電引力は F = Q²/(2ε₀S) とも、F = ε₀SV²/(2d²) とも書ける。どちらで見るかで、d を変えたときのふるまいが変わる。

力を描く前の図はこれだけ。左の極板は固定、右の極板はばねで壁につながっている。ここから下へ、1本ずつ足していく。

次へ ↓ ①静電引力とつり合い

① 静電引力とつり合いの伸び

極板間にはたらく静電引力は、F = Q²/(2ε₀S) だ。Q = 0.20 μC、S = 0.020 m² を入れると、F = (0.20×10⁻⁶)²/(2 × 8.85×10⁻¹² × 0.020) ≈ 0.11 N。この力は、Q が一定なら、極板間隔 d によらない。

つり合いでは、ばねの力がこの引力と等しくなる。ばねの伸びを x₀ とすると、kx₀ = F だから、x₀ = 0.11/50 ≈ 0.0023 m = 2.3 mm。極板は、ばねの自然長の位置から 2.3 mm だけ左へ引かれたところでつり合う。


次へ ↓ ②つり合い位置のまわりの振動

② つり合い位置のまわりの振動

極板をつり合い位置から少しずらすとどうなるか。Q が一定なら、静電引力 F は d が変わっても 0.11 N のままだ。変わるのはばねの力だけだ。つり合い位置からのずれを u とすると、合力は −ku になる。つまり、つり合い位置のまわりの運動は、ふつうのばねの単振動だ。

角振動数は ω = √(k/m) = √(50/0.50) = 10 rad/s、周期は T = 2π/ω ≈ 0.63 s。振幅 A = 1.0 mm のとき、最大の速さは v_max = ωA = 0.010 m/s、最大の加速度は a_max = ω²A = 0.10 m/s² だ。静電引力は、つり合い位置をずらすだけで、振動の速さにはきかない。


次へ ↓ ③d を半分にすると

③ d を半分にすると

はじめの電気量を確かめよう。静電容量は C₀ = ε₀S/d = 8.85×10⁻¹² × 0.020 / 0.0050 = 35.4 pF。電圧は V₀ = Q/C₀ = 0.20×10⁻⁶ / (35.4×10⁻¹²) ≈ 5650 V。静電エネルギーは U₀ = Q²/(2C₀) ≈ 0.56 mJ だ。

d を半分の 2.5 mm にすると、C = ε₀S/d だから静電容量は 2 倍の 70.8 pF。Q が一定なので、V = Q/C は半分の 約 2820 V、U = Q²/(2C) も半分の 約 0.28 mJ になる。減ったエネルギー 0.28 mJ は、静電気力のはたらき F×Δd = 0.11 × 0.0025 ≈ 0.28 mJ と一致する。エネルギーのつじつまが合う。


次へ ↓ ④電池につないだままなら

④ 電池につないだままなら

こんどは、電池につないだまま（V 一定）で d を半分にしてみよう。V = 5650 V のままだと、静電引力は F = ε₀SV²/(2d²) で、d が半分になると 4 倍の 約 0.45 N になる。

そのときのばねの力はどうか。ばねの伸びは 2.3 mm + 2.5 mm = 4.8 mm だから、ばねの力は 50 × 0.0048 ≈ 0.24 N しかない。引く力 0.45 N がばねの力 0.24 N を上回るので、極板はさらに引き寄せられ、つり合いはない。V 一定では、引力が d で変わるので、ステップ②の単振動の議論はそのまま使えない。


次へ ↓ ⑤まとめ・罠の確認

⑤ まとめ・罠の確認

この問題の罠は2つある。1つめは、「V 一定」と「Q 一定」を混同することだ。V 一定では引力は 1/d² で変わるが、Q 一定では引力は一定だ。何が一定かで、d を変えたときのふるまいがまったく変わる。2つめは、静電引力とばねの力の向きを取り違えることだ。引力は極板を近づける向き、ばねの力は極板を遠ざける向きだ。つり合いは、その2つのバランスだ。

切り分けはこうだ。電池を切り離したら Q が一定になり、引力は定数になる。だから、つり合い位置をずらしたぶんだけ、ばねの単振動になる。橋渡し量は、静電引力 F ≈ 0.11 N だった。d を変えるときは、まず何が一定かを確認しよう。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 静電引力 F ≈ 0.11 N、つり合いの伸び 2.3 mm。(2) つり合い位置のまわりで単振動、ω = 10 rad/s、周期 約 0.63 s。(3) d を半分にすると C = 70.8 pF、V ≈ 2820 V、U ≈ 0.28 mJ。静電気力のはたらき 約 0.28 mJ と一致する。(4) V 一定では引力は約 0.45 N になり、ばねの力 0.24 N では支えきれない。もとになった単体モデル：コンデンサは 第9問：コンデンサ、単振動は 第11問：単振動・振り子 で確かめられる。
