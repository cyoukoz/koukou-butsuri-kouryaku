組み合わせ問題CF：気体＋ピストン＋ばね＋音速＋ドップラー＋開管の共鳴

この問題は、BR（気体＋ピストン＋ばね＋音速＋開管の共鳴）にドップラー効果を足したものだ。サイクルが回ると、気体の温度が変わる。温度が変わると、管の中の音速が変わる。音速が変わると、管の共鳴する振動数と、ピストンの音のドップラー効果の両方が変わる。温度が橋渡しをする問題だ。BV では A→B のはじめの音が共鳴し、BZ では B の音が共鳴した。この問題では、共鳴するのは C→A でピストンが下がるときの音だ。

シリンダーの中にヘリウム（単原子分子気体、γ = 5/3、モル質量 4.0×10⁻³ kg/mol）が入っている。シリンダーの断面積は 0.010 m²、ピストンの質量は 10 kg、ばね定数は 1000 N/m、ばねの自然長のときの気体の高さは 0.20 m、大気圧は 1.0×10⁵ Pa、重力加速度は g = 10 m/s² とする。気体の状態は A（h = 0.20 m、T = 300 K）から始まる。A→B：加熱してピストンを h = 0.30 m まで上げる。B→C：ピストンを固定して 300 K まで冷やす。C→A：等温圧縮して A に戻す。

ピストンの上には 1240 Hz の音源がのっている。A→B のあいだ、ピストンは 34 m/s で上がっている瞬間を考える。C→A のあいだ、ピストンは 34 m/s で下がっている瞬間を考える。観測者はピストンの真上にいて、音を聞いている。シリンダーのそばに、長さ 0.85 m の開管がある。音速は v = √(γRT/M) で求める。R = 8.31 J/(mol・K) とする。

（1）p–V 図とサイクルの仕事・効率を求めよ。（2）各状態での音速と管の振動数を求めよ。（3）ピストンが動くときの音の高さを求め、共鳴するかどうかを確かめよ。（4）罠と変えたら。

この問題のもとのモデル：組み合わせ問題BN・気体＋ピストン＋ばね＋カルノー効率、組み合わせ問題BI・気体＋音速＋開管の共鳴、組み合わせ問題BR・気体＋ピストン＋ばね＋音速＋開管の共鳴、組み合わせ問題BV・気体＋ピストン＋ばね＋音速＋ドップラー＋開管の共鳴、組み合わせ問題BZ・気体＋ピストン＋ばね＋カルノー＋ドップラー＋開管の共鳴、組み合わせ問題P・気体＋ピストン＋ばね＋サイクル、Q18・ドップラー効果、Q14・定常波

はじめに：この問題の切れ目

この問題の橋渡しの量は温度だ。状態 A・B・C の温度が管の中の音速を決め、音速が管の振動数と、ピストンの音のドップラー効果の両方を決める。温度が変われば、共鳴するかどうかも変わる。A→B では上がる音、B では熱い音、C→A では下がる音の 3 つを比べる。

次へ ↓

① サイクル：p–V 図と正味の仕事

まず、気体のサイクルを p–V 図で確認する。状態 A では、ピストンの力のつり合いから pA = 1.10×10⁵ Pa、VA = 2.0×10⁻³ m³ になる。状態 B では、h = 0.30 m でばねが 0.10 m 縮むので pB = 1.20×10⁵ Pa、VB = 3.0×10⁻³ m³ になる。状態 C では、温度が 300 K に戻るので pC = 0.733×10⁵ Pa になる。温度は TB = 491 K、TC = 300 K だ。

正味の仕事は、p–V 図に囲まれた面積で、Wnet = 25.8 J になる。加熱で吸収した熱量は Qin = 325 J で、効率は η = 25.8 / 325 = 7.9% になる。カルノー効率は 1 − 300/491 = 39% だ。

次へ ↓

② 音速と管の振動数：温度が決める

気体の中の音速は v = √(γRT/M) だ。温度 T が上がると、音速は √T に比例して大きくなる。

状態 A・C（300 K）では、v = √(1.667×8.31×300/0.004) = 1020 m/s になる。開管の振動数は fn = nv/(2L) で、L = 0.85 m だから f1 = 600 Hz、f2 = 1200 Hz、f3 = 1800 Hz になる。

状態 B（491 K）では、v = 1020×√(491/300) = 1300 m/s になる。開管の振動数は f1 = 767 Hz、f2 = 1500 Hz、f3 = 2300 Hz になる。

ピストンの上の音源の振動数は 1240 Hz だ。音源そのものは、管の振動数（A・C では 600・1200・1800 Hz、B では 767・1500・2300 Hz）と一致しない。音源が止まっているときは、共鳴は起こらない。

次へ ↓

③ ドップラーと共鳴：C では共鳴するが、A・B では共鳴しない

ピストンが観測者に近づくとき、聞こえる音は f′ = f0·V/(V − vs) になる。ピストンが観測者から遠ざかるときは f′ = f0·V/(V + vs) になる。音速 V は、そのときの気体の温度のものを使わなければならない。

A→B のはじめは、気体の温度が 300 K で音速は 1020 m/s だ。ピストンが 34 m/s で上がるとき、音は f′ = 1240×1020/(1020 − 34) = 1280 Hz になる。管の振動数は 600・1200・1800 Hz で、1280 Hz と一致するものはない。だから、A→B のはじめは共鳴しない。

A→B のおわり＝状態 B では、気体の温度が 491 K で音速は 1300 m/s になる。ピストンが同じ 34 m/s で上がっても、音は f′ = 1240×1300/(1300 − 34) = 1270 Hz になる。B の管の振動数は 767・1500・2300 Hz で、1270 Hz と一致するものはない。だから、B でも共鳴しない。一番熱い B でも、共鳴するとは限らない。

C→A では、気体の温度が 300 K に戻り、音速は 1020 m/s になる。ピストンが 34 m/s で下がるとき、音源は観測者から遠ざかるので、音は f′ = 1240×1020/(1020 + 34) = 1200 Hz になる。管の f2 も 1200 Hz なので、共鳴する。音速の厳密な値 1019 m/s で計算すると、ドップラー音は 1200 Hz（1199.97 Hz）、管の f2 は 1200 Hz（1199.17 Hz）だが、有効数字 3 けたではどちらも 1200 Hz になる。下がることで音が低くなり、管の f2 にのるのがこの問題のしかけだ。

音源が止まっているときは、音は 1240 Hz のままで、A でも B でも C でも管の振動数と合わない。

次へ ↓

④ 罠：温度を無視すると、共鳴の有無をまちがえる

罠 1：「共鳴は一番熱い B で起こるはず」——まちがい。B では音は 1270 Hz、管の振動数は 767・1500・2300 Hz で、一致するものはない。共鳴するのは、300 K に戻った C で下がるときの音だ。

罠 2：「C の音を 491 K の音速で計算する」——まちがい。491 K の音速 1300 m/s を使うと、f′ = 1240×1300/(1300 + 34) = 1210 Hz になって、f2 = 1200 Hz とは一致しない。C の音速は 300 K で計算して 1020 m/s、ドップラー音は 1200 Hz だ。音速は、その状態の温度で計算しなければならない。

罠 3：「音速は温度に比例する」——まちがい。v ∝ T だと思うと、491 K の音速は 1020×491/300 = 1670 m/s、f1 = 980 Hz、ドップラー音は 1270 Hz になる。正しくは v ∝ √T で、音速は 1300 m/s、f1 = 767 Hz、ドップラー音は 1270 Hz だ。ドップラー音は有効数字 3 けたではどちらも 1270 Hz に見えるが、管の振動数が 980 Hz と 767 Hz でまるでちがう。音速をまちがえると、共鳴するかどうかを正しく確かめられない。

罠 4：「閉管でもドップラー音が共鳴する」——まちがい。閉管の振動数は奇数倍だけで、300 K では 300・900・1500 Hz、491 K では 383・1150・1920 Hz になり、C の音 1200 Hz も A の音 1280 Hz も B の音 1270 Hz も一致しない。

次へ ↓

⑤ 変えたら：ばね・管・音源・速さを変えると？

k = 2000 N/m なら、TB = 532 K、音速は 1360 m/s、f1 = 800 Hz になる。B のドップラー音は 1270 Hz のままで、B ではやはり共鳴しない。hB = 0.40 m なら、TB = 709 K、音速は 1570 m/s、f1 = 920 Hz になる。B のドップラー音は 1270 Hz のままで、やはり共鳴しない。k や hB を変えても、C は 300 K のままだから、C の音は 1200 Hz のままで共鳴する。C の共鳴は、サイクルのばねや高さを変えても変わらない。

L = 1.70 m なら、300 K では f1 = 300 Hz、f4 = 1200 Hz になるので、C のドップラー音 1200 Hz は f4 と一致して共鳴する。491 K では f1 = 383 Hz、f3 = 1150 Hz、f4 = 1500 Hz になり、B の音 1270 Hz は合わない。A の音 1280 Hz も合わない。

音源を 1200 Hz の音さに変えると、止まっているときは A・C で f2 = 1200 Hz と一致して共鳴する。ところが動くと、A ではドップラー音は 1240 Hz、B では 1230 Hz、C では 1160 Hz になり、管の振動数とは合わない。止まっているときは共鳴する音さも、動くと共鳴しなくなる。

ピストンの速さを 17 m/s にすると、A の音は 1260 Hz、B の音も 1260 Hz、C の音は 1220 Hz になり、管とは合わない。ピストンが止まっているとき（vs = 0）は、音は 1240 Hz のままで、A でも B でも C でも共鳴しない。

まとめ：この問題でおさえること
