組み合わせCE：振り子＋弾性衝突＋ばね＋摩擦＋ドップラー＋開管の共鳴

問題

長さ 1.0 m の糸に質量 1.0 kg の玉をつけ、玉を 0.80 m の高さまで持ち上げて静かに放す。玉には音さ（f0 = 390 Hz）がついている。最下点で玉は静止した質量 1.0 kg のブロックと弾性衝突し、ブロックは水平な床の上のばね（k = 100 N/m）に当たる。ブロックと床の動摩擦係数は μ = 0.20 である。最下点の横には、開管（長さ 0.44 m）が置いてある。音速は 340 m/s、重力加速度は g = 10 m/s² とする。振り子の振れは大きいので、周期は単振動の近似ではなく、厳密な値を使う。

（1）振り子：最下点の速さと音、周期を求めよ。（2）弾性衝突とばね：ブロックの速さと最大の縮みを求めよ。（3）再衝突と共鳴。（4）罠と変えたら。

この問題は、組み合わせ問題BK：振り子＋弾性衝突＋ばね＋摩擦＋ドップラーと組み合わせ問題BE：ドップラー効果＋開管の共鳴を組み合わせた問題です。橋渡しになる量は「速さ」です。単体モデルは第11問・単振動、第18問・ドップラー効果、第14問・定在波です。

この問題の切れ目（スライス）

  1. ① 振り子：0.80 m から落ち、最下点で 4.0 m/s、音は 395 Hz
  2. ② 弾性衝突とばね：ブロック 4.0 m/s、最大の縮み 0.38 m
  3. ③ 再衝突と共鳴：玉は 0.65 m まで上がり、音 386 Hz が管の f1 と一致
  4. ④ 罠：音さの 390 Hz と最下点の 395 Hz は共鳴しない
  5. ⑤ 変えたら：L・f0・閉管・μ で共鳴は変わるか

① 振り子：最下点で 4.0 m/s、音は 395 Hz、周期は 2.2 s

cosθ = (L − h)/L = 0.20、θ ≈ 78.5° になる。最下点の速さは v = √(2gh) = √(2 × 10 × 0.80) = 4.0 m/s、運動エネルギーは 8.0 J になる。張力は T = mg + mv²/L = 10 + 16 = 26 N になる。

周期：振れが大きいので、単振動の周期 2π√(L/g) ≈ 2.0 s は使えない。厳密な周期は T = 4√(L/g)·K(sin(θ/2)) ≈ 2.2 s、最下点までの時間は T/4 ≈ 0.56 s になる。単振動の近似だと 0.50 s になり、約 13% ずれる。

ドップラー効果：玉が観測者に向かうので、f′ = f0·V/(V − v) になる。最下点では f′ = 390 × 340/(340 − 4.0) ≈ 395 Hz になる。放す位置から最下点まで、速さが増えるにつれて音は 390 Hz から 395 Hz へ上がる。0.25 s では約 393 Hz になる。うなりは、音さの 390 Hz との差で、最大で約 4.6 Hz になる。

次へ ↓

② 弾性衝突とばね：ブロック 4.0 m/s、最大の縮み 0.38 m

弾性衝突（等しい質量）：速さが入れ替わる。玉は止まり（音は 390 Hz に戻る）、ブロックが 4.0 m/s で動く。運動量 4.0 kg·m/s、運動エネルギー 8.0 J は保存する。

ばねの角振動数は ω = √(k/M) = 10 rad/s になる。縮むとき、摩擦は左向きにはたらくので、つり合いのずれは x_eq1 = −f/k = −0.020 m になる。最大の縮みは x_max = −0.020 + √[0.020² + (4.0/10)²] ≈ 0.38 m になる。ばねの力は k·x_max = 38 N になる。圧縮にかかる時間は 0.15 s だ。

戻るとき、摩擦は右向きにはたらくので、つり合いのずれは +0.020 m に変わる。押し返しの速さは v_return = ω√[(x_max − 0.020)² − 0.020²] ≈ 3.6 m/s になる。戻りに 0.16 s かかる。摩擦熱は 1.5 J、押し返しの運動エネルギーは 6.5 J になる。

次へ ↓

③ 再衝突と共鳴：玉は 0.65 m まで上がり、音は 386 Hz

再衝突：ブロックが戻って玉に当たる。等しい質量の弾性衝突で、ブロックは止まり、玉が 3.6 m/s をもらって左へ振り上がる。上がる高さは h2 = v²/2g = 3.6²/20 ≈ 0.65 m、振り上がりの角度は約 69°、上がる時間は約 0.55 s になる。玉は観測者から遠ざかるので、音は f′ = 390 × 340/(340 + 3.6) ≈ 386 Hz に聞こえる。頂点では 390 Hz に戻る。

共鳴：開管の振動数は f_n = n·v/(2L) = n × 340/(2 × 0.44) になる。f1 = 386 Hz、f2 = 773 Hz、f3 = 1159 Hz だ。再衝突の音 386 Hz は管の f1 と一致するので、共鳴する。厳密には、再衝突の音は 385.9 Hz、管の f1 は 386.4 Hz で、有効数字 3 けたではどちらも 386 Hz になる。音さの 390 Hz そのものは管の振動数ではないし、最下点の 395 Hz も合わない。共鳴するのは、再衝突で玉が上がりはじめる一瞬だけだ。

次へ ↓

④ 罠：音さの 390 Hz は共鳴しない、最速の最下点でも共鳴しない

罠：「音さの 390 Hz が共鳴する」——まちがい。管の振動数は 386・773・1159 Hz で、390 Hz はどれとも合わない。共鳴するのはドップラーで低くなった再衝突の音 386 Hz だけだ。

罠：「最速の最下点で共鳴する」——まちがい。最下点の音は 395 Hz で、管の f1 = 386 Hz とは合わない。速いところで共鳴するとは限らない。

罠：「くっつく衝突なら 392 Hz で共鳴する」——まちがい。くっつくと玉とブロックは 2.0 m/s でいっしょに動き、音は 392 Hz になる。386 Hz の f1 とは 6 Hz 離れていて、共鳴しない。ばねの最大の縮みも 0.25 m になる。

罠：「1段の計算で押し返し 4.0 m/s、上がる高さ 0.80 m」——まちがい。1段の計算だと押し返しは当たった速さと同じ 4.0 m/s、上がる高さは 0.80 m になるが、摩擦の向きの反転を入れると正しくは 3.6 m/s、0.65 m だ。摩擦なしだと 0.40 m になる。

次へ ↓

⑤ 変えたら：h・L・f0・閉管・μ で共鳴が変わる

h = 0.20 m なら、最下点で 2.0 m/s、音は 392 Hz になり、管の f1 = 386 Hz と合わず、共鳴しない。はね返りの音も 388 Hz で合わない。ばねの最大の縮みは 0.18 m、ばねの力 18 N、押し返し 1.6 m/s、上がる高さ 0.13 m になる（BK の数値）。

L = 0.88 m なら、f1 = 193 Hz、f2 = 386 Hz になる。再衝突の音 386 Hz は f2 と一致して、やはり共鳴する。

f0 = 440 Hz なら、最下点の音は 445 Hz、再衝突の音は 440 × 340/(340 + 3.6) ≈ 435 Hz になり、管の 386 Hz と合わず、共鳴しない。

閉管なら、f_n = (2n − 1)v/4L で、193・580・966 Hz になる。再衝突の 386 Hz はどれとも合わず、共鳴しない。

μ = 0.40 なら、最大の縮み 0.36 m、ばねの力 36 N、押し返し 3.2 m/s、摩擦熱 2.9 J、上がる高さ 0.51 m になる。再衝突の音は 386 Hz（厳密には 386.4 Hz）で、管の f1（厳密には 386.4 Hz）とやはり一致して、共鳴する。

振り子（h = 0.80 m、最下点 4.0 m/s、周期 2.2 s）に弾性衝突とばね＋摩擦（最大の縮み 0.38 m、押し返し 3.6 m/s）を組み合わせ、ドップラー効果と開管の共鳴を足しました。最下点の音は 395 Hz で管とは合わず、再衝突で玉が上がりはじめるときの音 386 Hz（厳密には 385.9 Hz、管の f1 は 386.4 Hz）が管の f1 と一致して共鳴します。音源そのものの 390 Hz は共鳴しません。橋渡しになった量は「速さ」でした。
