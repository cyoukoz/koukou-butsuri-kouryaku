組み合わせCV：円錐振り子＋ドップラー＋開管の共鳴（遠ざかる最大で共鳴）

質量 m = 1.0 kg の玉を、長さ L = 1.0 m の糸でつるし、半径 r = 0.60 m の水平な円を描くように回します。糸が鉛直方向となす角は θ = 37°（sin θ = 0.60、cos θ = 0.80）、支点から円の面までの鉛直距離は 0.80 m、重力加速度は g = 10 m/s² とします。玉には振動数 f0 = 402.5 Hz の音源がついていて、観測者は円の面と同じ高さで十分に遠いところにいます。音速は V = 340 m/s です。長さ L = 0.425 m の開管がそばに置いてあります。

この問題では、（1）円錐振り子の速さと周期を求め、（2）観測者に向かう半径方向の速さを調べ、（3）ドップラー効果で聞こえる音の高さと開管の共鳴を調べ、（4）まちがいやすい点と、条件を変えたらどうなるかを考えます。

土台になっている問題：AO・円錐振り子、BE・ドップラー＋開管の共鳴、第18問・ドップラー効果、第14問・定常波、第11問・単振動・振り子

解き方の地図

  • ① 円錐振り子：速さ 2.1 m/s、周期 1.78 s、張力 12.5 N
  • ② 半径方向の速さ：近づく最大 2.1 m/s、横の点では 0
  • ③ ドップラーと共鳴：遠ざかる最大の音 400 Hz が管の f1 と有効数字3けたで一致して共鳴する
  • ④ 罠：音源の 402.5 Hz・近づく最大の 405 Hz は共鳴しない
  • ⑤ 変えたら：L・f0・閉管・r・糸の長さで共鳴は変わるか

① 円錐振り子：速さと周期

玉にはたらく力は、重力 mg = 1.0 × 10 = 10 N（下向き）と糸の張力 T です。玉は水平面で等速円運動をしているので、鉛直方向の力はつり合い、水平方向の力が向心力になります。

張力の鉛直成分は T cos θ = mg なので、T = 10/0.80 = 12.5 N です。張力の水平成分は T sin θ = 12.5 × 0.60 = 7.5 N で、これが向心力 mv²/r になります。v² = 7.5 × 0.60/1.0 = 4.5 より、速さは v = 2.1 m/s（もっとくわしく計算すると 2.13 m/s）です。

角振動数は ω = v/r = 2.1/0.60 = 3.5 rad/s です。周期は T = 2π√(L cos θ/g) = 2π√(1.0 × 0.80/10) = 2π√0.080 = 1.78 s とも求められます。玉の高さは、支点から円の面まで 0.80 m なので、支点が地面から 2.0 m の高さなら玉は地面から 1.2 m の高さにあります。

② 半径方向の速さ

観測者は円の面と同じ高さで十分に遠いところにいるので、音の高さを決めるのは、玉の速さそのものではなく、観測者に向かう方向の速さ、つまり半径方向の速さです。玉が観測者にいちばん近い点を通るとき、玉は観測者に向かって真っすぐ進み、半径方向の速さは +2.1 m/s（近づく最大）になります。

玉が観測者からいちばん遠い点を通るとき、玉は観測者から真っすぐ遠ざかり、半径方向の速さは −2.1 m/s（遠ざかる最大）になります。玉が横の点を通るとき、玉は観測者から見て横向きに進むので、半径方向の速さは 0 になります。

時刻 t での半径方向の速さは、v·cos(ωt) = 2.1·cos(3.5t) m/s と書けます。玉の速さはつねに 2.1 m/s で一定なのに、半径方向の速さは +2.1 → 0 → −2.1 → 0 → +2.1 m/s と、1周のあいだに変わります。遠ざかる最大は 1周に 1回だけおとずれます。

次へ ↓

③ ドップラーと共鳴

音源が速さ v_r で観測者に近づくとき、聞こえる音は f′ = f0 × V/(V − v_r) です。遠ざかる最大のとき v_r = −2.13 m/s なので、f′ = 402.5 × 340/(340 + 2.13) = 399.99 Hz → 400 Hz です。近づく最大のとき v_r = 2.13 m/s なので、f′ = 402.5 × 340/(340 − 2.13) = 405.04 Hz → 405 Hz です。横の点では v_r = 0 なので、音は 402.5 Hz のままです。

1周のあいだの音の高さは、t = 0 s（近づく最大）で 405.04 Hz、t = 0.44 s（横の点）で 402.5 Hz、t = 0.89 s（遠ざかる最大）で 399.99 Hz、t = 1.33 s（横の点）で 402.5 Hz、t = 1.78 s（近づく最大）で 405.04 Hz と変わります。1周に 1回だけ、音は 400 Hz になります。

一方、開管の振動数は f1 = 340/(2 × 0.425) = 400 Hz、f2 = 800 Hz、f3 = 1200 Hz です。

遠ざかる最大の音 399.99 Hz は、管の f1 = 400.00 Hz と有効数字3けたで 400 Hz に一致します。厳密な値は 0.01 Hz だけちがうので「ちょうど一致」とは言えませんが、3けたの有効数字では同じ 400 Hz です。だから玉が観測者からいちばん遠ざかる瞬間、1周に 1回だけ管が共鳴して大きく鳴ります。

動かない 402.5 Hz の音源と比べると、近づく最大の音とのうなりは 405.04 − 402.5 = 2.5 Hz で最大になります（厳密には 2.54 Hz）。

④ 罠

罠1：「音源そのものの 402.5 Hz が共鳴する」——まちがい。402.5 Hz は管の f1 = 400 Hz と 2.5 Hz はなれているので共鳴しません。音源の音が共鳴するわけではありません。

罠2：「近づく最大の 405 Hz が共鳴する」——まちがい。405.04 Hz は f1 = 400 Hz と 5 Hz はなれているので共鳴しません。速さの大きさは遠ざかる最大と同じ 2.1 m/s なのに、音はちがいます。

罠3：「玉の速さは一定だから音も一定」——まちがい。玉の速さはつねに 2.1 m/s で一定ですが、音は 400 Hz から 405 Hz のあいだで変わります。音を変えるのは速さそのものではなく、観測者に向かう半径方向の速さだからです。

罠4：符号をまちがえて、近づくとき f′ = f0 × V/(V + v)、遠ざかるとき f′ = f0 × V/(V − v) を使うと、近づく最大の音が 402.5 × 340/(340 + 2.13) = 399.99 Hz、遠ざかる最大の音が 402.5 × 340/(340 − 2.13) = 405.04 Hz になって、共鳴する瞬間を「近づく最大」とまちがえます。近づくときは分母が V − v、遠ざかるときは V + v です。400 Hz という値じたいは出てきますが、出てくる瞬間がちがいます。

罠5：「平均の音が共鳴する」——まちがい。最大の音と最小の音の平均は (405.04 + 399.99)/2 = 402.52 Hz ≈ 402.5 Hz で、f1 = 400 Hz とは一致しないので共鳴しません。共鳴するのは、遠ざかる最大の瞬間の音だけです。

⑤ 変えたら

L = 0.85 m にすると、f1 = 340/(2 × 0.85) = 200 Hz、f2 = 400 Hz、f3 = 600 Hz、f4 = 800 Hz になります。遠ざかる最大の音 400 Hz は f2 と一致するので、やはり共鳴します。L = 0.17 m にすると f1 = 1000 Hz、f2 = 2000 Hz、f3 = 3000 Hz になり、遠ざかる最大の音とは一致しないので共鳴しません。

f0 = 440 Hz にすると、近づく最大の音は 440 × 340/(340 − 2.13) = 443 Hz、遠ざかる最大の音は 440 × 340/(340 + 2.13) = 437 Hz になり、管の振動数とは一致しないので共鳴しません。管を閉管（片端が閉じた管）にすると、振動数は 200 Hz、600 Hz、1000 Hz になり、遠ざかる最大の音 400 Hz とは一致しないので共鳴しません。

r = 0.80 m にすると（L = 1.0 m のまま）、sin θ = 0.80、cos θ = 0.60、tan θ = 4/3、θ ≈ 53° になります。速さは v = √(0.80 × 10 × 4/3) = 3.3 m/s、角振動数は ω = √(10/0.60) = 4.1 rad/s、周期は T = 1.54 s、張力は 10/0.60 = 16.7 N です。近づく最大の音は 402.5 × 340/(340 − 3.27) = 406 Hz、遠ざかる最大の音は 399 Hz になり、管の f1 = 400 Hz とは一致しないので共鳴しません。399 Hz は f1 と 1 Hz しかちがわないのに、一致しないので共鳴しません。

L = 0.50 m にすると（θ = 37° のまま）、半径は r = 0.50 × 0.60 = 0.30 m、速さは v = √(0.30 × 10 × 0.75) = 1.5 m/s、角振動数は ω = √(10/(0.50 × 0.80)) = 5.0 rad/s、周期は T = 1.26 s です。張力は 12.5 N のまま変わりません。近づく最大の音は 404 Hz、遠ざかる最大の音は 401 Hz になり、管の f1 = 400 Hz とは一致しないので共鳴しません。

円錐振り子（速さ 2.1 m/s、周期 1.78 s、張力 12.5 N）に、ドップラー効果と開管の共鳴を組み合わせました。玉の速さは一定ですが、観測者に向かう半径方向の速さは +2.1 → 0 → −2.1 → 0 m/s と変わります。遠ざかる最大の音は 399.99 Hz で、管の f1 = 400.00 Hz と有効数字3けたで 400 Hz に一致して、1周に 1回だけ共鳴します。音源の 402.5 Hz、近づく最大の 405 Hz、平均の音 402.5 Hz は共鳴しません。橋渡しになった量は「速度（半径方向）」でした。
