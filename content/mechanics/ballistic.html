組み合わせ問題E：弾道振り子（衝突＋振り子・エネルギー）

問題：糸の長さ L = 1.0 m で天井からつるされた質量 M = 1.99 kg のおもりに、質量 m = 0.010 kg の弾丸が水平に v0 = 400 m/s で撃ち込まれた。弾丸はおもりにめり込んで一緒に動き、おもりは振り上がった。g = 10 m/s² とする。(1) 衝突直後の速さ v′ を求めよ。(2) おもりが振り上がる最大の高さ h を求めよ。(3) 最大の振れ角 θ と、そのときの糸の張力を求めよ。最下点の張力も求めよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v1.6、ballistic 型）が下の JSON データから計算して描く。力の矢印は 2 px/N（重力 20 N は 40、張力 28 N は 56）。衝突直後の速さの矢印は 30 px/(m/s)（v′ = 2.0 m/s は 60）。弾丸の速度矢印だけは方向だけの固定長 60 px だ。v0 = 400 m/s は v′ の 200 倍で、同じ縮尺では描けないためだ。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。弾丸がめり込む前と後では、使える保存則が変わる。2つの場面をつなぐのは、衝突直後の速さだ。

時間系（どの物体か）橋渡し量この場面で解くこと
衝突前弾丸だけ（おもりは静止）—弾丸の運動量 p = 4.0 kg·m/s、運動エネルギー 800 J（ステップ①）
衝突の瞬間弾丸＋おもり（めり込む）速さ v′ = 2.0 m/s運動量保存だけで v′ を求める。エネルギーは保存されない（ステップ②）
衝突後（振り上がり）弾丸＋おもり（合計 2.00 kg）v′ = 2.0 m/s を初速度として使うエネルギー保存で最大の高さ h = 0.20 m、角度 θ ≈ 36.9°、張力を求める（ステップ③④）

保存則を境界をまたいで使わないこと。衝突の瞬間、運動エネルギーは 800 J から 4.0 J へ減る。衝突の前後でエネルギー保存を使ってはいけない。

力を描く前の図はこれだけ。左の弾丸が、右のおもりに向かって飛んでくる。ここから下へ、1本ずつ足していく。

次へ ↓ ①衝突前の運動量とエネルギー

① 衝突前の運動量とエネルギー

弾丸の速度矢印は方向だけの固定長だ（v0 = 400 m/s は v′ の 200 倍で、同じ縮尺では描けない）。おもりは静止しているので、速さは 0 だ。

弾丸の運動量は p = mv0 = 0.010 × 400 = 4.0 kg·m/s。運動エネルギーは (1/2)mv0² = (1/2) × 0.010 × 400² = 800 J。おもりは静止しているので、運動量も運動エネルギーも 0 だ。系全体の運動量は 4.0 kg·m/s、運動エネルギーは 800 J になる。


次へ ↓ ②衝突の瞬間（運動量保存だけ）

② 衝突の瞬間（運動量保存だけ）

弾丸がおもりにめり込む完全非弾性衝突では、運動量だけが保存される。衝突の前後で、弾丸＋おもりの運動量は変わらない。衝突直後の速さを v′ とすると、(m + M)v′ = mv0 だから、v′ = 4.0 / 2.00 = 2.0 m/s。弾丸の速さ 400 m/s から見ると、200 分の 1 になってしまった。

運動エネルギーはどうなったか。衝突直後は (1/2)(m + M)v′² = (1/2) × 2.00 × 2.0² = 4.0 J。衝突前の 800 J から 796 J も失われた。失われたエネルギーは、弾丸がおもりにめり込むときの変形や熱になった。ここでエネルギー保存を使ったら、v′ = 400 m/s のままになってしまう。衝突の瞬間をまたいでエネルギー保存を使ってはいけない。


次へ ↓ ③振り上がり（エネルギー保存）

③ 振り上がり（エネルギー保存）

張力は速さと関係するので、ここでは重力だけを描いている。張力はステップ④で描く。

衝突が終わったあとは、弾丸＋おもり（合計 2.00 kg）が速さ v′ = 2.0 m/s で振り上がる。糸の張力は運動の向きと直角なので仕事をしない。だから、振り上がりのあいだは力学的エネルギーが保存される。最下点の運動エネルギーが、最大の高さでの位置エネルギーになる。(1/2)(m + M)v′² = (m + M)gh から、h = v′² / (2g) = 2.0² / (2 × 10) = 0.20 m。質量は両辺で消えるので、h は v′ だけで決まる。


次へ ↓ ④最大の角度と張力

④ 最大の角度と張力

糸の長さ L = 1.0 m で、高さが h = 0.20 m だけ上がったとき、糸と鉛直線のなす角を θ とすると、cosθ = (L − h) / L = 0.80 / 1.0 = 0.80 だから、θ ≈ 36.9° になる（3:4:5 の直角三角形の角だ）。

張力は場所で変わる。最大の高さでは速さが 0 なので、糸に沿う向きのつり合いから T = (m + M)g cosθ = 20 × 0.80 = 16 N。いちばん下（衝突直後）では、張力が重力を上回って向心力になる。T − (m + M)g = (m + M)v′² / L だから、T = 20 + 2.00 × 2.0² / 1.0 = 28 N。重力 20 N より 8 N だけ大きい。張力は「つねに重力と等しい」のではない。

おもりの振動の周期は T = 2π√(L/g) ≈ 1.99 s。最下点から最大の高さまでにかかる時間は、その 4 分の 1 で 約 0.50 s だ。


次へ ↓ ⑤まとめ・罠の確認

⑤ まとめ・罠の確認

罠を数字で確かめよう。もし衝突の瞬間をまたいでエネルギー保存を（まちがって）使ったら、どうなるか。(1/2)mv0² = (m + M)gh から h = 800 / 20 = 40 m になってしまう。糸の長さは 1.0 m しかないのに、40 m も上がるはずがない。おかしいと気づけるのが、切り分けの力だ。

この問題の切り分けは3つだけだ。衝突前は弾丸の運動量とエネルギー、衝突の瞬間は運動量保存だけ、振り上がりはエネルギー保存だけ。橋渡し量は、衝突直後の速さ v′ = 2.0 m/s だった。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) v′ = 2.0 m/s。(2) h = 0.20 m。(3) θ ≈ 36.9°、最大の高さの張力は 16 N、最下点の張力は 28 N。周期は約 1.99 s、最下点から最大の高さまでは約 0.50 s。もとになった単体モデル：運動量と衝突は 第12問：運動量・衝突、振り子の周期と単振動は 第11問：単振動・振り子 で確かめられる。
