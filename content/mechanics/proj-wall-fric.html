組み合わせ問題AQ：斜方投射＋壁＋床の摩擦

質量 0.50 kg の玉を速さ 10 m/s、仰角 45° で打ち出す。5.0 m 先に壁がある。壁との反発係数は 0.80、床との動摩擦係数は 0.20 とする。重力加速度は g=10 m/s² とする。(1) 玉が壁に当たるまでの時間と高さを求めよ。(2) 壁ではね返ったあと、玉はどこに着地し、着地の速さはいくらか。(3) 着地のあと、玉は床を何 m すべって止まるか。止まるまでの時間と、摩擦で生じる熱を求めよ。(4) 着地の運動エネルギーが全部摩擦熱になるとするとどうなるか。(5) 反発係数を 1.0 にする、動摩擦係数を 0.40 にするとどうなるか。

はじめに：どう切り分けるか

打ち出し → 壁ではね返る → 着地 → 床をすべる → 罠 → 変えたら、の順に区切る。橋渡し量は「速さ」だ。

いつ何が起きるか橋渡し量どこで解くか
はじめ斜方投射壁まで 0.71 s、高さ 2.5 mステップ①
壁はね返るvx が −5.66 m/s になるステップ②
着地床をすべる着地の横の速さ 5.66 m/sステップ③
罠・変えたらエネルギー熱になるのは横の 8.0 J だけステップ④⑤

図：玉を投げると壁ではね返り、着地してから床をすべって止まる。組み合わせ問題AB のつづきだ。

ステップ① 打ち出しから壁まで

初速度を分解すると、vx = vy = 10×cos45° ≈ 7.07 m/s。壁までの時間は t = 5.0/7.07 ≈ 0.71 s。

そのときの高さは y = 7.07×0.71 − 5×0.71² = 5.0 − 2.5 = 2.5 m。鉛直の速さは vy = 7.07 − 10×0.71 = 0 になる。壁のところがちょうど最高点だ。

次へ ↓

ステップ② はね返って着地

壁はなめらかだから、鉛直方向の力はない。水平成分だけが反発係数 0.80 倍になって、vx′ = −0.80×7.07 ≈ −5.66 m/s になる。

壁のあとの運動エネルギーは ½×0.50×5.66² = 8.0 J。壁の前は ½×0.50×7.07² = 12.5 J だったので、壁で 4.5 J 失われた。

高さ 2.5 m から落ちる時間は t = √(2×2.5/10) ≈ 0.71 s。着地点は x = 5.0 − 5.66×0.71 = 1.0 m。着地のとき、縦の速さは vy = −10×0.71 ≈ −7.07 m/s で、着地の速さは √(5.66² + 7.07²) ≈ 9.1 m/s。

次へ ↓

ステップ③ 床をすべる

着地の瞬間、縦の速さ 7.07 m/s は床に吸収されて 0 になる。横の速さ 5.66 m/s だけが残って、玉は床をすべる。

摩擦力は f = μmg = 0.20×0.50×10 = 1.0 N。加速度は a = μg = 2.0 m/s² で、速さは直線で減っていく。

止まるまでの距離は s = 5.66²/(2×2.0) = 8.0 m。時間は t = 5.66/2.0 ≈ 2.8 s。摩擦で生じる熱は、横の運動エネルギーと等しく、½×0.50×5.66² = 8.0 J。止まるのは、出発点より 7.0 m 後ろ（x = −7.0 m）だ。

次へ ↓

ステップ④ 罠：着地の KE が全部熱になると思い込む

着地の速さは 9.1 m/s、運動エネルギーは ½×0.50×9.1² ≈ 20.5 J。でも、この 20.5 J が全部摩擦熱になるわけではない。

着地の運動エネルギーは、横の 8.0 J と縦の 12.5 J に分かれる。縦の 12.5 J は、着地の瞬間に床に吸収されて、音や変形になって消える。摩擦熱になるのは、横の 8.0 J だけだ。

エネルギーの行き先をたどると、はじめ 25 J → 壁で 4.5 J 失う → 着地で縦の 12.5 J 失う → 摩擦熱 8.0 J で、ちょうど 25 J になる。

次へ ↓

ステップ⑤ 変えたら

反発係数を 1.0（弾性）にすると、vx′ = −7.07 m/s で、着地はちょうど出発点 x = 0 になる。すべる距離は 7.07²/(2×2.0) = 12.5 m、時間は 3.5 s、熱は 12.5 J になる。

動摩擦係数を 0.40 にすると、加速度は 4.0 m/s² になり、止まるまでの距離は 5.66²/(2×4.0) = 4.0 m、時間は 1.4 s になる。熱は横の運動エネルギーと等しいので、8.0 J のままだ。

床がなめらか（μ=0）なら、摩擦力は 0 なので、玉は 5.66 m/s のままどこまでもすべり続ける。

5つのチェックをすべて入れると完了になります。

答え：壁まで 0.71 s、高さ 2.5 m、着地 x=1.0 m、着地の速さ≈9.1 m/s、すべる距離 8.0 m、止まるまで 2.8 s、摩擦熱 8.0 J。斜方投射は投げ上げの動きを見る、壁との衝突は組み合わせ問題AB：斜方投射＋壁との衝突、斜方投射のエネルギーは組み合わせ問題G：斜方投射＋エネルギーに戻って確認しよう。
