組み合わせ問題BR：気体＋ピストン＋ばね＋音速＋共鳴管

シリンダーの中にヘリウム（単原子分子気体、γ = 5/3、モル質量 4.0×10⁻³ kg/mol）が入っている。シリンダーの断面積は 0.010 m²、ピストンの質量は 10 kg、ばね定数は 1000 N/m、ばねの自然長のときの気体の高さは 0.20 m、大気圧は 1.0×10⁵ Pa、重力加速度は g = 10 m/s² とする。気体の状態は A（h = 0.20 m、T = 300 K）から始まる。A→B：加熱してピストンを h = 0.30 m まで上げる。B→C：ピストンを固定して 300 K まで冷やす。C→A：等温圧縮して A に戻す。シリンダーのそばに、長さ 0.85 m の開管と 1200 Hz の音さがある。音速は v = √(γRT/M) で求める。

(1) p–V 図とサイクルの仕事・効率を求めよ。(2) 各状態での音速と管の振動数を求めよ。(3) 1200 Hz の音さが共鳴する状態を求めよ。(4) 罠と変えたら。

はじめに：どう切り分けるか

場面考えること使うモデル
サイクル仕事と効率気体＋ピストン＋ばね
音速温度で音速が決まる気体の音速
共鳴管音さと管の振動数の一致開管の共鳴
効率カルノー効率との比べ熱効率

この問題の橋渡しの量は温度だ。状態 A・B・C の温度が管の中の音速を決め、音速が管の振動数を決める。温度が変われば、共鳴するかどうかも変わる。

次へ ↓

① p–V 図：A→B は W = 115 J、ΔU = 210 J、Q = 325 J

状態 A では、力のつり合いから p_A = p0 + mg/S = 1.0×10⁵ + 100/0.010 = 1.10×10⁵ Pa、体積は V_A = 0.010 × 0.20 = 2.0 L、温度は T_A = 300 K になる。状態 B では、ばねが 0.10 m 縮むので p_B = 1.10×10⁵ + 1000 × 0.10/0.010 = 1.20×10⁵ Pa、V_B = 3.0 L、温度は T_B = p_B·V_B/nR ≈ 491 K になる。

A→B では、仕事は W = 115 J（大気の仕事 100 J ＋ 重力の仕事 10 J ＋ ばねの仕事 5.0 J）、内部エネルギーの変化は ΔU = 210 J、吸った熱は Q = ΔU + W = 325 J になる。B→C では体積が変わらないので W = 0、ΔU = −210 J、Q = −210 J になり、圧力は p_C ≈ 0.733×10⁵ Pa になる。C→A では等温圧縮で W ≈ −89 J、ΔU = 0 になる。正味の仕事は 25.8 J、効率は 7.9%、カルノー効率は 39% になる（組み合わせ問題BN と同じサイクルだ）。

次へ ↓

② 音速と管の振動数：300 K で 1020 m/s・600 Hz、491 K で 1300 m/s・767 Hz

気体の中の音速は v = √(γRT/M) で決まる。300 K では v = √(5/3 × 8.31 × 300/0.004) ≈ 1020 m/s になる。491 K では、音速は √T に比例するので、v = 1020 × √(491/300) ≈ 1300 m/s になる。

開管の振動数は f_n = n·v/(2L) だ。300 K では f1 = 1020/(2 × 0.85) = 600 Hz、f2 = 1200 Hz、f3 = 1800 Hz になる。491 K では f1 = 767 Hz、f2 = 1500 Hz、f3 = 2300 Hz になる。温度が上がると、音速が上がって管の振動数も上がる。

次へ ↓

③ 共鳴：1200 Hz の音さは A・C の f2 と一致するが、B では合わない

1200 Hz の音さは、状態 A・C では管の f2 = 1200 Hz と一致するので、共鳴する。開管の f2 は、管の長さがちょうど 1 波長になる振動で、両端と中央が腹になる。

状態 B では、管の振動数は f1 = 767 Hz、f2 = 1500 Hz、f3 = 2300 Hz になり、1200 Hz と一致する振動数はない。だから、B では 1200 Hz の音さは共鳴しない。B で共鳴する音さは、f1 = 767 Hz の音さだ。767 Hz はちょうどの値で、770 Hz に丸めてはいけない（770 Hz の音さは、767 Hz の管とは 3 Hz ちがうので共鳴しない）。

次へ ↓

④ 罠：B の音速を 300 K のまま使うとまちがう／v ∝ T はまちがい

罠：「サイクルを通して共鳴は変わらない」——まちがい。B では温度が上がって音速が上がり、管の振動数が変わる。A・C で共鳴しても、B では共鳴しない。共鳴するかどうかは、そのときの温度で決まる。

罠：「B の音速を 300 K のまま計算する」——まちがい。300 K の音速 1020 m/s を使うと、f2 = 1200 Hz のままに見えて「B でも共鳴する」と思ってしまう。B の音速は 491 K で計算して 1300 m/s、f2 = 1500 Hz だ。音速は、その状態の温度で計算しなければならない。

罠：「音速は温度に比例する」——まちがい。v ∝ T だと思うと、491 K の音速は 1020 × 491/300 = 1670 m/s、f1 = 980 Hz になる。正しくは v ∝ √T で、音速は 1300 m/s、f1 = 767 Hz だ。

罠：「閉管でも 1200 Hz が共鳴する」——まちがい。閉管の振動数は奇数倍だけで、300 K では 300・900・1500 Hz、491 K では 383・1150・1920 Hz になり、1200 Hz と一致する振動数はない。

次へ ↓

⑤ 変えたら：k・L・閉管で共鳴が変わる

k = 2000 N/m なら、T_B = 532 K、音速は 1360 m/s、f1 = 800 Hz になる。1200 Hz の音さは共鳴しない。800 Hz の音さなら、f1 と一致して共鳴する。

h_B = 0.40 m なら、T_B = 709 K、音速は 1570 m/s、f1 = 920 Hz になる。1200 Hz の音さは共鳴しない。

L = 1.70 m なら、300 K では f1 = 300 Hz、f4 = 1200 Hz になるので、1200 Hz の音さは f4 と一致して共鳴する。491 K では f1 = 383 Hz、f3 = 1150 Hz、f4 = 1500 Hz になり、1200 Hz は合わない。

閉管（L = 0.85 m）では、300 K で 300・900・1500 Hz、491 K で 383・1150・1920 Hz になり、1200 Hz はどちらでも合わない。491 K の 1150 Hz は近いが、50 Hz ちがうので共鳴しない。

まとめ（答え）

(1) 正味の仕事 25.8 J、効率 7.9%、カルノー効率 39%。(2) 300 K：音速 1020 m/s、f1 = 600、f2 = 1200、f3 = 1800 Hz。491 K：音速 1300 m/s、f1 = 767、f2 = 1500、f3 = 2300 Hz。(3) 1200 Hz の音さは A・C の f2 と一致して共鳴するが、B では合わない。B で共鳴する音さは 767 Hz。(4) B の音速は 491 K で計算する。v ∝ √T。

もとになった単体モデル：気体＋ピストン＋ばねのサイクルは組み合わせ問題BN：気体＋ピストン＋ばね＋カルノー効率、気体の音速と開管の共鳴は組み合わせ問題BI：気体＋音速＋開管の共鳴、気体＋ピストン＋ばねは組み合わせ問題P：気体＋ピストン＋ばね＋サイクル、定常波は第14問：定常波で確かめられる。
