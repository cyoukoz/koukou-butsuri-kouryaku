第21問：ボーア模型・ド・ブロイ波長

問題：水素原子の電子のエネルギーは、En = −13.6/n² eV（n = 1, 2, 3, …）で表される。hc = 1240 eV·nm、プランク定数 h = 6.63×10−34 J·s、電子の質量 me = 9.11×10−31 kg、素電荷 e = 1.602×10−19 C とする。(1) n = 3 から n = 2 へ移るときに出る光のエネルギーと波長を求めよ。(2) n = 2 から n = 1 へ移るときに出る光のエネルギーと波長を求めよ。(3) n = 1 の電子の速さは約 2.19×10⁶ m/s である。電子のド・ブロイ波長を求め、軌道半径 a0 = 0.529×10⁻¹⁰ m の円周と比べよ。(4) 100 V で加速した電子の速さとド・ブロイ波長を求め、面間隔 d = 0.20 nm の結晶でブラッグ反射が起こる角度を求めよ。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。準位図の高さは 15 px/eV で、遷移の矢印の長さはエネルギー差×15 px になっている。ド・ブロイ波の図では、円周に沿う波を 1 波長分だけ描いている。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：エネルギーはとびとびで、しかも負の値

水素原子の電子は、どんなエネルギーでも取れるわけではない。取れるのは、En = −13.6/n² eV という、とびとびの値だけだ。n = 1 なら −13.6 eV、n = 2 なら −3.40 eV、n = 3 なら −1.51 eV になる。エネルギーが負なのは、電子が原子核に引きつけられて「束縛されている」からで、0 になるのは、電子が原子から逃げて自由になったとき（イオン化）だ。

図の横線が準位で、上が 0 eV（イオン化）、下に行くほどエネルギーが低い。電子が上の準位から下の準位へ移るとき、その差のエネルギーを光として出す。

次へ ↓ ①バルマー線

① バルマー線：3 → 2 は 1.89 eV、656 nm の赤い光

n = 3（−1.51 eV）から n = 2（−3.40 eV）へ移るとき、電子はエネルギーを失う。その差は、ΔE = (−1.51) − (−3.40) = 1.89 eV で、このエネルギーが光になる。光の波長は、λ = hc/ΔE = 1240 / 1.89 ≈ 656 nm だ。赤い光で、水素のスペクトルの Hα 線と呼ばれるものだ。

光のエネルギーは、波長が短いほど大きい。656 nm は可視光の赤い方のはしで、目に見える。図の矢印の長さは、1.89 eV を 15 px/eV で描いたものだ。


次へ ↓ ②ライマン線

② ライマン線：2 → 1 は 10.2 eV、122 nm の紫外線

n = 2（−3.40 eV）から n = 1（−13.6 eV）へ移るとき、エネルギーの差は、ΔE = (−3.40) − (−13.6) = 10.2 eV になる。波長は、λ = 1240 / 10.2 ≈ 122 nm だ。可視光（400〜700 nm）よりずっと短く、目には見えない紫外線になる。

下の準位へ落ちる幅が大きいほど、出る光のエネルギーは大きく、波長は短くなる。図の矢印が①よりずっと長いのは、そのためだ。n = 1 への遷移は、すべて紫外線になる（ライマン系列）。


次へ ↓ ③ド・ブロイ波長

③ ド・ブロイ波長：n = 1 の円周に、波が 1 個ちょうど入る

電子にも波の性質があり、波長は λ = h/mv で決まる。n = 1 の電子は、速さ v ≈ 2.19×10⁶ m/s で、λ = 6.63×10⁻³⁴ / (9.11×10⁻³¹ × 2.19×10⁶) ≈ 3.32×10⁻¹⁰ m ≈ 0.33 nm になる。

一方、n = 1 の軌道の円周は、2πa0 = 2π × 0.529×10⁻¹⁰ m ≈ 3.32×10⁻¹⁰ m ≈ 0.33 nm で、ド・ブロイ波長と一致する。つまり、n = 1 の軌道には、波がちょうど 1 個入っている。波が円周にぴったり入るから、波が自分自身と打ち消し合わずに、安定して存在できる。これが、とびとびの準位の理由だ。n = 2 なら波が 2 個、n = 3 なら 3 個入る。


次へ ↓ ④100 V の電子とブラッグ反射

④ 100 V の電子：λ ≈ 0.123 nm、ブラッグ反射角は約 17.9°

100 V で加速した電子は、運動エネルギーが 100 eV になる。速さは、v = √(2eV/m) = √(2 × 1.602×10⁻¹⁹ × 100 / 9.11×10⁻³¹) ≈ 5.93×10⁶ m/s だ。ド・ブロイ波長は、λ = h/mv ≈ 0.123 nm になる。光の波長（数百 nm）よりずっと短いが、結晶の原子の間隔（0.20 nm）と比べると、同じくらいの大きさだ。

だから、電子の波は結晶で回折・反射する。面間隔 d = 0.20 nm の結晶では、ブラッグの条件 2d・sinθ = λ から、sinθ = 0.123 / (2 × 0.20) ≈ 0.308 になり、θ ≈ 17.9° だ。電子が波であることの、直接の証拠になる実験だ。


次へ ↓ ⑤まとめ

⑤ まとめ：電子は「小さな惑星」ではない

ボーア模型の軌道の絵は、電子が原子核のまわりを小さな惑星のように回っている、という意味ではない。電子は、軌道の円周に波がちょうど整数個入る「定常波」として存在している。軌道の絵は、波の腹がどこにあるかを示す目安であって、電子の通り道の地図ではない。ここを古典的な絵のまま捉えると、量子力学に入ったときに間違う。

光のエネルギーは E = hν = hc/λ で、電子の波長は λ = h/mv だ。光も電子も、粒子と波の両方の性質をもつ。光の粒子性は 第15問：光電効果、光の波性は 第8問：ヤングの干渉 でも確かめられる。
