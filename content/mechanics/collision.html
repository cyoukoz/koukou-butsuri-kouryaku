第12問：運動量・衝突

問題：なめらかな水平面の上で、質量 m1 = 2.0 kg の物体 A が速さ v1 = 3.0 m/s で、静止している質量 m2 = 1.0 kg の物体 B に衝突する。(1) 弾性衝突のとき、衝突後の A と B の速さを求めよ。(2) A と B がくっついて一体となって動くとき（完全非弾性衝突）、衝突後の速さと、失われる運動エネルギーを求めよ。外力の力積はないものとする。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。速度の矢印の長さは速さに比例している（15 px/(m/s)）。速度の矢印は破線で、力ではない。

はじめに：衝突は「瞬間」で切り分ける

衝突は、ほんの一瞬の出来事だ。その瞬間だけを切り取ると、運動量保存が使える。衝突の前と後では、別の法則が使える。運動エネルギーは、弾性衝突のときだけ保存する。合体すると、エネルギーは失われる。まず衝突の前を見よう。

物体 A が速さ 3.0 m/s で右向きに進み、物体 B は止まっている。ここから下へ、1つずつ確かめていく。

次へ ↓ ①弾性衝突の速さ

① 弾性衝突：A は 1.0 m/s、B は 4.0 m/s

弾性衝突では、運動量保存とエネルギー保存の2つの式が使える。連立すると、v1' = (m1 − m2) / (m1 + m2) × v1 = (1/3) × 3.0 = 1.0 m/s、v2' = 2m1 / (m1 + m2) × v1 = (4/3) × 3.0 = 4.0 m/s。重い A が軽い B を押すと、A は遅くなって前に進み続け、B は A より速く飛び出す。図でも、B の速度の矢印のほうがずっと長い。


次へ ↓ ②弾性：運動量もエネルギーも保存

② 弾性：運動量もエネルギーも保存

運動量は、衝突前 2.0 × 3.0 = 6.0 kg·m/s、衝突後 2.0 × 1.0 + 1.0 × 4.0 = 6.0 kg·m/s で変わらない。運動エネルギーも、衝突前 ½ × 2.0 × 9.0 = 9.0 J、衝突後 ½ × 2.0 × 1.0 + ½ × 1.0 × 16 = 1.0 + 8.0 = 9.0 J で変わらない。弾性衝突とは、エネルギーが失われない衝突のことだ。


次へ ↓ ③合体：速さは 2.0 m/s

③ 合体：速さは 2.0 m/s、運動量は保存

2つの物体がくっつくと、1つの物体（質量 3.0 kg）になって動く。運動量保存だけを使えば、v' = m1v1 / (m1 + m2) = 6.0 / 3.0 = 2.0 m/s。運動量は、衝突前 6.0、衝突後 3.0 × 2.0 = 6.0 で変わらない。合体しても、運動量は保存する。ここまでは弾性衝突と同じだ。


次へ ↓ ④合体：エネルギーは失われる

④ 合体：エネルギーは 3.0 J 失われる

合体後の運動エネルギーは ½ × 3.0 × 4.0 = 6.0 J。衝突前の 9.0 J より 3.0 J 少ない。失われたエネルギーは、物体の変形や熱になった。だから、合体の問題でエネルギー保存を使ってはいけない。運動量は保存、エネルギーは保存しない。ここがこの問題の中心の罠だ。エネルギー保存を衝突の瞬間をまたいで使うと、答えが変わってしまう。


次へ ↓ ⑤まとめ

⑤ まとめ：保存則を使う場面を間違えない

衝突の問題は、まず「弾性か、合体か」を決める。運動量保存は、衝突の瞬間にはいつでも使える（外力の力積がなければ）。エネルギー保存は、弾性衝突のときだけ使える。合体のときは、エネルギーは失われる。速度の向きにも注意しよう。運動量はベクトルで、向きを逆にすると符号が変わる。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 弾性衝突では A が 1.0 m/s、B が 4.0 m/s。運動量 6.0 kg·m/s、エネルギー 9.0 J はどちらも保存する。(2) 合体では速さ 2.0 m/s、運動量は 6.0 のまま保存するが、エネルギーは 9.0 J から 6.0 J になり、3.0 J 失われる。衝突のあとにばねを押し縮める問題は 組み合わせ問題B：衝突＋ばね で扱う。橋渡し量は衝突直後の速さ v' = 2.0 m/s だ。
