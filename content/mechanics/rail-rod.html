第17問：レール＋棒の電磁誘導

問題：紙面の裏向きの一様な磁場 B = 0.40 T の中に、間隔 L = 0.50 m の2本のレールがある。レールの左端は抵抗 R = 2.0 Ω でつながっている。質量 m = 0.20 kg の導体棒がレールの上にまたがり、摩擦はない。棒を右向きに一定の力 F = 0.080 N で引き続ける。棒は静止から出発する。(1) 速さ v = 2.0 m/s のときの誘導起電力・電流・磁場の力・加速度を求めよ。(2) 終端速度と時定数を求めよ。(3) 終端速度のときのエネルギーの流れを説明せよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。速度の矢印は 15 px/(m/s)、電流は 100 px/A、力は 500 px/N だ。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：装置と因果の鎖

この問題は、1つの因果の鎖でできている。棒が動く → レールと棒で囲まれた部分の磁束が変わる → 誘導起電力が生まれる → 回路に電流が流れる → 電流が流れる棒は磁場から力を受ける → その力は棒の運動を妨げる向き。最後の「妨げる向き」が、終端速度を生む。磁場の向き（紙面の裏向き）と、棒を引く力の向きを、はじめに図で確かめておく。

棒が右へ動くと、レール・棒・抵抗で囲まれた長方形の面積が広がり、裏向きの磁束が増える。磁束そのものではなく、磁束の「変化」が起電力を生む。ここが第1の罠だ。磁束が大きくても、変わらなければ起電力は 0 だ。

次へ ↓ ①誘導起電力

① 誘導起電力 ε = BLv

速さ v = 2.0 m/s のとき、棒が 1 秒間に掃く面積は L × v = 0.50 × 2.0 = 1.0 m2。磁束の変化率は B × 1.0 = 0.40 Wb/s だから、誘導起電力は ε = BLv = 0.40 × 0.50 × 2.0 = 0.40 V。起電力は速さに比例する。速さが 2 倍になれば、起電力も 2 倍になる。v = 0 なら起電力は 0 だ。


次へ ↓ ②電流とその向き

② 電流 I = ε / R とその向き

回路の抵抗は R = 2.0 Ω だから、電流は I = ε / R = 0.40 / 2.0 = 0.20 A。向きは、レンツの法則で決まる。裏向きの磁束が増えているので、電流はそれを打ち消す向き、つまり表向きの磁場を作る向きに流れる。棒の中では、電流は上向きに流れる（棒の中の正の電荷は、v × B の力で上に押される）。下向きとすると、磁場の力の向きも逆になってしまう。


次へ ↓ ③磁場からの力

③ 磁場からの力 F = BIL（運動を妨げる向き）

電流が流れる棒は、磁場から力を受ける。大きさは Fmag = BIL = 0.40 × 0.20 × 0.50 = 0.040 N。向きは、電流が上向き・磁場が裏向きなので、左向き（棒の運動と逆向き）。外から引く力は右向き 0.080 N だから、合力は 0.080 − 0.040 = 0.040 N（右向き）。加速度は a = 合力 / m = 0.040 / 0.20 = 0.20 m/s²。磁場の力が運動を妨げる向きになるのは、レンツの法則の言い換えだ。もし磁場の力が右向きなら、棒はどんどん加速してエネルギーが無から生まれてしまう。


次へ ↓ ④終端速度

④ 終端速度 vt = 4.0 m/s、時定数 τ = 10 s

速くなると、起電力も電流も磁場の力も大きくなる。磁場の力が外力と等しくなったところで、合力は 0 になり、棒はそれ以上加速しない。その速さが終端速度だ。Fmag = BIL = B × (BLv/R) × L = (BL)2v / R だから、F = (BL)2vt / R より、vt = F・R / (BL)2 = 0.080 × 2.0 / (0.20)2 = 4.0 m/s。このとき ε = 0.80 V、I = 0.40 A、Fmag = 0.080 N = F で、加速度は 0 だ。速さは vt(1 − e−t/τ) の形で近づき、時定数は τ = mR / (BL)2 = 0.20 × 2.0 / 0.04 = 10 s。10 秒で終端速度の約 63% まで速くなる。


次へ ↓ ⑤エネルギー

⑤ エネルギー：外力の仕事はジュール熱になる

終端速度のとき、外力が 1 秒間にする仕事は F・vt = 0.080 × 4.0 = 0.32 W。抵抗で 1 秒間に発生するジュール熱は I2R = 0.402 × 2.0 = 0.32 W。ぴったり一致する。速さが変わらなくなったので、運動エネルギーは増えない。外力の仕事は、すべてジュール熱になっている。v = 2.0 m/s のときは、外力の仕事率は 0.16 W、ジュール熱は 0.080 W で、残りの 0.080 W が運動エネルギーの増加になっている（合力 × 速さ = 0.040 × 2.0 = 0.080 W）。

なお、外から引く力がなければ、棒は止まる。初速 4.0 m/s なら、止まるまでに進む距離は v0・τ = 40 m で、初めの運動エネルギー 1.6 J がすべてジュール熱になる。終端速度があるのは、外力が引き続けているからだ。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) v = 2.0 m/s のとき ε = 0.40 V、I = 0.20 A（棒の中は上向き）、磁場の力 0.040 N（左向き）、加速度 0.20 m/s²。(2) 終端速度 4.0 m/s、時定数 10 s。(3) 終端速度では外力の仕事率 0.32 W がすべてジュール熱になる。磁場の力の向きの考え方は 組み合わせC：荷電粒子＋円運動 のローレンツ力、力のつり合いは 第4問：三力のつり合い でも確かめられる。
