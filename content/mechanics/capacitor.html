第9問：コンデンサ

問題：面積 S = 0.020 m2 の平行板コンデンサーがある。極板間隔 d = 1.0 mm のとき、10 V の電池につないだ。電気容量 C、蓄えられる電荷 Q、静電エネルギー U を求めよ。次に、(a) 電池につないだまま極板間隔を 2.0 mm に広げたとき、(b) 電池を切り離してから極板間隔を 2.0 mm に広げたとき、それぞれ C・Q・V・U がどう変わるか求めよ。ε0 = 8.85×10−12 F/m とする。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。電場の矢印の長さは電場の強さに、引力の矢印の長さは極板間の引力に比例している。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：コンデンサの形を見る

コンデンサは、2 枚の金属の板をすき間をあけて向かい合わせたものだ。上の板にはプラスの電荷が、下の板にはマイナスの電荷がたまる。2 枚の板のあいだには、一様な電場ができる。

図はこれだけ。ここから下へ、1つずつ確かめていく。

次へ ↓ ①C・Q・U を求める

① C = εS / d、Q = CV、U = ½CV²

電気容量は C = ε0S / d = 8.85×10−12 × 0.020 / 1.0×10−3 = 177 pF。蓄えられる電荷は Q = CV = 177×10−12 × 10 = 1.77 nC。静電エネルギーは U = ½CV² = 0.5 × 177×10−12 × 100 = 8.85 nJ。電場の矢印は 3 本とも同じ長さで、極板のあいだで電場が一様なことが分かる。


次へ ↓ ②電場と引力

② 電場 E と極板間の引力

極板間の電場は E = V / d = 10 / 1.0×10−3 = 1.0×104 V/m。プラスとマイナスの板は引き合う。その引力は F = Q² / (2εS) = 8.85×10−6 N。引力は電荷の 2 乗に比例するから、Q が半分になると引力は 4 分の 1 になる。ここが次のステップの分かれ道だ。


次へ ↓ ③電池につないだまま

③ (a) 電池につないだまま d を 2 倍に（V 一定）

電池につないだままなら、電圧 V は 10 V のまま変わらない。d が 2 倍になると C = εS / d は半分で 88.5 pF、Q = CV は半分で 0.885 nC、U = ½CV² は半分で 4.43 nJ になる。電場は E = V / d で半分の 5.0×103 V/m になるから、図の電場の矢印も半分の長さだ。引力は Q が半分なので 4 分の 1 の 2.21×10−6 N になる。減った分の電荷は電池に戻り、減った分のエネルギーは電池が受け取る。


次へ ↓ ④電池を切り離してから

④ (b) 電池を切り離してから d を 2 倍に（Q 一定）

電池を切り離すと、電荷はどこへも逃げられない。だから Q は 1.77 nC のまま変わらない。d が 2 倍になると C は半分で 88.5 pF だが、V = Q / C は 2 倍の 20 V になる。U = ½QV は 2 倍の 17.7 nJ になる。エネルギーが増えた分は、引力に逆らって板を引いた外の人がした仕事だ。電場は E = Q / (εS) で、Q が変わらないから 1.0×104 V/m のままで、図の電場の矢印の長さも変わらない。引力も Q が変わらないから 8.85×10−6 N のままだ。


次へ ↓ ⑤まとめ

⑤ まとめ：何が一定かがすべてを決める

2 つの場合の違いは、最初に何が一定かを決めることだけだ。電池につないだままなら V が一定、切り離したら Q が一定。そこから C = εS / d、Q = CV、U = ½CV² を使えば、あとは全部決まる。d を変えたあとに Q = CV を使うとき、Q と V のどちらが一定だったかを間違えると、答えが逆になる。まず「V 一定か、Q 一定か」を言ってから計算しよう。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：はじめは C = 177 pF、Q = 1.77 nC、U = 8.85 nJ。(a) 電池接続のまま d を 2 倍にすると C = 88.5 pF、Q = 0.885 nC、U = 4.43 nJ。(b) 切り離してから d を 2 倍にすると C = 88.5 pF、V = 20 V、U = 17.7 nJ。コンデンサのエネルギーの行き来は 組み合わせD：LC回路＋単振動 でも使う。
