第24問：クーロンの法則・電場

問題：点電荷 Q = +2.0 μC がある。クーロン定数は k = 9.0×10⁹ N·m²/C² とする。(1) Q から r = 0.10 m と r = 0.20 m の位置の電場の大きさを求めよ。(2) q = +1.0 μC の試験電荷を r = 0.10 m の位置に置いたとき、試験電荷にかかる電気力を求めよ。試験電荷を 2 倍にすると、電場と電気力はどうなるか。(3) +2.0 μC と −2.0 μC の電荷を 0.30 m 離して置いたとき、2つの電荷の中点での電場の大きさと電位を求めよ。(4) 2つの電荷のまわりの電気力線を描け。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。電場の矢印は 30 px/(1.0×10⁶ N/C)（1.8×10⁶ N/C → 54 px）で、距離は 700 px/m（0.10 m → 70 px）になっている。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：電場は「1 C あたりの力」

電荷があると、そのまわりの空間は「電場」という状態になる。電場 E とは、その場所に +1 C の電荷を置いたときに、どれだけの力がかかるか、という量だ。だから、電場が分かれば、どんな電荷 q を置いても、かかる力は F = qE で求まる。電場は、置く電荷がなくても、そこに決まっている。

正の電荷のまわりでは、電場は電荷から外向きになる。遠くなるほど電場は弱くなり、矢印は短くなる。どれだけ短くなるかが、次のステップだ。

次へ ↓ ①1個の電荷の電場

① 1個の電荷の電場：0.10 m で 1.8×10⁶ N/C、0.20 m で 4.5×10⁵ N/C

点電荷の電場は、E = kQ/r² で決まる。r = 0.10 m では、E = 9.0×10⁹ × 2.0×10⁻⁶ / 0.10² = 1.8×10⁶ N/C だ。r = 0.20 m では、E = 9.0×10⁹ × 2.0×10⁻⁶ / 0.20² = 4.5×10⁵ N/C になる。

距離が 2 倍になると、電場は 1/4 になる。1/r² だからだ。図の矢印の長さも、54 px から 13.5 px へ、ちょうど 1/4 になっている。重力の逆2乗則と同じ形だが、重力と違って、電荷には正と負があり、力は引くことも押すこともある。


次へ ↓ ②電場と電気力

② 電場と電気力：F = 1.8 N。q を 2 倍にしても E は変わらない

r = 0.10 m の位置に、q = +1.0 μC の試験電荷を置く。かかる電気力は、F = qE = 1.0×10⁻⁶ × 1.8×10⁶ = 1.8 N だ。図の青い矢印が F、赤い破線の矢印が E だ。F は 36 px、E は 54 px で、縮尺が違うことに注意しよう（F は 20 px/N、E は 30 px/(1.0×10⁶ N/C)）。

ここが罠だ。試験電荷を q = +2.0 μC に 2 倍にすると、電気力は F = 2.0×10⁻⁶ × 1.8×10⁶ = 3.6 N に 2 倍になる。でも、電場 E は 1.8×10⁶ N/C のまま変わらない。電場は、置く電荷 q がなくても決まっている量で、q を変えても変わらないからだ。E = F/q と書くと、F が 2 倍になっても q も 2 倍になるので、E は変わらない。電場と電気力を混同してはいけない。


次へ ↓ ③中点の電場と電位

③ 中点：電場は 1.6×10⁶ N/C、電位は 0 V

+2.0 μC と −2.0 μC を 0.30 m 離して置く。中点は、どちらの電荷からも 0.15 m の位置だ。+ の電荷がつくる電場は、E1 = 9.0×10⁹ × 2.0×10⁻⁶ / 0.15² = 8.0×10⁵ N/C で、向きは + から離れる方向（右向き）だ。− の電荷がつくる電場は、E2 = 9.0×10⁹ × 2.0×10⁻⁶ / 0.15² = 8.0×10⁵ N/C で、向きは − に近づく方向（これも右向き）だ。

電場はベクトルなので、向きを考えて足す。2つとも右向きだから、合計は E = 8.0×10⁵ + 8.0×10⁵ = 1.6×10⁶ N/C（右向き）になる。図では E1 と E2 を少し上下にずらして描いているが、実際は中点の同じ場所で、同じ向きに重なっている。

一方、電位はスカラーで、向きはなく、ただ足し算する。V1 = kQ/r = 9.0×10⁹ × 2.0×10⁻⁶ / 0.15 = +1.2×10⁵ V、V2 = 9.0×10⁹ × (−2.0×10⁻⁶) / 0.15 = −1.2×10⁵ V だから、合計は V = 0 V になる。電位は 0 でも、電場は 0 ではない。電位が 0 だから電場も 0 だ、と間違えてはいけない。電位は「高さ」で、電場は「坂の傾き」だ。平らな場所でも、傾きが 0 とは限らない。


次へ ↓ ④電気力線

④ 電気力線：＋から出て、−に入る

電気力線は、電場の向きを目に見えるようにしたものだ。線は + の電荷から出て、− の電荷に入る。線の接線の方向が、その場所の電場の向きだ。線が密なところほど、電場が強い。

この図では、+ と − のあいだに線が集まっている。③で求めたとおり、中点の電場は 1.6×10⁶ N/C と強い。線は交わることはなく、+ から出た線は必ず − に入るか、遠くへ逃げる。電気力線は、電場の「地図」だ。


次へ ↓ ⑤まとめ

⑤ まとめ：E は q なし、F = qE、電位はスカラー

点電荷の電場は E = kQ/r² で、距離が 2 倍になると 1/4 になる。電場 E は置く電荷 q がなくても決まる量で、電気力は F = qE だ。q を変えても E は変わらない。2つの電荷があるとき、電場はベクトルとして向きつきで足し、電位はスカラーとしてただ足す。電位が 0 でも、電場が 0 とは限らない。

電荷がためるエネルギーや、電荷の動きの考え方は、第9問：コンデンサや第19問：直流回路でも確かめられる。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 0.10 m で 1.8×10⁶ N/C、0.20 m で 4.5×10⁵ N/C。(2) F = 1.8 N。q を 2 倍にすると F は 3.6 N になるが、E は 1.8×10⁶ N/C のまま。(3) 中点の電場は 1.6×10⁶ N/C（右向き）、電位は 0 V。(4) 電気力線は＋から出て−に入る。電荷のエネルギーは 第9問：コンデンサ、電流は 第19問：直流回路でも確かめられる。
