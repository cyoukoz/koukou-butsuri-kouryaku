組み合わせ問題CP：気体＋カルノーサイクル＋ドップラー＋開管の共鳴（D で f1 と共鳴）

この問題は、カルノーサイクルにドップラー効果と開管の共鳴を足したものだ。サイクルが回ると、気体の温度が変わる。温度が変わると、管の中の音速が変わる。音速が変わると、管の共鳴する振動数と、ピストンの音のドップラー効果の両方が変わる。温度と速さが橋渡しをする問題だ。BV では A、BZ では B の f1、CF では C、CL では B の f2 が共鳴したが、この問題では D の f1 が共鳴する。

シリンダーの中にヘリウム（単原子分子気体、γ = 5/3、モル質量 4.0×10⁻³ kg/mol）が入っている。ピストンの上には 1031 Hz の音源がのっている。観測者はピストンの真上にいて、音を聞いている。気体を次のカルノーサイクルで動かす。A（V = 2.0 L、T = 600 K）→B（V = 6.0 L、T = 600 K）：等温膨張。B→C（V = 17.0 L、T = 300 K）：断熱膨張。C→D（V = 5.7 L、T = 300 K）：等温圧縮。D→A：断熱圧縮。nR = 1.0 J/K、R = 8.31 J/(mol・K) とする。シリンダーのそばに、長さ 0.50 m の開管がある。音速は v = √(γRT/M) で求める。各状態の直後のピストンの速さは、A では 34 m/s（上がる）、B では 28 m/s（上がる）、C では 42 m/s（下がる）、D では 12 m/s（下がる）とする。ドップラー効果はその瞬間の速さで決まるので、サイクル全体にかかる時間は関係ない。

（1）p–V 図とサイクルの仕事・効率を求め、カルノー効率と比べよ。（2）各状態での音速と管の振動数を求めよ。（3）ピストンが動くときの音の高さを求め、共鳴するかどうかを確かめよ。（4）罠と変えたら。

この問題のもとのモデル：組み合わせ問題BN・気体＋ピストン＋ばね＋カルノー効率、組み合わせ問題BI・気体＋音速＋開管の共鳴、組み合わせ問題BR・気体＋ピストン＋ばね＋音速＋開管の共鳴、組み合わせ問題BV・気体＋ピストン＋ばね＋音速＋ドップラー＋開管の共鳴、組み合わせ問題BZ・気体＋ピストン＋ばね＋カルノー効率＋ドップラー＋開管の共鳴、組み合わせ問題CL・気体＋ピストン＋ばね＋カルノー効率＋ドップラー＋開管の共鳴（B で f2 と共鳴）、組み合わせ問題P・気体＋ピストン＋ばね＋サイクル、Q18・ドップラー効果、Q14・定常波

はじめに：この問題の切れ目

切れ目何をするか使うモデル

この問題の橋渡しの量は温度と速さだ。状態 A・B・C・D の温度が管の中の音速を決め、音速とピストンの速さがドップラー音を決める。温度が変われば、共鳴するかどうかも変わる。BV では A で、BZ では B の f1 で、CF では C で、CL では B の f2 で共鳴したが、この問題では D の f1 が共鳴する。D は最も冷たい点で、断熱圧縮 D→A の始点であり、ピストンの速さも最も小さい。

次へ ↓

① サイクル：p–V 図と正味の仕事、カルノー効率との比べ

まず、気体のサイクルを p–V 図で確認する。状態 A では、pA = nRT/V = 1.0×600/2.0×10⁻³ = 3.00×10⁵ Pa、VA = 2.0 L になる。状態 B では、T = 600 K のまま V = 6.0 L になるので pB = 1.00×10⁵ Pa になる。B→C は断熱膨張で、VC = 6.0×(600/300)3/2 = 17.0 L、TC = 300 K、pC = 0.18×10⁵ Pa になる。C→D は等温圧縮で、VD = 2.0×(600/300)3/2 = 5.7 L、TD = 300 K、pD = 0.53×10⁵ Pa になる。D→A は断熱圧縮で、A に戻る。

A→B では、仕事は WAB = nRT ln(VB/VA) = nRT ln 3 ≈ 660 J、内部エネルギーの変化は ΔUAB = 0、吸熱は QAB = 660 J になる。B→C では QBC = 0、WBC = 450 J、ΔUBC = −450 J になる。C→D では、WCD = nRT ln(VD/VC) = nRT ln(1/3) ≈ −330 J、ΔUCD = 0、QCD = −330 J になる。D→A では QDA = 0、WDA = −450 J、ΔUDA = 450 J になる。

正味の仕事は、p–V 図に囲まれた面積で、Wnet = 660 + 450 − 330 − 450 = 330 J になる。効率は η = Wnet/QAB = 330/660 = 50% になる。同じ 300 K と 600 K のあいだのカルノー効率は ηC = 1 − 300/600 = 50% で、このサイクルはカルノーサイクルだから、効率はカルノー効率と等しい。厳密な値は、WAB = 659.17 J、WCD = −329.58 J、正味の仕事は 329.59 J、吸熱は 659.17 J だ。

次へ ↓

② 音速と管の振動数：温度が決める

気体の中の音速は v = √(γRT/M) だ。温度 T が上がると、音速は √T に比例して大きくなる。

状態 C・D（300 K）では、v = √(1.667×8.31×300/0.004) = 1020 m/s になる。開管の振動数は fn = nv/(2L) で、L = 0.50 m だから f1 = 1019 Hz、f2 = 2038 Hz、f3 = 3058 Hz になる。厳密な値は、音速が 1019.19 m/s、f1 = 1019.19 Hz、f2 = 2038.38 Hz、f3 = 3057.57 Hz だ。

状態 A・B（600 K）では、v = 1020×√(600/300) = 1440 m/s になる。開管の振動数は f1 = 1441 Hz、f2 = 2883 Hz、f3 = 4324 Hz になる。厳密な値は、音速が 1441.35 m/s、f1 = 1441.35 Hz、f2 = 2882.71 Hz、f3 = 4324.06 Hz だ。

ピストンの上の音源の振動数は 1031 Hz だ。音源そのものは、管の振動数（300 K では 1019・2038・3058 Hz、600 K では 1441・2883・4324 Hz）と一致しない。音源が止まっているときは、共鳴は起こらない。

次へ ↓

③ ドップラーと共鳴：A・B・C では共鳴しないが、D の f1 で共鳴する

ピストンが観測者に近づくとき、聞こえる音は f′ = f0·V/(V − vs) になる。遠ざかるときは f′ = f0·V/(V + vs) になる。音速 V は、そのときの気体の温度のものを使わなければならない。

A の直後（600 K、34 m/s で上がる）では、音は f′ = 1031×1441/(1441 − 34) = 1056 Hz になる。厳密な値は 1055.91 Hz で、管の振動数（1441・2883・4324 Hz）とは一致しない。だから、A では共鳴しない。

B の直後（600 K、28 m/s で上がる）では、音は f′ = 1031×1441/(1441 − 28) = 1051 Hz になる。厳密な値は 1051.43 Hz で、管の振動数とは一致しない。だから、B でも共鳴しない。

C の直後（300 K、42 m/s で下がる）では、音は遠ざかるので f′ = 1031×1019/(1019 + 42) = 990 Hz になる。厳密な値は 990.19 Hz で、管の振動数（1019・2038・3058 Hz）とは一致しない。だから、C でも共鳴しない。

D の直後（300 K、12 m/s で下がる）では、音は f′ = 1031×1019/(1019 + 12) = 1019 Hz になる。厳密な値は 1019.00 Hz で、管の f1（厳密には 1019.19 Hz）と有効数字 3 けたで一致する。どちらも 1019 Hz になるので、D では共鳴する。同じ音源でも、温度と速さが変わると、共鳴するかどうかが変わる。D は最も冷たい点で、ピストンの速さも最も小さい。速さが小さいからこそ、ドップラー音は音源の 1031 Hz に近く、管の f1 = 1019 Hz と一致する。

音源が止まっているときは、音は 1031 Hz のままで、どの状態でも管の振動数と合わない。

次へ ↓

④ 罠：温度を無視すると、共鳴を見逃す

罠 1：「音源そのものが共鳴する」——まちがい。1031 Hz は管の振動数（300 K では 1019・2038・3058 Hz、600 K では 1441・2883・4324 Hz）と一致しない。f1 = 1019 Hz とは 12 Hz しか離れていないが、有効数字 3 けたでは 1031 Hz と 1019 Hz で、一致しない。

罠 2：「いちばん速いピストンの音が共鳴する」——まちがい。ピストンが最も速いのは C の 42 m/s だが、その音は 990 Hz で、管の f1 = 1019 Hz とは 29 Hz 離れていて合わない。速いからといって共鳴するとは限らない。いちばん高い音も A の 1056 Hz で、管とは合わない。

罠 3：「D の音を 600 K の音速で計算する」——まちがい。600 K の音速 1441 m/s を使うと、f′ = 1031×1441/(1441 + 12) = 1022 Hz になり、管の f1（1019 Hz）と有効数字 3 けたで一致しないので「D では共鳴しない」と思ってしまう。D の音速は 300 K で計算して 1019 m/s、ドップラー音は 1019 Hz で、管の f1 = 1019 Hz と一致して共鳴する。音速は、その状態の温度で計算しなければならない。

罠 4：「音速は温度に比例する」——まちがい。v ∝ T だと思うと、600 K の音速は 1019×600/300 = 2040 m/s、f1 = 2038 Hz、ドップラー音は 1031×2038/(2038 − 34) = 1048 Hz になる。正しくは v ∝ √T で、音速は 1441 m/s、f1 = 1441 Hz、ドップラー音は 1056 Hz だ。

罠 5：「断熱過程の仕事は熱だ」——まちがい。B→C の仕事 450 J と D→A の仕事 −450 J は、熱の出入りではない。断熱過程では Q = 0 で、仕事は内部エネルギーの変化になる。B→C では ΔU = −450 J、D→A では ΔU = +450 J だ。吸った熱は A→B の 660 J だけで、効率の分母は 660 J だ。

次へ ↓

⑤ 変えたら：管・音源・気体・体積比を変えると？

L = 1.00 m なら、300 K では f1 = 510 Hz、f2 = 1019 Hz になるので、D の音 1019 Hz は f2 と一致して、やはり共鳴する。600 K では f1 = 721 Hz、f2 = 1441 Hz になり、A の音 1056 Hz は合わない。L = 0.25 m なら、300 K では f1 = 2038 Hz、600 K では f1 = 2883 Hz になり、どの音も合わないので、共鳴しない。

音源を 900 Hz の音さに変えると、A ではドップラー音は 922 Hz、B では 918 Hz、C では 864 Hz、D では 890 Hz になり、管の振動数とは合わない。止まっているときは 900 Hz のままで、どの状態でも共鳴しない。

気体を水素（2 原子分子気体、γ = 7/5、モル質量 2.0×10⁻³ kg/mol）に変えると、音速は 300 K で 1320 m/s、600 K で 1870 m/s になる。管の振動数は 300 K で f1 = 1321 Hz、600 K で f1 = 1868 Hz になる。ドップラー音は A で 1050 Hz、B で 1047 Hz、C で 999 Hz、D で 1022 Hz になり、管の振動数とは合わないので、共鳴しない。断熱膨張の体積は VC = 33.9 L、VD = 11.3 L と大きくなるが、正味の仕事は 330 J、効率は 50% のままで変わらない。カルノーサイクルだから、γ を変えても効率は変わらない。

等温膨張の体積比を 2 倍（VB = 4.0 L）にすると、WAB = 416 J、正味の仕事は 208 J になるが、効率は 50% のまま変わらない。温度とピストンの速さは変わらないので、D の音 1019 Hz は f1 と一致して、やはり共鳴する。

閉管の振動数は奇数倍だけで、300 K では 510・1529・2548 Hz、600 K では 721・2162・3603 Hz になり、どのドップラー音とも一致しない。

まとめへ ↓

まとめ：この問題でおさえること

（1）正味の仕事 330 J、効率 50%、カルノー効率 50%。（2）300 K：音速 1020 m/s、f1 = 1019、f2 = 2038、f3 = 3058 Hz。600 K：音速 1440 m/s、f1 = 1441、f2 = 2883、f3 = 4324 Hz。（3）A の 1056 Hz・B の 1051 Hz・C の 990 Hz は管とは合わないが、D の 1019 Hz は管の f1 と一致して共鳴する。（4）ドップラー音の音速は、その状態の温度で計算する。v ∝ √T。断熱過程の仕事は熱ではない。
