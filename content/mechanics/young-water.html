組み合わせ問題H：干渉＋屈折

問題：波長 λ = 600 nm の赤い光でヤングの干渉実験をする。二重スリットの間隔は d = 0.20 mm、スリットからスクリーンまでの距離は L = 1.0 m とする。まず空気中で実験し、次に装置全体を水（屈折率 n = 4/3）の中に入れて同じ実験をする。(1) 空気中の縞間隔と、3番目の明線の位置を求めよ。(2) 水の中では光の波長はどう変わるか。(3) 水の中の縞間隔と、3番目の明線の位置を求めよ。(4) 青い光（空気中で 450 nm）なら、空気中と水中で縞間隔はどうなるか。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v1.7、youngWater 型）が下の JSON データから計算して描く。光路図は第8問と同じ配置（スリット x=120、スクリーン x=330、中心 y=150、縞 10 px/mm）。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。ここでは、光が水に入る前と後で切る。屈折で変わるのは波長だけ、干渉の式の形は同じだ。場面をつなぐのは、波長 λ′ だ。

時間系（どの光か）橋渡し量この場面で解くこと
空気中赤い光（λ = 600 nm）—縞間隔 Δx = 3.0 mm、3番目の明線 9.0 mm（ステップ①）
水に入る瞬間同じ光（振動数は変わらない）波長 λ′ = 450 nm速さが c/n になり、波長が λ/n になる（ステップ②）
水中赤い光（λ′ = 450 nm）波長 λ′ = 450 nm縞間隔 Δx′ = 2.25 mm、3番目の明線 6.75 mm（ステップ③）
青い光の場合青い光（空気中で 450 nm）波長（空気中で 450 nm）空気中で 2.25 mm、水中で 1.69 mm（ステップ④）

光が媒質に入ると、速さが変わる。でも振動数は、光源が決めるものだから変わらない。速さ = 波長 × 振動数 だから、速さが 1/n 倍になれば、波長も 1/n 倍になる。干渉の式 Δx = λL/d は、λ を λ′ に置き換えるだけで、そのまま使える。

力を描く前の図はこれだけ。二重スリットを通った光が、スクリーンに縞を作る。ここから下へ、1本ずつ足していく。

次へ ↓ ①空気中の縞間隔

① 空気中の縞間隔と3番目の明線

ヤングの干渉では、明るい縞の条件は「光路差 = nλ」、縞間隔は Δx = λL/d だ。λ = 600 nm、L = 1.0 m、d = 0.20 mm を入れると、Δx = 600×10⁻⁹ × 1.0 / (0.20×10⁻³) = 3.0×10⁻³ m = 3.0 mm。3番目の明線の位置は、x = 3Δx = 9.0 mm だ。

図の2本の光路は、3番目の明線へ向かう光だ。下の光路のほうが、ちょうど 3λ だけ長い。光路差が波長の整数倍のところで、波が強め合って明るくなる。


次へ ↓ ②水に入ると波長が変わる

② 水に入ると波長が変わる

光の速さは、真空中では c = 3.0×10⁸ m/s だが、水の中では c/n = 3.0×10⁸ / (4/3) = 2.25×10⁸ m/s になる。振動数は光源が決めるものだから、空気中のまま f = c/λ = 3.0×10⁸ / (600×10⁻⁹) = 5.0×10¹⁴ Hz で変わらない。

速さ = 波長 × 振動数 だから、水中の波長は λ′ = v/f = 2.25×10⁸ / (5.0×10¹⁴) = 450×10⁻⁹ m = 450 nm。つまり λ′ = λ/n だ。波の山と山の間隔が、4/3 分の 1 に縮む。


次へ ↓ ③水中の縞間隔

③ 水中の縞間隔と3番目の明線

干渉の式の形は、水の中でも同じだ。λ を λ′ に置き換えるだけ。Δx′ = λ′L/d = 450×10⁻⁹ × 1.0 / (0.20×10⁻³) = 2.25×10⁻³ m = 2.25 mm。3番目の明線の位置は、x′ = 3Δx′ = 6.75 mm だ。

図のとおり、水の中では縞が狭くなる。縞間隔は 3.0 mm から 2.25 mm へ、ちょうど 3/4 倍（= 1/n 倍）になった。光路差の条件「光路差 = nλ′」も、λ′ で数え直せば同じ形だ。


次へ ↓ ④青い光ならどうなるか

④ 青い光ならどうなるか

青い光は、空気中での波長が 450 nm と短い。空気中の縞間隔は Δx = 450×10⁻⁹ × 1.0 / (0.20×10⁻³) = 2.25 mm。赤い光の 3.0 mm より、もともと狭い。

水に入れると、さらに λ′ = 450 / (4/3) = 337.5 nm になる。縞間隔は Δx′ = 337.5×10⁻⁹ × 1.0 / (0.20×10⁻³) ≈ 1.69 mm。波長が短い光ほど、縞は狭い。色と媒質の両方が、縞間隔を決める。


次へ ↓ ⑤まとめ・罠の確認

⑤ まとめ・罠の確認

この問題の罠は2つある。1つめは、「水に入ると振動数が変わる」と思い込むことだ。振動数は光源が決めるもので、媒質が変わっても変わらない。変わるのは速さと波長だ。2つめは、「屈折角が変わる話」と混同することだ。屈折の式 n₁sinθ₁ = n₂sinθ₂ は光の進む向きの話で、こちらは波長そのものが変わる話だ。どちらも「n が出てくる」が、別のはたらきだ。

切り分けはこうだ。光が媒質に入る前と後で切り、橋渡し量は波長 λ′ = λ/n。干渉の式は λ を λ′ に置き換えるだけで、そのまま使える。縞間隔は 1/n 倍になる。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 空気中の縞間隔 Δx = 3.0 mm、3番目の明線 9.0 mm。(2) 水中の波長 λ′ = 450 nm（振動数 5.0×10¹⁴ Hz は変わらない）。(3) 水中の縞間隔 Δx′ = 2.25 mm、3番目の明線 6.75 mm。(4) 青い光は空気中で 2.25 mm、水中で約 1.69 mm。もとになった単体モデル：干渉の式は 第8問：ヤングの干渉、屈折の考え方は 第20問：屈折・レンズ で確かめられる。
