組み合わせ問題AS：光電効果＋コンデンサ＋磁場円運動

光電管の陰極（仕事関数 2.0 eV）に波長 400 nm の光を当てる。陰極と陽極のあいだにはコンデンサ（電気容量 10 nF）がつながっており、飛び出した電子は陽極に集まってコンデンサを充電する。光電流は 1.0 μA で一定である。電子の電気量 e = 1.60×10−19 C、電子の質量 m = 9.11×10−31 kg、hc = 1240 eV·nm とする。(1) 飛び出す電子の最大の運動エネルギーと、最も速い電子の速さを求めよ。(2) コンデンサの電圧が阻止電圧に達したとき、たまった電荷、電子の数、静電エネルギー、充電にかかる時間を求めよ。(3) 飛び出した電子を磁束密度 1.0 mT の一様な磁場に入れる。電子の円運動の半径、周期、振動数を求めよ。

はじめに：どう切り分けるか

光電効果 → コンデンサの充電 → 磁場の円運動 → 罠 → 変えたら、の順に区切る。橋渡し量は「電子の運動エネルギー（速さ）」だ。

ステップ① 光電効果：飛び出す電子の最大の運動エネルギー

光子のエネルギーは E = hc/λ = 1240/400 ≈ 3.10 eV。光電効果の式 Kmax = E − φ より、Kmax = 3.10 − 2.0 = 1.10 eV。

最も速い電子の速さは ½mv² = Kmax より、vmax = √(2K/m) = √(2 × 1.10 × 1.60×10−19/9.11×10−31) ≈ 6.2×105 m/s。

波長 650 nm の光では、光子のエネルギーは 1240/650 ≈ 1.91 eV < 2.0 eV なので、電子は出ない。限界波長は λ0 = hc/φ = 1240/2.0 = 620 nm である。

ステップ② コンデンサの充電：阻止電圧までたまる

電子が陽極に集まると、コンデンサが充電されて電圧が上がる。コンデンサの電圧が阻止電圧 V0 まで上がると、最も速い電子でも陽極に届かなくなり、充電は止まる。

阻止電圧は、電子の最大の運動エネルギーを電気的なエネルギーと等しく置いて、eV0 = Kmax より V0 = 1.10 V。たまった電荷は Q = CV0 = 10×10−9 × 1.10 = 11 nC。電子の数は N = Q/e = 11×10−9/1.60×10−19 ≈ 6.9×1010 個。静電エネルギーは U = ½CV0² = ½ × 10×10−9 × 1.10² ≈ 6.1 nJ。

充電にかかる時間は、光電流 I = 1.0 μA で一定として、t = Q/I = 11×10−9/1.0×10−6 = 11 ms。

次へ ↓

ステップ③ 磁場の円運動：電子は円を描く

飛び出した電子が磁場に入ると、ローレンツ力 F = evB を受けて円運動をする。速さは変わらない（磁場は仕事をしない）。

半径は r = mv/eB = 9.11×10−31 × 6.2×105/(1.60×10−19 × 1.0×10−3) ≈ 3.5 mm。周期は T = 2πm/eB = 2π × 9.11×10−31/(1.60×10−19 × 1.0×10−3) ≈ 36 ns。振動数は f = 1/T ≈ 28 MHz。

ローレンツ力の大きさは F = evB ≈ 1.0×10−16 N で、これが向心力である。周期が速さによらないことに注意：速さが違っても、円を1周する時間は同じである。

ステップ④ 罠：明るい光で V0 も r も大きくなる？

光を明るくすると、飛び出す電子の数は増えるが、1個の電子の最大の運動エネルギーは変わらない。したがって、阻止電圧 V0 は 1.10 V のまま、円運動の半径も 3.5 mm のままである。

明るくなるのは、電子の数が増えて充電が速くなることだけである（充電時間は 11 ms から 5.5 ms になる）。

また、阻止電圧で止まるのは、最も速い電子（Kmax の電子）だけである。運動エネルギーが小さい電子は、もっと小さい電圧で止まる。したがって「阻止電圧で全ての電子が止まる」はまちがいである。

ステップ⑤ 変えたら：波長 300 nm、磁場 2 倍、明るい光

波長を 300 nm にすると、光子のエネルギーは 1240/300 ≈ 4.13 eV、Kmax = 4.13 − 2.0 = 2.13 eV、vmax ≈ 8.7×105 m/s、V0 = 2.13 V、Q ≈ 21 nC、U ≈ 23 nJ、r ≈ 4.9 mm。周期は速さによらないので T ≈ 36 ns のままである。

磁場を 2.0 mT にすると、r = mv/eB より半径は半分の 1.8 mm、周期も半分の 18 ns（振動数 56 MHz）、ローレンツ力は 2 倍の 2.0×10−16 N になる。

光を明るくして光電流が 2.0 μA になると、充電時間は半分の 5.5 ms になるが、V0 と r は変わらない。

5つのチェックをすべて入れると完了になります。
