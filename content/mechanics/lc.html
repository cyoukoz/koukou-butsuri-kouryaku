組み合わせ問題D：LC回路＋単振動

問題：インダクタンス L = 0.10 H のコイルと、電気容量 C = 100 μF のコンデンサだけをつないだ回路がある。はじめコンデンサに電荷 Q0 = 1.0 × 10−3 C をため、スイッチを入れて回路を閉じる。抵抗はないものとする。(1) 電荷の振動の角振動数 ω と周期 T、振動数 f、(2) 最大電流 I0 とはじめのコンデンサの電圧 V0、(3) エネルギーの移り変わり、(4) ばね・質量の単振動との対応を求めよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v0.6、lc 型）が下の JSON データから回路図を描く。電流の矢印は破線で描く（向きだけを示し、大きさの縮尺ではない）。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：切り分けマップ（まずここで切る）

組み合わせ問題は、いきなり1本の式で解こうとすると間違える。先に時間で切り、系で切り、橋渡し量を決める。この問題の切り分けは次の表のとおり。

時間系（回路の状態）使う法則橋渡し量
t = 0コンデンサに電荷 Q0、電流は 0Q = CVQ0 = 1.0 mC、V0 = 10 V、電気エネルギー 5.0 mJ
t = T / 4電荷は 0、電流が最大エネルギー保存最大電流 I0 ≈ 0.32 A、磁気エネルギー 5.0 mJ
t = T / 2電荷は −Q0、電流は 0電荷の符号が逆になるQ = −1.0 mC、電気エネルギー 5.0 mJ
t = 3T / 4電荷は 0、電流は −I0エネルギー保存電流の向きが逆になる
t = Tもとの状態に戻る周期運動1周期 T ≈ 0.020 s

いちばんの罠は、エネルギーが「消える」と思うこと。この回路に抵抗はないから、エネルギーは失われない。電気エネルギーと磁気エネルギーのあいだを行ったり来たりするだけだ。電荷が 0 になった瞬間、エネルギーは 0 ではなく、全部コイルの磁気エネルギーになっている。

図はこれだけ。左がコンデンサ、右がコイルで、1つの輪になっている。ここから下へ、1つずつ進んでいく。

次へ ↓ ①t = 0

① t = 0：コンデンサに電荷がたまっている

はじめ、コンデンサの上板は +、下板は − で、電荷は Q0 = 1.0 × 10−3 C。電圧は V0 = Q0 / C = 1.0 × 10−3 / 1.0 × 10−4 = 10 V。電気エネルギーは (1/2) Q0² / C = 0.5 × (1.0 × 10−3)² / 1.0 × 10−4 = 5.0 × 10−3 J（5.0 mJ）。電流はまだ 0。ばねでいえば「いちばん伸ばしたところで、速度が 0」の状態だ。コイルにはまだエネルギーはない。


次へ ↓ ②対応表

② 対応表：ばね・質量の単振動と同じ式

この回路の電荷 Q は、L d²Q / dt² + Q / C = 0 という式に従う。ばね・質量の単振動の式 m d²x / dt² + kx = 0 と形が同じだ。対応は次の表のとおり。

LC回路ばね・質量意味
電荷 Q変位 x振動する量そのもの
電流 I = dQ / dt速度 v = dx / dt変化の速さ
インダクタンス L質量 m変化しにくさ（慣性）
1 / Cばね定数 kもとに戻そうとする強さ
(1/2) Q² / C(1/2) kx²たまっているエネルギー
(1/2) LI²(1/2) mv²動いているエネルギー

図は t = T / 4 の状態で、電流の矢印が上の導線を右向き、下の導線を左向きに流れている。コイルは「電流の変化を嫌う」はたらきで、ばね・質量でいう質量の役目をする。だから電流は急には止まれず、振動が続く。


次へ ↓ ③角振動数と周期

③ 角振動数と周期：ω = 1 / √(LC)

ばね・質量では ω = √(k / m) だった。対応表で k → 1/C、m → L と置き換えると、ω = √(1 / LC) = 1 / √(LC) になる。数を入れると、ω = 1 / √(0.10 × 1.0 × 10−4) = 1 / √(1.0 × 10−5) ≈ 316 rad/s。周期は T = 2π / ω ≈ 0.020 s（19.9 ms）、振動数は f = 1 / T ≈ 50 Hz。罠は、ω の式に Q0 を入れてしまうこと。周期ははじめの電荷の大きさには依らない（ばねの周期が振幅に依らないのと同じ）。


次へ ↓ ④最大電流とエネルギー

④ 最大電流とエネルギーの交換

t = T / 4 では、コンデンサの電荷は 0 になり、電流が最大になる。最大電流は I0 = ωQ0 = 316 × 1.0 × 10−3 ≈ 0.32 A。このときの磁気エネルギーは (1/2) LI0² = 0.5 × 0.10 × 0.32² ≈ 5.0 × 10−3 J（5.0 mJ）で、はじめの電気エネルギー 5.0 mJ と一致する。エネルギーは消えていない。電気から磁気へ、そっくり移っただけだ。ばねでいえば「つり合い位置を通るとき、速度が最大で、運動エネルギーが最大」の状態だ。


次へ ↓ ⑤符号が逆になる

⑤ t = T / 2 と 3T / 4：符号が逆になる

t = T / 2 では、コイルの電流がコンデンサを逆向きに充電し終えて、電荷は Q = −Q0、電流は 0 になる。図では上板が −、下板が + に入れ替わっている。電気エネルギーは (1/2) Q² / C で、Q が2乗されるから、符号が逆でも 5.0 mJ のままだ。t = 3T / 4 では、電荷は 0 に戻り、電流は −I0（向きが逆）で磁気エネルギーが 5.0 mJ になる。t = T で、はじめの状態に戻る。1周期で、電荷は +Q0 → 0 → −Q0 → 0 → +Q0 と1周する。


次へ ↓ 完了にする

完了にする

切り分けマップで「時間・系・橋渡し量」を分けたことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) ω = 1 / √(LC) ≈ 316 rad/s、T ≈ 0.020 s、f ≈ 50 Hz、(2) I0 = ωQ0 ≈ 0.32 A、V0 = Q0 / C = 10 V、(3) エネルギーは電気 5.0 mJ と磁気 5.0 mJ のあいだを行ったり来たりする（抵抗がないので失われない）、(4) 対応は Q ↔ x、I ↔ v、L ↔ m、1/C ↔ k。ばねの単振動の考え方は 第5問：ばねのつり合い と 組み合わせ問題B：衝突＋ばね でも確かめられる。なお、コイル・コンデンサの単体モデルのページはまだないので、このページの②で扱った対応表をそのまま使うこと。
