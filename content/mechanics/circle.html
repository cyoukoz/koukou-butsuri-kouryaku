第10問：円運動

問題：(1) なめらかな水平面の上で、質量 m = 1.0 kg の物体を長さ r = 0.50 m の糸でつないで、速さ v = 2.0 m/s で等速円運動させる。糸の張力 T、角速度 ω、周期 T を求めよ。(2) 鉛直面内の半径 R = 0.50 m のループを、同じ物体が回る。頂点でレールから離れずに回るための最小の速さと、そのときの速さで最下点を通るときの垂直抗力 N を求めよ。g = 10 m/s² とする。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。力の矢印の長さは力の大きさに比例している（2.5 px/N）。「必要な向心力」の矢印は破線で、力ではなく要請の目印だ。重力の矢印と重ならないよう、少し横にずらして描いてある。

はじめに：円運動は「曲がる」運動

等速円運動では、速さは変わらないのに速度の向きが変わり続ける。向きを変えるには、つねに中心向きの力が要る。その力を向心力という。ただし、向心力は新しい力の名前ではない。糸の張力や垂直抗力、重力のうち、中心を向いたものがその役割を果たす。ここがこの問題の中心の罠だ。

図は真上から見た円の軌道だ。ここから下へ、1つずつ確かめていく。

次へ ↓ ①水平面内の円運動

① 水平面内の円運動：張力 T = mv² / r

中心向きの力は、糸の張力 T だけだ。向心力の式 mv² / r に数を入れると、T = 1.0 × 2.0² / 0.50 = 8.0 N。角速度は ω = v / r = 2.0 / 0.50 = 4.0 rad/s、周期は T = 2π / ω ≈ 1.57 s。速度の矢印は破線で、円の接線方向を向いている。重力と垂直抗力はつり合っていて、図には出てこない。


次へ ↓ ②向心力は新しい力ではない

② 向心力は新しい力ではない

力の図示に「向心力」という矢印を1本足してはいけない。働いている力は張力 T だけで、それが中心を向いているから向心力の役割を果たしている、というだけだ。張力と向心力を両方数えると二重計算になる。Q1 の分解と同じ罠で、「成分」と「もとの力」を二重に数えてはいけないのと同じことだ。


次へ ↓ ③ループの頂点

③ ループの頂点：N = 0、重力だけが向心力

頂点では、重力 mg = 10 N が下向き（中心向き）で、垂直抗力 N はレールから物体を押す力だ。速さがちょうどいいと、重力だけで向心力がまかなえて、N = 0 になる。その速さは mv² / R = mg から、v = √(gR) = √(10 × 0.50) ≈ 2.24 m/s。これより遅いと、重力だけでは曲がりきれず、物体はレールから離れて落ちる。破線の「必要な向心力」の矢印は、重力の矢印と同じ長さ（10 N）で、重力だけで足りていることが分かる。


次へ ↓ ④ループの最下点

④ ループの最下点：N = 60 N

頂点から最下点まで落ちると、速さは増える。エネルギー保存から、v² = v頂点² + 4gR = 5.0 + 20 = 25 なので、最下点の速さは 5.0 m/s。最下点では、垂直抗力 N が上向き（中心向き）で、重力 mg が下向きだ。中心向きの力の差が向心力になる：N − mg = mv² / R なので、N = 10 + 1.0 × 25 / 0.50 = 60 N。重力の 6 倍だ。だからループの最下点では、体が重く感じる。


次へ ↓ ⑤まとめ

⑤ まとめ：中心向きの力を探す

円運動の問題は、まず「中心はどこか」を決める。次に、働く力のうち中心を向いたものを集めて、mv² / r と等しいと置く。中心を向いていない力は、向心力にはならない。速さが足りないと N = 0 になって落ちる、というのも、式を立ててから分かることだ。向心力を新しい力として足すのだけは、しないこと。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 張力 T = 8.0 N、角速度 ω = 4.0 rad/s、周期 ≈ 1.57 s。(2) 頂点の最小の速さ ≈ 2.24 m/s（N = 0）、最下点の速さ 5.0 m/s、垂直抗力 N = 60 N。円運動の考え方は 単元をまたぐ組み合わせC：荷電粒子＋円運動 でも使う。ローレンツ力が向心力の役割を果たす、同じ形の問題だ。
