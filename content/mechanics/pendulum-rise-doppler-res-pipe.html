組み合わせCA：振り子＋弾性衝突＋ばね＋摩擦＋ドップラー＋開管の共鳴

問題

長さ 1.0 m の糸に質量 1.0 kg の玉をつけ、玉を 0.45 m の高さまで持ち上げて静かに放す。玉には音さ（f0 = 490 Hz）がついている。最下点で玉は静止した質量 1.0 kg のブロックと弾性衝突し、ブロックは水平な床の上のばね（k = 100 N/m）に当たる。ブロックと床の動摩擦係数は μ = 0.20 である。最下点の横には、開管（長さ 0.35 m）が置いてある。音速は 340 m/s、重力加速度は g = 10 m/s² とする。振り子の振れは大きいので、周期は単振動の近似ではなく、厳密な値を使う。

（1）振り子：最下点の速さと音、周期を求めよ。（2）弾性衝突とばね：ブロックの速さと最大の縮みを求めよ。（3）再衝突と共鳴。（4）罠と変えたら。

この問題は、組み合わせ問題BK：振り子＋弾性衝突＋ばね＋摩擦＋ドップラーと組み合わせ問題BE：ドップラー効果＋開管の共鳴を組み合わせた問題です。橋渡しになる量は「速さ」です。単体モデルは第11問・単振動、第18問・ドップラー効果、第14問・定在波です。

この問題の切れ目（スライス）

  1. ① 振り子：0.45 m から落ち、最下点で 3.0 m/s、音は 494 Hz
  2. ② 弾性衝突とばね：ブロック 3.0 m/s、最大の縮み 0.28 m
  3. ③ 再衝突と共鳴：玉は 0.34 m まで上がり、音 486 Hz が管の f1 と一致
  4. ④ 罠：音さの 490 Hz と最下点の 494 Hz は共鳴しない
  5. ⑤ 変えたら：L・f0・閉管・μ で共鳴は変わるか

① 振り子：最下点で 3.0 m/s、音は 494 Hz、周期は 2.1 s

cosθ = (L − h)/L = 0.55、θ ≈ 56.6° になる。最下点の速さは v = √(2gh) = √(2 × 10 × 0.45) = 3.0 m/s、運動エネルギーは 4.5 J になる。張力は T = mg + mv²/L = 10 + 9 = 19 N になる。

周期：振れが大きいので、単振動の周期 2π√(L/g) ≈ 2.0 s は使えない。厳密な周期は T = 4√(L/g)·K(sin(θ/2)) ≈ 2.1 s、最下点までの時間は T/4 ≈ 0.53 s になる。単振動の近似だと 0.50 s になり、約 6% ずれる。

ドップラー効果：玉が観測者に向かうので、f′ = f0·V/(V − v) になる。最下点では f′ = 490 × 340/(340 − 3.0) ≈ 494 Hz になる。放す位置から最下点まで、速さが増えるにつれて音は 490 Hz から 494 Hz へ上がる。0.25 s では約 493 Hz になる。うなりは、音さの 490 Hz との差で、最大で約 4.4 Hz になる。

次へ ↓

② 弾性衝突とばね：ブロック 3.0 m/s、最大の縮み 0.28 m

弾性衝突（等しい質量）：速さが入れ替わる。玉は止まり（音は 490 Hz に戻る）、ブロックが 3.0 m/s で動く。運動量 3.0 kg·m/s、運動エネルギー 4.5 J は保存する。

ばねの角振動数は ω = √(k/M) = 10 rad/s になる。縮むとき、摩擦は左向きにはたらくので、つり合いのずれは x_eq1 = −f/k = −0.020 m になる。最大の縮みは x_max = −0.020 + √[0.020² + (3.0/10)²] ≈ 0.28 m になる。ばねの力は k·x_max = 28 N になる。圧縮にかかる時間は 0.15 s だ。

戻るとき、摩擦は右向きにはたらくので、つり合いのずれは +0.020 m に変わる。押し返しの速さは v_return = ω√[(x_max − 0.020)² − 0.020²] ≈ 2.6 m/s になる。戻りに 0.16 s かかる。摩擦熱は 1.1 J、押し返しの運動エネルギーは 3.4 J になる。

次へ ↓

③ 再衝突と共鳴：玉は 0.34 m まで上がり、音は 486 Hz

再衝突：ブロックが戻って玉に当たる。等しい質量の弾性衝突で、ブロックは止まり、玉が 2.6 m/s をもらって左へ振り上がる。上がる高さは h2 = v²/2g = 2.6²/20 ≈ 0.34 m、振り上がりの角度は約 49°、上がる時間は約 0.52 s になる。玉は観測者から遠ざかるので、音は f′ = 490 × 340/(340 + 2.6) ≈ 486 Hz に聞こえる。頂点では 490 Hz に戻る。

共鳴：開管の振動数は f_n = n·v/(2L) = n × 340/(2 × 0.35) になる。f1 = 486 Hz、f2 = 971 Hz、f3 = 1460 Hz だ。再衝突の音 486 Hz は管の f1 と一致するので、共鳴する。厳密には、再衝突の音は 486.28 Hz、管の f1 は 485.71 Hz で、有効数字 3 けたではどちらも 486 Hz になる。音さの 490 Hz そのものは管の振動数ではないし、最下点の 494 Hz も合わない。共鳴するのは、再衝突で玉が上がりはじめる一瞬だけだ。

次へ ↓

④ 罠：音さの 490 Hz は共鳴しない、最速の最下点でも共鳴しない

罠：「音さの 490 Hz が共鳴する」——まちがい。管の振動数は 486・971・1460 Hz で、490 Hz はどれとも合わない。共鳴するのはドップラーで低くなった再衝突の音 486 Hz だけだ。

罠：「最速の最下点で共鳴する」——まちがい。最下点の音は 494 Hz で、管の f1 = 486 Hz とは合わない。速いところで共鳴するとは限らない。

罠：「くっつく衝突なら 492 Hz で共鳴する」——まちがい。くっつくと玉とブロックは 1.5 m/s でいっしょに動き、音は 492 Hz になる。486 Hz の f1 とは 6 Hz 離れていて、共鳴しない。ばねの最大の縮みも 0.18 m になる。

罠：「1段の計算で押し返し 3.0 m/s、上がる高さ 0.45 m」——まちがい。1段の計算だと押し返しは当たった速さと同じ 3.0 m/s、上がる高さは 0.45 m になるが、摩擦の向きの反転を入れると正しくは 2.6 m/s、0.34 m だ。摩擦なしだと 0.30 m になる。

次へ ↓

⑤ 変えたら：h・L・f0・閉管・μ で共鳴が変わる

h = 0.20 m なら、最下点で 2.0 m/s、音は 493 Hz になり、管の f1 = 486 Hz と合わず、共鳴しない。ばねの最大の縮みは 0.18 m、ばねの力 18 N、押し返し 1.6 m/s、上がる高さ 0.13 m になる（BK の数値）。

L = 0.70 m なら、f1 = 243 Hz、f2 = 486 Hz になる。再衝突の音 486 Hz は f2 と一致して、やはり共鳴する。

f0 = 440 Hz なら、再衝突の音は 440 × 340/(340 + 2.6) ≈ 437 Hz になり、管の 486 Hz と合わず、共鳴しない。

閉管なら、f_n = (2n − 1)v/4L で、243・729・1210 Hz になる。再衝突の 486 Hz はどれとも合わず、共鳴しない。

μ = 0.40 なら、最大の縮み 0.26 m、ばねの力 26 N、押し返し 2.2 m/s、摩擦熱 2.1 J、上がる高さ 0.24 m になる。再衝突の音は 487 Hz になり、管の f1 = 486 Hz とは有効数字 3 けたで合わず、共鳴しない。

振り子（h = 0.45 m、最下点 3.0 m/s、周期 2.1 s）に弾性衝突とばね＋摩擦（最大の縮み 0.28 m、押し返し 2.6 m/s）を組み合わせ、ドップラー効果と開管の共鳴を足しました。最下点の音は 494 Hz で管とは合わず、再衝突で玉が上がりはじめるときの音 486 Hz（厳密には 486.28 Hz、管の f1 は 485.71 Hz）が管の f1 と一致して共鳴します。音源そのものの 490 Hz は共鳴しません。橋渡しになった量は「速さ」でした。

もとになった単体モデル：振り子＋衝突＋ばね＋ドップラーは組み合わせ問題BK：振り子＋弾性衝突＋ばね＋摩擦＋ドップラー、開管の共鳴は組み合わせ問題BE：ドップラー効果＋開管の共鳴、振り子は第11問：単振動・振り子、ドップラー効果は第18問：ドップラー効果で確かめられる。
