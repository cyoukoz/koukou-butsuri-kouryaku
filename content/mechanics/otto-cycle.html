組み合わせ問題AJ：オットーサイクル（ガソリンエンジン）

問題：ガソリンエンジンのシリンダーに、空気 n = 0.040 mol が入っている。はじめ A：p1 = 1.0×10⁵ Pa、V1 = 1.0 L、T1 = 300 K だ。ピストンで圧縮比 r = 8 まで断熱圧縮し（A→B）、等積で加熱して T3 = 2000 K にし（B→C）、断熱膨張させ（C→D）、等積で冷やしてはじめに戻す（D→A）。空気は二原子分子気体で γ = 1.4、Cv = (5/2)R とする。(1) B の圧力と温度、圧縮に必要な仕事を求めよ。(2) C の圧力と、入る熱を求めよ。(3) D の圧力と温度、膨張の仕事と出る熱、正味の仕事と効率を求めよ。(4) カルノー効率と比べよ。(5) 圧縮比を 4・12 にすると効率はどうなるか。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v3.1、ottoCycle 型）が下の JSON データから計算して描く。p-V 図の縦軸は対数軸で、断熱曲線は pV^γ = 一定から計算した点列だ。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。サイクルは4つの過程に切る。過程ごとに、状態方程式と熱力学第一法則と断熱の式を使い分ける。

断熱変化では pV^γ = 一定、等積変化では W = 0 だ。過程ごとに使える式がちがう。p-V 図の面積が、正味の仕事になる。

はじめ、A は p1 = 1.0×10⁵ Pa、V1 = 1.0 L、T1 = 300 K だ。物質量は、n = p1V1/(RT1) = 1.0×10⁵ × 1.0×10⁻³ / (8.31 × 300) ≈ 0.040 mol になる。ここから下へ、1つずつ確かめていく。

次へ ↓ ①断熱圧縮

① 断熱圧縮：A→B

まず A→B の断熱圧縮だけを見る。体積は、圧縮比 r = 8 なので、V2 = V1/8 = 1.0/8 = 0.125 L になる。断熱変化では pV^γ = 一定なので、圧力は p2 = p1 × r^γ = 1.0×10⁵ × 8^1.4 ≈ 1.84×10⁶ Pa になる。

温度は、T2 = T1 × r^(γ−1) = 300 × 8^0.4 ≈ 689 K になる。断熱変化では、熱の出入りがないので、入った仕事が全部内部エネルギーの増加になる。圧縮に必要な仕事は、W_in = ΔU = nCv(T2 − T1) = 0.040 × 20.8 × (689 − 300) ≈ 324 J だ。

圧力が 18 倍にもなるのは、体積が 1/8 になるだけでなく、温度も上がるからだ。pV^γ = 一定の式に、T2/T1 = (V1/V2)^(γ−1) の関係が入っている。


次へ ↓ ②等積加熱

② 等積加熱：B→C

次に B→C の等積加熱だけを見る。ガソリンに点火して、体積を変えずに熱を入れる。温度は T3 = 2000 K まで上がる。体積は変わらないので、圧力は温度に比例して上がる。p3 = p2 × T3/T2 = 1.84×10⁶ × 2000/689 ≈ 5.33×10⁶ Pa になる。

入る熱は、等積変化なので Q_in = nCv(T3 − T2) になる。Cv = (5/2)R = 20.8 J/(mol·K) なので、Q_in = 0.040 × 20.8 × (2000 − 689) ≈ 1092 J だ。体積は変わらないので、仕事は W = 0 で、熱は全部内部エネルギーの増加になる。

ここで Cp ではなく Cv を使うのが大事だ。体積が変わらないので、定積熱容量 Cv を使う。Cp を使うと、1092 J ではなく 1529 J になってしまう。


次へ ↓ ③断熱膨張と等積冷却

③ 断熱膨張と等積冷却：C→D→A

次に C→D の断熱膨張を見る。体積が 0.125 L から 1.0 L に戻る。温度は、T4 = T3/r^(γ−1) = 2000/8^0.4 ≈ 871 K になる。圧力は、p4 = p3/r^γ = 5.33×10⁶/8^1.4 ≈ 2.90×10⁵ Pa になる。

膨張で気体のする仕事は、W_out = ΔU = nCv(T3 − T4) = 0.040 × 20.8 × (2000 − 871) ≈ 941 J だ。圧縮で入れた 324 J より大きい。差が、正味の仕事になる。

最後に D→A の等積冷却で、はじめに戻る。出る熱は、Q_out = nCv(T4 − T1) = 0.040 × 20.8 × (871 − 300) ≈ 475 J だ。正味の仕事は、W = Q_in − Q_out = 1092 − 475 = 617 J になる。941 − 324 = 617 J とも一致する。効率は、η = W/Q_in = 617/1092 ≈ 57% だ。理論式 η = 1 − 1/r^(γ−1) = 1 − 1/8^0.4 ≈ 0.565 とも一致する。


次へ ↓ ④罠：カルノー効率と比べる

④ 罠：カルノー効率と比べる

罠は、オットーサイクルの効率がカルノー効率と同じになると思うことだ。2000 K と 300 K のあいだのカルノー効率は、η_C = 1 − 300/2000 = 85% になる。オットーの 57% よりずっと大きい。カルノー効率は、同じ 2 つの温度のあいだで動く熱機関の上限だ。オットーは 85% をこえられない。

なぜオットーは 85% に届かないのか。カルノーサイクルは、熱を 2000 K でだけ入れ、300 K でだけ出す。オットーは、加熱のあいだ温度が 689 K から 2000 K まで変わり、冷却のあいだも 871 K から 300 K まで変わる。熱を、最高温度より低い温度でも入れているので、効率が下がる。

もう1つの罠は、γ の取り違えだ。空気は二原子分子気体で γ = 1.4 だが、ヘリウムの γ = 5/3 を使うと、η = 1 − 8^(−2/3) = 75% になってしまう。気体がちがえば、γ も Cv もちがう。問題文の気体を確かめてから計算する。


次へ ↓ ⑤変えたら

⑤ 変えたら：圧縮比を上げる

圧縮比を変えると、効率はどうなるか。効率は η = 1 − 1/r^(γ−1) だけで決まる。圧縮比 r = 4 なら、η = 1 − 4^(−0.4) ≈ 43% になる。r = 8 なら 57%、r = 12 なら、η = 1 − 12^(−0.4) ≈ 63% になる。圧縮比を上げると、効率は上がる。

r = 12 のとき、圧縮後の温度は T2 = 300 × 12^0.4 ≈ 811 K、圧力は p2 = 1.0×10⁵ × 12^1.4 ≈ 3.24×10⁶ Pa になる。圧縮後の温度が高くなるほど、加熱で入る熱の割合が増え、効率が上がる。

実際のガソリンエンジンの圧縮比は、10 前後だ。上げすぎると、点火する前に混合気が爆発するノッキングが起きる。効率を上げるには、圧縮比を上げるだけでなく、ノッキングを防ぐ工夫もいる。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) V2=0.125 L、p2=1.84×10⁶ Pa、T2=689 K、W_in=324 J。(2) p3=5.33×10⁶ Pa、Q_in=1092 J、W=0。(3) T4=871 K、p4=2.90×10⁵ Pa、W_out=941 J、Q_out=475 J、W=617 J、η=57%。(4) カルノー効率は 85%。γ=5/3 とすると 75% になってしまう。(5) r=4 では 43%、r=12 では 63%、r=12 では T2=811 K、p2=3.24×10⁶ Pa。もとになった単体モデル：理想気体は 第7問：気体・ピストン、熱サイクルは 第16問：熱サイクル、気体＋ピストン＋ばね＋サイクルは 組み合わせ問題P：気体＋ピストン＋ばね＋サイクル、気体＋共鳴管は 組み合わせ問題M：気体＋共鳴管 で確かめられる。
