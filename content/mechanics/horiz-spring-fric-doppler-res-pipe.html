組み合わせDA：水平ばね振り子＋摩擦＋ドップラー＋開管の共鳴（最初の1回だけ共鳴）

質量 m = 1.0 kg のおもりを、ばね定数 k = 100 N/m のばねで水平な床の上の壁につなぎます。おもりは床の上をすべり、床とのあいだに大きさが変わらない摩擦力 f = 2.0 N がはたらきます。重力加速度は g = 10 m/s² としますが、重力は床からの垂直抗力とつり合うので、水平方向の運動には関係しません。つりあいの位置から 0.20 m 右の点でおもりを静かにはなすと、おもりは左右に振動します。おもりには振動数 f0 = 397.5 Hz の音源がついていて、観測者はおもりのはるか左にいます。音速は V = 340 m/s です。長さ L = 0.425 m の開管がそばに置いてあります。

この問題では、（1）水平ばね振り子＋摩擦のつりあいと振動を求め、（2）つりあいの位置を通るときの速さを調べ、（3）ドップラー効果で聞こえる音の高さと開管の共鳴を調べ、（4）まちがいやすい点と、条件を変えたらどうなるかを考えます。

土台になっている問題：組み合わせCY・鉛直ばね振り子＋摩擦＋ドップラー＋開管の共鳴、組み合わせCW・鉛直ばね振り子＋ドップラー＋開管の共鳴、組み合わせAA・斜面上のばね振り子＋摩擦、第5問・ばねのつり合い、第11問・単振動・振り子、BE・ドップラー＋開管の共鳴、第18問・ドップラー効果、第14問・定常波

解き方の地図

  • ① 水平ばね振り子＋摩擦：つりあいは自然長、振幅 0.20 m、振幅は半周期ごとに 0.040 m 減る
  • ② 中心の速さ：1.8、1.4、0.98、0.57 m/s（エネルギーで求める）
  • ③ ドップラーと共鳴：1 回目の左向きの音 400 Hz が管の f1 と有効数字3けたで一致して共鳴する
  • ④ 罠：「共鳴は1周期ごとにくり返される」はまちがい——2 回目の左向きは 399 Hz
  • ⑤ 変えたら：L・f0・閉管・μ・振幅で共鳴は変わるか

① 水平ばね振り子＋摩擦：つりあいと振動

おもりにはたらく力は、重力 mg = 1.0 × 10 = 10 N（下向き）と床からの垂直抗力 10 N（上向き）で、鉛直方向はつり合っています。水平方向にはたらく力は、ばねの力だけです。だから水平方向の運動は、重力とは関係ありません。

おもりが静止するつりあいの位置では、ばねの力が 0 になるので、つりあいの位置はばねの自然長の端です。鉛直ばね振り子（CY）ではつりあいが自然長から 0.10 m 下にずれましたが、水平ばね振り子ではずれません。

おもりをはなす点はつりあいから 0.20 m 右なので、おもりはつりあいの位置を中心に、振幅 A = 0.20 m の振動をします。左端はつりあいの位置から 0.20 m 左です。

角振動数は ω = √(k/m) = √(100/1.0) = 10 rad/s、周期は T = 2π/ω = 2π/10 = 0.63 s です。半周期は T/2 = 0.31 s です。摩擦がなければ速さの最大は v_max = Aω = 0.20 × 10 = 2.0 m/s ですが、摩擦があるので実際には小さくなります。

はなす点では、ばねは 0.20 m 伸びておもりを k × 0.20 = 20 N 左向きに引きます。だからおもりははじめ左向きに動き出します。

摩擦力 f = 2.0 N は、動いているあいだつねに動きと反対向きにはたらきます。摩擦があると、振動の中心はつりあいの位置から摩擦力の分だけずれます。ずれは δ_f = f/k = 2.0/100 = 0.020 m です。左向きに動くあいだは中心が 0.020 m 右にずれ、右向きに動くあいだは 0.020 m 左にずれます。そのため振幅は半周期ごとに 2δ_f = 0.040 m ずつ減ります。

振幅：0.20 → 0.16 → 0.12 → 0.08 → 0.04 → 0 m。5 半周期、1.57 s で止まります。動いた距離は 0.20 + 2 × (0.16 + 0.12 + 0.08 + 0.04) + 0 = 1.00 m、摩擦で熱になったエネルギーは 2.0 × 1.00 = 2.0 J で、はじめのエネルギー ½kA² = ½ × 100 × 0.20² = 2.0 J と一致します。

② 中心の速さ

つりあいの位置の中心を通るときの速さは、エネルギーで求めます。はじめの位置（振幅 A）から中心までのあいだに摩擦がする仕事は f × A です。

1 回目の中心：½mv² = ½ × 100 × 0.20² − 2.0 × 0.20 = 2.00 − 0.40 = 1.6 J → v = 1.8 m/s。1 回目は左向きに通ります。時刻は t = 0.17 s です。

2 回目の中心：½mv² = ½ × 100 × 0.16² − 2.0 × 0.16 = 1.28 − 0.32 = 0.96 J → v = 1.4 m/s。2 回目は右向きに通ります。時刻は t = 0.49 s です。

3 回目の中心：½mv² = ½ × 100 × 0.12² − 2.0 × 0.12 = 0.72 − 0.24 = 0.48 J → v = 0.98 m/s。3 回目は左向きに通ります。時刻は t = 0.81 s です。

4 回目の中心：½mv² = ½ × 100 × 0.08² − 2.0 × 0.08 = 0.32 − 0.16 = 0.16 J → v = 0.57 m/s。4 回目は右向きに通ります。時刻は t = 1.13 s です。

5 回目は振幅が 0 になるので速さは 0 m/s で、おもりはつりあいの位置で止まります。時刻は t = 1.57 s です。中心のエネルギーは 1.6 → 0.96 → 0.48 → 0.16 → 0 J と減っていきます。速さが小さくなるのは、摩擦でエネルギーが減るからです。

③ ドップラーと共鳴

おもりが左向きに動くときは観測者に近づくので音は高くなり、右向きに動くときは遠ざかるので音は低くなります。近づくとき f′ = f0 × V/(V − v)、遠ざかるとき f′ = f0 × V/(V + v) です。折り返し点ではおもりが止まるので音は 397.5 Hz のままです。

中心を通るときの音は、1 回目の左向きが 399.60 Hz、1 回目の右向きが 395.89 Hz、2 回目の左向きが 398.65 Hz、2 回目の右向きが 396.84 Hz で、折り返し点と止まったときは 397.5 Hz です。

1 回目の左向きは、速さ 1.8 m/s（厳密には 1.79 m/s）で近づくので、音は f′ = 397.5 × 340/(340 − 1.79) = 399.60 Hz です。1 回目の右向きは、速さ 1.4 m/s（厳密には 1.39 m/s）で遠ざかるので、音は f′ = 397.5 × 340/(340 + 1.39) = 395.89 Hz です。2 回目の左向きは、速さ 0.98 m/s で近づくので、音は f′ = 397.5 × 340/(340 − 0.98) = 398.65 Hz です。2 回目の右向きは、速さ 0.57 m/s で遠ざかるので、音は f′ = 397.5 × 340/(340 + 0.57) = 396.84 Hz です。

一方、開管の振動数は f1 = 340/(2 × 0.425) = 400 Hz、f2 = 800 Hz、f3 = 1200 Hz です。

1 回目の左向きの音 399.60 Hz は、管の f1 = 400.00 Hz と有効数字3けたで 400 Hz に一致します。厳密な値は 0.40 Hz だけちがうので「ちょうど一致」とは言えませんが、3けたの有効数字では同じ 400 Hz です。だからおもりがつりあいの位置を1 回目に左向きに通る瞬間だけ、管が共鳴して大きく鳴ります。2 回目の左向きの音 398.65 Hz は 399 Hz で、f1 とは 1 Hz しかちがわないのに共鳴しません。1 Hz ちがうだけでも、一致しなければ共鳴しません。

動かない 397.5 Hz の音源と比べると、うなりは 1 回目の左向きの音で 399.60 − 397.5 = 2.1 Hz、1 回目の右向きの音で 397.5 − 395.89 = 1.6 Hz で、最大は 2.1 Hz です。

④ 罠

罠1：「音源そのものの 397.5 Hz が共鳴する」——まちがい。397.5 Hz は管の f1 = 400 Hz と 2.5 Hz はなれているので共鳴しません。音源の音が共鳴するわけではありません。

罠2：「共鳴は1周期ごとにくり返される」——まちがい。摩擦がなければ、左向きに通る音は毎回 399.85 Hz → 400 Hz になって、1周期に 1回ずつ共鳴します。でも摩擦があると、2 回目の左向きの音は 398.65 Hz → 399 Hz になって、f1 とは 1 Hz しかちがわないのに共鳴しません。共鳴するのは最初の1回だけです。

罠3：「摩擦がなくても、1 回目の音はちがう」——まちがい。摩擦なしなら中心の速さはつねに 2.0 m/s で、左向きの音は 397.5 × 340/(340 − 2.0) = 399.85 Hz → 400 Hz、右向きの音は 397.5 × 340/(340 + 2.0) = 395.18 Hz → 395 Hz になります。1 回目の答えは摩擦あり（399.60 Hz）と同じ 400 Hz です。摩擦が変えるのは 1 回目の答えではなく、共鳴がくり返されるかどうかです。

罠4：重力を入れて、つりあいが自然長から mg/k = 0.10 m ずれる（CY の鉛直ばねと同じ）と考え、振幅を 0.30 m とすると、速さの最大は v_max = 0.30 × 10 = 3.0 m/s になって、音は 397.5 × 340/(340 − 3.0) = 401.04 Hz → 401 Hz になり、共鳴しないとまちがえます。水平面では重力は床からの垂直抗力とつり合い、水平方向の運動には関係しません。つりあいは自然長そのもので、振幅は 0.20 m です。

罠5：符号をまちがえて f′ = f0 × V/(V + v) を使うと、左向きに通る音が 397.5 × 340/(340 + 1.79) = 395.42 Hz になって、共鳴しないとまちがえます。右向きに通る音も 397.5 × 340/(340 − 1.39) = 399.13 Hz になって、やはり共鳴しません。左向き（近づくとき）は分母が V − v、右向き（遠ざかるとき）は V + v です。

罠6：左端からはなすと、1 回目の中心は右向きに通るので、音は 397.5 × 340/(340 + 1.79) = 395.42 Hz → 395 Hz になって、共鳴はすっかりなくなります。右端からはなしてはじめて、1 回目の中心が左向き（近づく）になって 400 Hz になります。

⑤ 変えたら

L = 0.85 m にすると、f1 = 340/(2 × 0.85) = 200 Hz、f2 = 400 Hz、f3 = 600 Hz、f4 = 800 Hz になります。1 回目の左向きの音 400 Hz は f2 と一致するので、やはり共鳴します。L = 0.17 m にすると f1 = 1000 Hz、f2 = 2000 Hz、f3 = 3000 Hz になり、1 回目の左向きの音とは一致しないので共鳴しません。

f0 = 440 Hz にすると、1 回目の左向きの音は 440 × 340/(340 − 1.79) = 442 Hz、1 回目の右向きの音は 440 × 340/(340 + 1.39) = 438 Hz になり、管の振動数とは一致しないので共鳴しません。管を閉管（片端が閉じた管）にすると、振動数は 200 Hz、600 Hz、1000 Hz になり、1 回目の左向きの音 400 Hz とは一致しないので共鳴しません。

μ = 0.40 にすると、摩擦力は f = 4.0 N になります（最大静止摩擦力も 4.0 N とします）。ずれは δ_f = 4.0/100 = 0.040 m で、振幅は半周期ごとに 2 × 0.040 = 0.080 m ずつ減ります。振幅は 0.20 → 0.12 → 0.04 → 0 m と減ります。1 回目の中心の速さは、エネルギーで ½mv² = ½ × 100 × 0.20² − 4.0 × 0.20 = 2.00 − 0.80 = 1.2 J → v = 1.5 m/s（厳密には 1.549 m/s）です。左向きの音は 397.5 × 340/(340 − 1.549) = 399.32 Hz → 399 Hz になって、管の f1 = 400 Hz とは一致しないので、共鳴はすっかりなくなります。

振幅を A = 0.30 m にすると（つりあいから 0.30 m 右ではなす）、1 回目の中心の速さは、エネルギーで ½mv² = ½ × 100 × 0.30² − 2.0 × 0.30 = 4.50 − 0.60 = 3.9 J → v = 2.8 m/s（厳密には 2.793 m/s）です。左向きの音は 397.5 × 340/(340 − 2.793) = 400.79 Hz → 401 Hz になって、1 回目では共鳴しません。でも 3 回目の中心（左向き）の速さは 2.0 m/s（厳密には 1.990 m/s）で、音は 397.5 × 340/(340 − 1.990) = 399.84 Hz → 400 Hz になって共鳴します。共鳴する回が 1 回目から 3 回目にずれます。振幅は 0.30 → 0.26 → 0.22 → 0.18 → 0.14 → 0.10 → 0.06 → 0.02 m と減り、7 半周期（2.2 s）で止まります。動いた距離は 2.24 m、熱は 4.48 J です。

水平ばね振り子＋摩擦（つりあいは自然長、振幅 0.20 m、振幅は半周期ごとに 0.040 m 減る、5 半周期で止まる）に、ドップラー効果と開管の共鳴を組み合わせました。中心の速さは 1.8 → 1.4 → 0.98 → 0.57 m/s と小さくなります。1 回目の左向きの音は 399.60 Hz で、管の f1 = 400.00 Hz と有効数字3けたで 400 Hz に一致して、最初の1回だけ共鳴します。2 回目の左向きの音は 398.65 Hz → 399 Hz で共鳴しません。音源の 397.5 Hz、右向きの音も共鳴しません。水平面では重力は垂直抗力とつり合い、つりあいは自然長そのものです。橋渡しになった量は「速度（水平方向）」でした。
