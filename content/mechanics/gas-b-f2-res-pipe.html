← 前の問題：組み合わせ問題CK・落下するコイル＋コンデンサー＋ばね＋摩擦＋ドップラー＋開管の共鳴

組み合わせ問題CL：気体＋ピストン＋ばね＋カルノー効率＋ドップラー＋開管の共鳴（B で f2 と共鳴）

この問題は、BN（気体＋ピストン＋ばね＋カルノー効率）にドップラー効果と開管の共鳴を足したものだ。サイクルが回ると、気体の温度が変わる。温度が変わると、管の中の音速が変わる。音速が変わると、管の共鳴する振動数と、ピストンの音のドップラー効果の両方が変わる。温度と速さが橋渡しをする問題だ。BV では A、BZ では B の f1 が共鳴したが、この問題では B の f2 が共鳴する。

シリンダーの中にヘリウム（単原子分子気体、γ = 5/3、モル質量 4.0×10⁻³ kg/mol）が入っている。シリンダーの断面積は 0.010 m²、ピストンの質量は 10 kg、ばね定数は 1000 N/m、ばねの自然長のときの気体の高さは 0.20 m、大気圧は 1.0×10⁵ Pa、重力加速度は g = 10 m/s² とする。気体の状態は A（h = 0.20 m、T = 300 K）から始まる。A→B：加熱してピストンを h = 0.30 m まで上げる。B→C：ピストンを固定して 300 K まで冷やす。C→A：等温圧縮して A に戻す。

ピストンの上には 1494 Hz の音源がのっている。A→B のあいだ、ピストンは 34 m/s で上がっている瞬間を考える。観測者はピストンの真上にいて、音を聞いている。ドップラー効果はその瞬間の速さで決まるので、サイクル全体にかかる時間は関係ない。シリンダーのそばに、長さ 0.85 m の開管がある。音速は v = √(γRT/M) で求める。R = 8.31 J/(mol・K) とする。

（1）p–V 図とサイクルの仕事・効率を求め、カルノー効率と比べよ。（2）各状態での音速と管の振動数を求めよ。（3）ピストンが動くときの音の高さを求め、共鳴するかどうかを確かめよ。（4）罠と変えたら。

この問題のもとのモデル：組み合わせ問題BN・気体＋ピストン＋ばね＋カルノー効率、組み合わせ問題BI・気体＋音速＋開管の共鳴、組み合わせ問題BR・気体＋ピストン＋ばね＋音速＋開管の共鳴、組み合わせ問題BV・気体＋ピストン＋ばね＋音速＋ドップラー＋開管の共鳴、組み合わせ問題BZ・気体＋ピストン＋ばね＋カルノー効率＋ドップラー＋開管の共鳴、組み合わせ問題P・気体＋ピストン＋ばね＋サイクル、Q18・ドップラー効果、Q14・定常波

はじめに：この問題の切れ目

切れ目何をするか使うモデル
サイクル仕事と効率、カルノー効率との比べ気体＋ピストン＋ばね

この問題の橋渡しの量は温度と速さだ。状態 A・B・C の温度が管の中の音速を決め、音速とピストンの速さがドップラー音を決める。温度が変われば、共鳴するかどうかも変わる。BV では A で、BZ では B の f1 で共鳴したが、この問題では B の f2 が共鳴する。

次へ ↓

① サイクル：p–V 図と正味の仕事、カルノー効率との比べ

まず、気体のサイクルを p–V 図で確認する。状態 A では、ピストンの力のつり合いから pA = 1.10×10⁵ Pa、VA = 2.0×10⁻³ m³ になる。状態 B では、h = 0.30 m でばねが 0.10 m 縮むので pB = 1.20×10⁵ Pa、VB = 3.0×10⁻³ m³ になる。状態 C では、温度が 300 K に戻るので pC = 0.733×10⁵ Pa になる。温度は TB = 491 K、TC = 300 K だ。

A→B では、仕事は WAB = 115 J、内部エネルギーの変化は ΔUAB = 210 J、吸熱は QAB = 325 J になる。B→C では WBC = 0、ΔUBC = −210 J、QBC = −210 J になる。C→A では、温度が変わらないので ΔUCA = 0、仕事は WCA ≈ −89 J になる。

正味の仕事は、p–V 図に囲まれた面積で、Wnet = 115 − 89.2 = 25.8 J になる。効率は η = Wnet/QAB = 25.8/325 ≈ 7.9% になる。同じ 300 K と 491 K のあいだのカルノー効率は ηC = 1 − 300/491 ≈ 39% で、このサイクルの効率はカルノー効率の 1/5 ほどしかない。カルノーサイクルなら同じ 325 J の熱から 325 × 0.39 ≈ 127 J の仕事が得られる。

A→B の仕事 115 J の内訳は、大気の仕事 p0ΔV = 100 J、重力の位置エネルギーの増加 mgΔh = 10 J、ばねのエネルギーの増加 ½k(Δh)² = 5.0 J で、100 + 10 + 5.0 = 115 J と合う。

次へ ↓

② 音速と管の振動数：温度が決める

気体の中の音速は v = √(γRT/M) だ。温度 T が上がると、音速は √T に比例して大きくなる。

状態 A・C（300 K）では、v = √(1.667×8.31×300/0.004) = 1020 m/s になる。開管の振動数は fn = nv/(2L) で、L = 0.85 m だから f1 = 600 Hz、f2 = 1200 Hz、f3 = 1800 Hz になる。

状態 B（491 K）では、v = 1020×√(491/300) = 1300 m/s になる。開管の振動数は f1 = 767 Hz、f2 = 1534 Hz、f3 = 2300 Hz になる。厳密な値は、音速が 1304 m/s、f1 = 766.99 Hz、f2 = 1533.98 Hz、f3 = 2300.97 Hz だ。

ピストンの上の音源の振動数は 1494 Hz だ。音源そのものは、管の振動数（A・C では 600・1200・1800 Hz、B では 767・1534・2300 Hz）と一致しない。音源が止まっているときは、共鳴は起こらない。

次へ ↓

③ ドップラーと共鳴：A では共鳴しないが、B の f2 で共鳴する

ピストンが観測者に近づくとき、聞こえる音は f′ = f0·V/(V − vs) になる。音速 V は、そのときの気体の温度のものを使わなければならない。

A→B のはじめは、気体の温度が 300 K で音速は 1020 m/s だ。ピストンが 34 m/s で上がるとき、音は f′ = 1494×1020/(1020 − 34) = 1546 Hz になる。厳密な値は 1545.55 Hz で、管の振動数（600・1200・1800 Hz）とは一致しない。だから、A では共鳴しない。

A→B のおわり＝状態 B では、気体の温度が 491 K で音速は 1300 m/s になる。ピストンが同じ 34 m/s で上がっても、音は f′ = 1494×1300/(1300 − 34) = 1534 Hz になる。厳密な値は 1534.00 Hz で、管の f2（厳密には 1533.98 Hz）と有効数字 3 けたで一致する。どちらも 1534 Hz になるので、B では共鳴する。同じ音源、同じ速さでも、温度が変わると音速が変わり、共鳴するかどうかが変わる。B の f1 = 767 Hz ではなく、f2 = 1534 Hz と一致するのがこの問題のポイントだ。

音源が止まっているときは、音は 1494 Hz のままで、A でも B でも管の振動数と合わない。C→A でピストンが 34 m/s で下がるときは、音は遠ざかるので f′ = 1494×1020/(1020 + 34) = 1446 Hz になり、管の振動数（600・1200・1800 Hz）とは合わない。

次へ ↓

④ 罠：温度を無視すると、共鳴を見逃す

罠 1：「サイクルを通して共鳴は変わらない」——まちがい。B では温度が上がって音速が上がり、管の振動数もドップラー音も変わる。A では共鳴しなくても、B では共鳴する。

罠 2：「B の音を 300 K の音速で計算する」——まちがい。300 K の音速 1020 m/s を使うと、f′ = 1494×1020/(1020 − 34) = 1546 Hz になり、管の f2（300 K では 1200 Hz）と合わないので「B では共鳴しない」と思ってしまう。B の音速は 491 K で計算して 1300 m/s、ドップラー音は 1534 Hz で、管の f2 = 1534 Hz と一致して共鳴する。音速は、その状態の温度で計算しなければならない。

罠 3：「音速は温度に比例する」——まちがい。v ∝ T だと思うと、491 K の音速は 1020×491/300 = 1670 m/s、f1 = 980 Hz、ドップラー音は 1494×1670/(1670 − 34) = 1525 Hz になる。正しくは v ∝ √T で、音速は 1300 m/s、f1 = 767 Hz、ドップラー音は 1534 Hz だ。

罠 4：「閉管でもドップラー音が共鳴する」——まちがい。閉管の振動数は奇数倍だけで、300 K では 300・900・1500 Hz、491 K では 383・1150・1920 Hz になり、A の音 1546 Hz も B の音 1534 Hz も一致しない。

次へ ↓

⑤ 変えたら：ばね・管・音源・速さを変えると？

k = 2000 N/m なら、TB = 532 K、音速は 1360 m/s、f1 = 800 Hz になる。ドップラー音は 1532 Hz になり、管の振動数（800・1600・2400 Hz）とは合わないので、B では共鳴しない。hB = 0.40 m なら、TB = 709 K、音速は 1570 m/s、f1 = 920 Hz になる。ドップラー音は 1527 Hz になり、管の振動数（920・1840・2760 Hz）とは合わないので、やはり共鳴しない。

L = 1.70 m なら、300 K では f1 = 300 Hz、f4 = 1200 Hz になるので、A のドップラー音 1546 Hz は合わない。491 K では f1 = 383 Hz、f3 = 1150 Hz、f4 = 1534 Hz になり、B の音 1534 Hz は f4 と一致して、やはり共鳴する。

音源を 1400 Hz の音さに変えると、A ではドップラー音は 1448 Hz、B では 1438 Hz になり、管の振動数とは合わない。止まっているときは 1400 Hz のままで、A でも B でも共鳴しない。

ピストンの速さを 17 m/s にすると、A の音は 1519 Hz、B の音は 1514 Hz になり、管とは合わない。ピストンが止まっているとき（vs = 0）は、音は 1494 Hz のままで、A でも B でも共鳴しない。
