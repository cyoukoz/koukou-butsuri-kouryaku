第16問：熱サイクル・熱機関

問題：単原子分子の理想気体 n ≈ 0.040 mol が、p–V図の長方形のサイクルを1周する。A（1.0×105 Pa、1.0 L、300 K）→ D（3.0×105 Pa、1.0 L）→ C（3.0×105 Pa、3.0 L）→ B（1.0×105 Pa、3.0 L）→ A の順に進む。気体定数 R = 8.31 J/(mol・K)、単原子分子では定積モル比熱 CV = (3/2)R、定圧モル比熱 Cp = (5/2)R とする。各過程の仕事・内部エネルギーの変化・熱を求め、1サイクルの仕事と熱効率を求めよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。p–V図の長方形の面積が、1サイクルの仕事 400 J にぴったり等しい。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：p–V図の読み方

p–V図では、横が体積 V、縦が圧力 p だ。右へ進むほど体積が大きく、上がるほど圧力が高い。A は左下（1.0×105 Pa、1.0 L、300 K）で、サイクルは A → D → C → B → A の順に、時計回りに1周する。時計回りだから、気体は1サイクルで外に仕事をする。反時計回りなら、仕事は外から気体にされる（冷凍機の向きだ）。

まず角の温度を決める。等積変化では T は p に比例し、等圧変化では T は V に比例する。A が 300 K だから、D は p が 3 倍で 900 K、C は V が 3 倍で 2700 K、B は p が 1/3 で 900 K になる。温度は pV の比から出す。n の値から出すと、n ≈ 0.040 mol の計算が要るが、比で出すほうが間違えにくい。

次へ ↓ ①等積変化 A→D

① 等積変化 A→D（加熱）

体積が変わらないから、気体がする仕事は W = 0。温度は 300 K から 900 K へ上がるので、内部エネルギーの変化は ΔU = nCVΔT = 0.040 × (3/2) × 8.31 × 600 ≈ +300 J。熱力学第一法則 Q = ΔU + W より、吸収した熱は Q = +300 J。等積変化では、吸収した熱がそのまま内部エネルギーになる。


次へ ↓ ②等圧膨張 D→C

② 等圧膨張 D→C（加熱しながら膨らむ）

圧力 3.0×105 Pa のまま、体積が 1.0 L から 3.0 L へ増える。気体が外にした仕事は W = pΔV = 3.0×105 × 2.0×10−3 = +600 J。温度は 900 K から 2700 K へ上がるので、ΔU = nCVΔT ≈ +900 J。吸収した熱は Q = ΔU + W = +1500 J。等圧変化の熱は nCpΔT でも出る（0.040 × (5/2) × 8.31 × 1800 ≈ 1500 J）。ここで Cp と CV を取り違えると、Q が 600 J ずれる。膨張の仕事の分だけ、Cp のほうが大きい。


次へ ↓ ③等積変化 C→B

③ 等積変化 C→B（冷却）

体積が変わらないから W = 0。温度は 2700 K から 900 K へ下がるので、ΔU = nCVΔT ≈ −900 J。熱は Q = ΔU + W = −900 J。マイナスは、気体が外へ熱を放出したことを表す。吸収した熱だけを数えるときは、この 900 J は入れない。放出した熱は、効率の計算では Qout の側に入る。


次へ ↓ ④等圧圧縮 B→A

④ 等圧圧縮 B→A（押されて戻る）

圧力 1.0×105 Pa のまま、体積が 3.0 L から 1.0 L へ減る。気体が外にした仕事は W = pΔV = 1.0×105 × (−2.0×10−3) = −200 J。マイナスは、外が気体に仕事をしたことを表す。温度は 900 K から 300 K へ下がるので、ΔU ≈ −300 J。熱は Q = ΔU + W = −500 J（500 J 放出した）。

4つの過程を足すと、ΔU の和は 300 + 900 − 900 − 300 = 0（1周して元に戻るから当然）。仕事の和は 0 + 600 + 0 − 200 = +400 J。これが p–V図の長方形の面積だ。図で中が塗られている部分が、そのまま 400 J になる。


次へ ↓ ⑤熱効率

⑤ 熱効率 η = W / Qin

吸収した熱は、プラスの Q だけを足す。Qin = 300 + 1500 = 1800 J。放出した熱は Qout = 900 + 500 = 1400 J。1800 − 1400 = 400 で、仕事と一致する（エネルギー保存）。熱効率は η = W / Qin = 400 / 1800 ≈ 22%。

同じ最高温度 2700 K と最低温度 300 K のあいだで動くカルノー機関の効率は、1 − 300/2700 ≈ 89% だ。この長方形のサイクルは 22% しかない。効率の分母は「吸収した熱の合計」であって、「吸収した熱 − 放出した熱」ではない。Qin を 400 J とすると、効率が 100% になってしまう。ここがこの問題の中心の罠だ。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：A→D は Q = +300 J、D→C は W = +600 J・Q = +1500 J、C→B は Q = −900 J、B→A は W = −200 J・Q = −500 J。1サイクルの仕事は +400 J、吸収した熱は 1800 J、効率は約 22%（カルノー効率は約 89%）。状態方程式と熱力学第一法則の使い方は 第7問：気体＋ピストン でも確かめられる。
