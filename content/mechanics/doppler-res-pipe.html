組み合わせ問題BP：ドップラー効果＋開管の共鳴＋気体の音速

長さ L = 0.85 m の開管があり、中の空気は 300 K で、音速は 340 m/s である。この管に向かって、900 Hz の音さ（おんさ）をのせた台車が 34 m/s で近づいている。音さの振動数は、台車が止まっているときの値である。音速は 340 m/s とする。

(1) 開管の振動数を求め、音さが静止したままでは共鳴しないことを確かめよ。(2) 近づくときの音の高さを求め、共鳴するかどうかを確かめよ。(3) 管を 600 K に熱したとき、共鳴するかどうかを確かめよ。(4) 罠と変えたら。

はじめに：どう切り分けるか

場面考えること使うモデル
開管の振動数f_n = n·v/(2L)気柱の共鳴
ドップラー効果近づくと音が高くなるドップラー効果
気体の音速音速は √T に比例気体の状態方程式
共鳴音の高さと管の振動数が一致する共鳴

この問題の橋渡しの量は振動数だ。音さの振動数はドップラーで変わり、管の振動数は気体の温度で変わる。2つが一致すると共鳴する。

次へ ↓

① 開管の振動数：f1=200 Hz、f5=1000 Hz、音さの 900 Hz は合わない

開管の振動数は f_n = n·v/(2L) だ。v = 340 m/s、L = 0.85 m なので、f1 = 340/(2 × 0.85) = 200 Hz になる。f2 = 400 Hz、f3 = 600 Hz、f4 = 800 Hz、f5 = 1000 Hz、f6 = 1200 Hz だ。

音さの 900 Hz は、f4 = 800 Hz と f5 = 1000 Hz のあいだで、どの振動数とも一致しない。台車が止まったままでは、音さの音は管と共鳴しない。

次へ ↓

② 近づく音さ：1000 Hz、f5 と一致して共鳴する

音源が観測者に近づくとき、観測される音は f′ = f0·V/(V − vs) になる。f0 = 900 Hz、vs = 34 m/s なので、f′ = 900 × 340/(340 − 34) = 900 × 340/306 = 1000 Hz になる。ちょうど f5 = 1000 Hz と一致するので、管は大きく鳴る（共鳴する）。

波長は λ′ = V/f′ = 340/1000 = 0.34 m になる。静止しているときの波長 0.38 m の 0.90 倍だ。台車が遠ざかると、f′ = 900 × 340/(340 + 34) ≈ 818 Hz になり、どの振動数とも一致しないので共鳴しない。

次へ ↓

③ 管を 600 K に熱す：音速 481 m/s、1000 Hz は合わなくなる

気体の音速は、絶対温度の平方根に比例する。v = √(γRT/M) なので、温度が 2 倍になると音速は √2 倍になる。600 K では v = 340 × √(600/300) = 340 × √2 ≈ 481 m/s になる。

管の振動数も変わる。f1 = 481/(2 × 0.85) ≈ 283 Hz になり、f2 = 566 Hz、f3 = 849 Hz、f4 = 1131 Hz、f5 = 1414 Hz、f6 = 1697 Hz になる。近づく音さの 1000 Hz は、f3 = 849 Hz と f4 = 1131 Hz のあいだで、共鳴しなくなる。

600 K で共鳴させるには、f3 = 849 Hz に合う音さが要る。近づくとき 849 Hz になる音さは、f0 = 849 × (481 − 34)/481 ≈ 789 Hz だ。

次へ ↓

④ 罠：音さの 900 Hz は共鳴しない／閉管では共鳴する

罠：「音さの 900 Hz が管と共鳴する」——まちがい。共鳴するのは、ドップラーで変わった 1000 Hz だ。音源の振動数（900 Hz）と観測される音の高さ（1000 Hz）を取り違えない。音さが静止したままでは、900 Hz はどの振動数とも一致しない。

罠：「管を熱すると共鳴しやすくなる」——まちがい。熱すると音速が上がり、管の振動数は上がる。1000 Hz は f3 と f4 のあいだに入ってしまい、共鳴しなくなる。温度を変えると共鳴の条件も変わる。

罠：「閉管でも同じ」——まちがい。閉管（L = 0.85 m）では f_n = (2n−1)v/4L = (2n−1) × 100 Hz で、f5 = 900 Hz になる。音さの 900 Hz は、閉管では静止したまま共鳴する。近づいた 1000 Hz は 100 Hz の偶数倍で、閉管の振動数にはないので共鳴しない。開管と閉管で振動数の並びがちがう。

次へ ↓

⑤ 変えたら：L・vs で共鳴するかどうかが変わる

L = 1.70 m の開管なら、f1 = 100 Hz になり、f10 = 1000 Hz になる。近づく音さの 1000 Hz は f10 と一致して共鳴する。管が長くなると振動数が細かくなるので、1000 Hz に合う次数が増える。

vs = 85 m/s で近づくと、f′ = 900 × 340/(340 − 85) = 1200 Hz になる。f6 = 1200 Hz と一致して共鳴する。vs = 17 m/s なら、f′ = 900 × 340/(340 − 17) ≈ 947 Hz になり、どの振動数とも一致しないので共鳴しない。

まとめ（答え）

(1) 開管は 200・400・600・800・1000・1200 Hz、900 Hz は合わない。(2) 近づくと 1000 Hz で f5 と一致して共鳴する。遠ざかると 818 Hz で共鳴しない。(3) 600 K では音速 481 m/s、f1=283 Hz、1000 Hz は合わない。(4) 音さの 900 Hz そのものは共鳴しない。閉管では 900 Hz が f5 と一致する。
