第8問：ヤングの干渉

問題：波長 λ = 600 nm の光を、間隔 d = 0.20 mm の二重スリットにあてる。スリットからスクリーンまでの距離は L = 1.0 m である。スクリーンにできる明線の間隔を求めよ。また、中央から 3 番目の明線の位置と、その点での 2 つの光の光路差を求めよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。2 本の光路の長さは三平方の定理から計算され、光路差の目印も計算で打たれている。ラベルは短い名前だけにして、枠からはみ出さないよう描画側で調整している。

はじめに：装置を見る

光源から出た光は、二重スリットの 2 つのすき間を通って、スクリーンに届く。2 つのすき間は、波長が同じ 2 つの新しい光源だと思えばよい。スクリーンには明るい縞と暗い縞が交互に並ぶ。

図はこれだけ。ここから下へ、1つずつ確かめていく。

次へ ↓ ①明るい縞の条件

① 明るい縞の条件（光路差 = nλ）

スクリーン上の 1 点に、2 つのすき間から光が届く。2 つの光路の長さの差（光路差）が、波長の整数倍 nλ のとき、2 つの波は山と山が重なって強め合い、明るくなる。図の赤い目印が光路差で、n = 3 の点では光路差は 3λ になっている。光路差そのものではなく、光路差が波長の何倍かが決め手だ。


次へ ↓ ②縞間隔

② 縞間隔 Δx = λL / d

光路差は、スクリーン上の位置 x を使うと d・x / L と書ける（x が L よりずっと小さいときの近似）。これが nλ に等しいとすると、n 番目の明線の位置は x = nλL / d。隣り合う明線の間隔は Δx = λL / d = 600×10−9 × 1.0 / 0.20×10−3 = 3.0×10−3 m（3.0 mm）。図のスクリーン上の赤い目印は 3.0 mm ごとに並んでいる。


次へ ↓ ③n=3 の明線

③ n = 3 の明線の位置と光路差

中央から 3 番目の明線の位置は x = 3Δx = 9.0 mm。その点での光路差は d・x / L = 0.20×10−3 × 9.0×10−3 / 1.0 = 1.8×10−6 m = 3λ。n = 3 だから光路差は 3λ で、条件と一致する。図では、上の光路（約 212px）と下の光路（約 228px）の差が光路差だ。


次へ ↓ ④暗い縞の条件

④ 暗い縞の条件（光路差 = (n + 1/2)λ）

光路差が波長の半端な倍数 (n + 1/2)λ のとき、2 つの波は山と谷が重なって打ち消し合い、暗くなる。中央に一番近い暗線は、光路差が λ/2 の点で、位置は x = (1/2)Δx = 1.5 mm。明線と暗線の条件を取り違えないこと。暗線も明線と同じ間隔（3.0 mm）で並ぶ。


次へ ↓ ⑤波長が変わると

⑤ 波長が変わるとどうなるか

縞間隔 Δx = λL / d は、波長 λ に比例する。λ が 2 倍になれば縞間隔も 2 倍、λ が小さくなれば縞間隔も狭くなる。だから赤い光（λ が大きい）のほうが青い光より縞が広い。d を大きくしたり L を短くしたりすると、縞間隔は逆に狭くなる。式を丸暗記するのではなく、λ・L・d のどれが分子でどれが分母かを見て判断しよう。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：縞間隔 Δx = 3.0 mm、n = 3 の明線は x = 9.0 mm、光路差は 3λ。暗線の条件は光路差 = (n + 1/2)λ。
