組み合わせ問題N：レール＋コンデンサ＋コイル

問題：幅 L = 1.0 m の 2 本のレールの上に、質量 m = 0.50 kg の棒を置いた。レールの端にはコンデンサ C = 0.50 F がつながっている。レールの面に垂直に B = 1.0 T の磁場（裏向き）がかかっている。棒を速さ v0 = 2.0 m/s ですべらせると、コンデンサが充電されながら棒は遅くなる。レールと棒の抵抗は無視できるものとする。(1) 棒がコンデンサを充電しながらすべり、充電が終わったあとの棒の速さと、コンデンサにたまった電荷とエネルギーを求めよ。(2) 充電が終わったあと、スイッチを切り替えてコンデンサをコイル L = 0.50 H につなぐ。LC 振動の角振動数・周期・最大電流を求めよ。(3) スイッチを切り替えてから T/4 のとき、コンデンサの電荷と回路の電流はどうなっているか。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v2.0、railCapCoil 型）が下の JSON データから計算して描く。速度の矢印は 30 px/(m/s)（v0 = 2.0 m/s は 60 px、v1 = 1.0 m/s は 30 px）、電流の矢印は方向だけの固定長 60 px。エネルギーの棒グラフの長さは 150 px/J で決める。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。棒がすべってコンデンサを充電する場面では力積と電荷、スイッチを切り替えたあとでは LC 振動を使う。2つをつなぐのは、コンデンサにたまった電荷だ。

すべりはじめ棒＋レール＋コンデンサ—誘導起電力 ε0 = BLv0 = 2.0 V（はじめに）
充電しながらすべる棒＋コンデンサ電荷 Q力積で v1 = 1.0 m/s、Q = 0.50 C、U = 0.25 J（ステップ①）

棒が遅くなるのは、充電電流が磁場から受ける力が、すべる向きと反対だからだ。充電が終わると電流は止まり、棒は一定の速さですべり続ける。充電の瞬間には電流が流れて熱が出るので、エネルギーは保存されない。速さを求めるには、力積を使う。

幅 1.0 m のレール、裏向きの磁場 1.0 T、質量 0.50 kg の棒、コンデンサ 0.50 F。棒が速さ 2.0 m/s ですべると、棒の両端に誘導起電力が生まれ、コンデンサが充電される。ここから下へ、1つずつ確かめていく。

次へ ↓ ①力積で充電後の速さを求める

① 力積で充電後の速さを求める

棒が磁場の中をすべると、棒の中の電荷がローレンツ力を受け、棒の上端が ＋、下端が − になる。棒の両端の電位差（誘導起電力）は ε = BLv だ。はじめは ε0 = 1.0 × 1.0 × 2.0 = 2.0 V ある。

棒が遅くなる理由は、充電電流 I が磁場から受ける力 F = BIL が、すべる向きと反対だからだ。棒の運動量の変化は、この力の力積に等しい。力積は ∫BIL dt = BL∫I dt = BLQ（Q は充電で流れた電荷）なので、m(v1 − v0) = −BLQ が成り立つ。

充電が終わると電流は止まる。棒の両端の電位差とコンデンサの電圧が等しくなるので、Q = C × BLv1 だ。2つの式から v1 を求めると、v1 = mv0/(m + B²L²C) になる。B²L²C = 1.0 × 1.0 × 0.50 = 0.50 kg は、コンデンサが棒にくっついてきたときの「効き目の質量」だ。v1 = 0.50 × 2.0 / (0.50 + 0.50) = 1.0 m/s になる。

電荷は Q = CBLv1 = 0.50 × 1.0 × 1.0 × 1.0 = 0.50 C、コンデンサのエネルギーは U = Q²/(2C) = 0.25 / 1.0 = 0.25 J になる。


次へ ↓ ②スイッチを切り替えて LC 振動

② スイッチを切り替えて LC 振動

充電が終わったあと、スイッチを切り替えてコンデンサをコイル L = 0.50 H につなぐ。コンデンサの電荷がコイルに流れ、電流が流れると、今度はコイルが電流を保とうとしてコンデンサを逆向きに充電する。電荷と電流が、ばねの変位と速度のように振動する。

角振動数は ω = 1/√(LC) = 1/√(0.50 × 0.50) = 1/0.50 = 2.0 rad/s。周期は T = 2π/ω = 2 × 3.14 / 2.0 ≈ 3.14 s、振動数は f = 1/T ≈ 0.32 Hz だ。

最大電流は I0 = Q0ω = 0.50 × 2.0 = 1.0 A。コイルのエネルギーの最大値は (1/2)LI0² = 0.5 × 0.50 × 1.0² = 0.25 J で、コンデンサのエネルギー 0.25 J とぴったり一致する。エネルギーは、コンデンサとコイルのあいだを行き来するだけだ。


次へ ↓ ③q と i の時間変化

③ q と i の時間変化

スイッチを切り替えた瞬間を t = 0 とすると、電荷は q(t) = Q0 cos ωt、電流は i(t) = −I0 sin ωt で変化する。t = 0 では q = 0.50 C（最大）、i = 0 だ。

(3) T/4 ≈ 3.14/4 ≈ 0.79 s のとき、ωt = π/2 になるので、q = 0.50 × cos(π/2) = 0、i = −1.0 × sin(π/2) = −1.0 A になる。電荷が 0 になる瞬間に、電流は最大になる。コンデンサのエネルギーが 0 になり、エネルギーはすべてコイルにある。

T/2 ≈ 1.57 s では q = −0.50 C（極板の ＋− が入れ替わる）、i = 0 になる。T ≈ 3.14 s で、はじめの状態に戻る。


次へ ↓ ④罠：エネルギー保存だけでは求まらない

④ 罠：エネルギー保存だけでは求まらない

ステップ①で、エネルギー保存だけを使って速さを求めるとどうなるか。充電後のエネルギー保存は、(1/2)mv1² + (1/2)CB²L²v1² = (1/2)mv0² だ。これを解くと v1 = v0/√(1 + B²L²C/m) = 2.0/√2 ≈ 1.41 m/s になってしまう。正しい答えは 1.0 m/s だ。

なぜまちがうのか。充電の瞬間には電流が流れて、ジュール熱が出るからだ。はじめの運動エネルギーは (1/2)mv0² = 0.5 × 0.50 × 4.0 = 1.0 J。あとに残るのは、運動エネルギー (1/2)mv1² = 0.25 J と静電エネルギー 0.25 J の合計 0.50 J だけだ。残りの 0.50 J は、充電のときに流れた電流のジュール熱になっている。エネルギーは保存されないので、エネルギー保存では v1 は求まらない。力積 BLQ を使うのが正しい。


次へ ↓ ⑤まとめ・罠の確認

⑤ まとめ・罠の確認

この問題の罠は、充電の場面でエネルギー保存を使ってしまうことだ。充電の瞬間には電流が流れてジュール熱が出るので、エネルギーは保存されない。速さを求めるには、棒の運動量の変化と電荷を結ぶ力積 BLQ を使う。充電が終わったあとの LC 振動では、抵抗がないのでエネルギーは保存され、コンデンサとコイルのあいだを行き来するだけだ。

切り分けはこうだ。充電の場面では力積で速さと電荷を求め、スイッチを切り替えたあとでは、電荷 Q0 = 0.50 C が橋渡し量になって、LC 振動の角振動数・周期・最大電流が決まる。充電後の速さ 1.0 m/s、電荷 0.50 C、角振動数 2.0 rad/s、周期 約 3.14 s、最大電流 1.0 A は、セットで覚えよう。

答え：(1) 充電後の速さ v1 = 1.0 m/s、電荷 Q = 0.50 C、エネルギー U = 0.25 J。(2) 角振動数 ω = 2.0 rad/s、周期 T ≈ 3.14 s、最大電流 I0 = 1.0 A。(3) T/4 ≈ 0.79 s で q = 0、i = −1.0 A（大きさは最大）。もとになった単体モデル：レール上の棒は 第17問：レール＋棒、コンデンサは 第9問：コンデンサ、LC 振動は 組み合わせ問題D：LC＋単振動、誘導起電力は 第32問：電磁誘導 で確かめられる。
