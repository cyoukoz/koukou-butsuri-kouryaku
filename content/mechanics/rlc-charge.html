組み合わせ問題AR：RLC回路の過渡応答

起電力 12 V の電池に、抵抗 20 Ω、コイル 0.10 H、コンデンサ 100 μF を直列につなぎ、スイッチを入れる。(1) 振動の角振動数と周期、減衰のようすを求めよ。(2) 電流 i(t) を求め、最大になる時刻と値を求めよ。(3) 電気量 q(t) を求め、最大になる時刻と値、コンデンサの最大電圧を求めよ。(4) コンデンサの電圧は電池の 12 V をこえない、電流は最初が最大だとするとどうなるか。(5) R を 0 にする、R を 100 Ω にするとどうなるか。

はじめに：どう切り分けるか

条件 → 電流 → 電気量 → 罠 → 変えたら、の順に区切る。橋渡し量は「電気量と電流」だ。

いつ何が起きるか橋渡し量どこで解くか
はじめ不足減衰の条件ω0=316 rad/s、α=100 /sステップ①
流れる電流最大 0.25 A（4.2 ms）ステップ②
たまる電気量最大 1.62 mC（10.5 ms）ステップ③
罠・変えたら電圧の行き過ぎVc は 16 V まで行くステップ④⑤

図：電池・抵抗・コイル・コンデンサの直列回路。コイルがあると、電気量は振動しながらたまっていく。

ステップ① 不足減衰の条件

固有角振動数は ω0 = 1/√(LC) = 1/√(0.10×100×10⁻⁶) ≈ 316 rad/s。減衰率は α = R/(2L) = 20/(2×0.10) = 100 /s。

α = 100 /s が ω0 = 316 rad/s より小さいので、不足減衰になる。振動の角振動数は ω' = √(ω0² − α²) = √(316² − 100²) = 300 rad/s で、周期は T' = 2π/ω' ≈ 21 ms。

振幅は e^(−αt) で減っていく。1周期後には e^(−100×0.021) ≈ 0.12 倍、5周期後にはほぼ 0 になる。

次へ ↓

ステップ② 電流 i(t)

電流は i(t) = (E/(Lω')) e^(−αt) sin(ω't) = 0.40 e^(−100t) sin(300t) A で表せる。t=0 では sin 0 = 0 なので、i(0) = 0。コイルが電流の急な変化をさまたげるからだ。

電流が最大になるのは、tan(ω't) = ω'/α = 3 のときで、ω't ≈ 1.25 rad、t ≈ 4.2 ms。そのとき i ≈ 0.25 A になる。

そのあと電流は振動しながら 0 に近づく。14.6 ms では −0.088 A まで逆向きに流れる。

次へ ↓

ステップ③ 電気量 q(t) とエネルギー

電気量は q(t) = Q∞[1 − e^(−αt)(cos ω't + (α/ω') sin ω't)] で増える。最終の電気量は Q∞ = CE = 1.2 mC。

電気量が最大になるのは、電流が 0 になるとき、つまり ω't = π、t ≈ 10.5 ms。そのとき q ≈ 1.62 mC で、最終値の 1.2 mC をこえて行き過ぎる。コンデンサの電圧は Vc = q/C ≈ 16 V になり、電池の 12 V をこえる。

そのとき、コンデンサにたまるエネルギーは U = ½q²/C ≈ 13 mJ、電池の仕事は W = Eq ≈ 19 mJ、ジュール熱は 19 − 13 = 6.3 mJ。やがて q は 1.2 mC に落ち着き、U∞ = 7.2 mJ、電池の仕事は 14.4 mJ、熱は 7.2 mJ になる。熱の合計は、抵抗だけの回路（AP）とちょうど同じだ。

次へ ↓

ステップ④ 罠：電圧は電池をこえない、電流は最初が最大

「コンデンサの電圧は電池の 12 V をこえない」はまちがい。コイルの慣性で電気が行き過ぎ、Vc は 16 V まで行く。R=0 なら 24 V まで行く。

「電流は最初が最大」もまちがい。RC だけの回路（AP）なら、初めの電流は I0 = E/R = 120 mA で最大だが、コイルがあると i(0) = 0 から始まり、4.2 ms で 0.25 A になる。

「抵抗を大きくするとジュール熱の合計が増える」もまちがい。熱の合計は W − U∞ = 7.2 mJ で、R の値では決まらない。R が大きいと、熱が出るのが速くなるだけだ。

次へ ↓

ステップ⑤ 変えたら

R を 0 にすると、α = 0 になって減衰がなくなり、振動がずっと続く。周期は T = 2π/ω0 ≈ 20 ms、電気量は 0 から 2.4 mC まで振動し、電圧は 0 から 24 V まで振動する。最大電流は 0.38 A になる。

R を 100 Ω にすると、α = 500 /s が ω0 = 316 rad/s をこえて過減衰になり、振動しなくなる。電気量はゆっくり 1.2 mC に近づき、95% まで約 28 ms かかる。

ちょうど振動するかしないかの境目は、臨界減衰 R = 2√(L/C) ≈ 63 Ω だ。

5つのチェックをすべて入れると完了になります。

答え：ω0≈316 rad/s、α=100 /s、ω'=300 rad/s、T'≈21 ms、最大電流 0.25 A（4.2 ms）、電気量の最大 1.62 mC（10.5 ms）、コンデンサの最大電圧 16 V、U∞=7.2 mJ、電池の仕事 14.4 mJ、ジュール熱 7.2 mJ。コンデンサは第9問：コンデンサ、過渡現象は第30問：RL・RC回路の過渡現象、LC振動は組み合わせ問題D：LC回路＋単振動、抵抗だけの充電は組み合わせ問題AP：RC回路の充電とエネルギーに戻って確認しよう。
