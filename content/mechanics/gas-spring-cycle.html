組み合わせ問題P：気体＋ピストン＋ばね＋サイクル

問題：縦のシリンダーに、面積 S = 0.010 m²、質量 m = 10 kg のピストンが入っている。ピストンの上にはばね（ばね定数 k = 1000 N/m）があり、ピストンの高さ h = 0.20 m のときにばねは自然長だ。ピストンの上は大気圧 p0 = 1.0×10⁵ Pa、シリンダーの中にはヘリウム（単原子気体）が入っている。状態Aでは h = 0.20 m、T = 300 K だ。(1) 加熱してピストンを h = 0.30 m まで上げた（状態B）。pB、TB、仕事・内部エネルギーの変化・吸熱を求めよ。(2) ピストンを固定して 300 K まで冷やした（状態C）。pC、仕事・内部エネルギーの変化・熱を求めよ。(3) ピストンを手で支えながらゆっくり戻し、冷やして T = 300 K に保ちながら状態Aに戻した。仕事・内部エネルギーの変化・熱と、サイクル全体の正味の仕事・効率を求めよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v2.1、gasSpringCycle 型）が下の JSON データから計算して描く。力の矢印は 20 N/px（気体の力 1100 N は 55 px、大気圧 1000 N は 50 px、重力・ばね 100 N は 5 px）、ピストン高さは 400 px/m で決める。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。加熱でピストンが上がる場面、ピストンを固定して冷やす場面、等温で戻す場面では、使える式がちがう。3つをつなぐのは、気体の圧力と体積だ。

時間系（何を見るか）橋渡し量この場面で解くこと
はじめ（状態A）気体＋ピストン＋ばね—力のつり合いから p = 1.10×10⁵ Pa（はじめに）
A→B：加熱気体＋ピストン＋ばね圧力 p・体積 Vばねが縮むので p も上がる。W=115 J、Q=325 J（ステップ①）
B→C：固定して冷却気体（ピストンは固定）体積 V = 3.0 LW=0、p=0.73×10⁵ Pa まで下がる（ステップ②）

ピストンの力のつり合いは、pS = p0S + mg + k(h − 0.20 m) だ。ピストンが上がるとばねが縮み、気体の圧力は上がる。だから加熱は等圧変化ではない。ここがこの問題の中心だ。

状態Aでは、ばねは自然長で力は 0 だ。気体の力は pS = 1.10×10⁵ × 0.010 = 1100 N、大気圧の力は 1000 N、重力は mg = 100 N で、1100 = 1000 + 100 とつり合う。ここから下へ、1つずつ確かめていく。

次へ ↓ ①A→B：加熱してピストンが上がる

① A→B：加熱してピストンが上がる

状態Bでは、ピストンは h = 0.30 m まで上がり、ばねは 0.10 m 縮む。ばねの力は k × 0.10 = 1000 × 0.10 = 100 N だ。力のつり合いから、気体の圧力は pB = p0 + mg/S + k(h − 0.20)/S = 1.0×10⁵ + 100/0.010 + 100/0.010 = 1.0×10⁵ + 1.0×10⁴ + 1.0×10⁴ = 1.20×10⁵ Pa になる。体積は VB = 0.010 × 0.30 = 3.0 L だ。

状態Aの pV/T から、nR = pAVA/TA = 1.10×10⁵ × 0.0020 / 300 = 0.733 J/K（物質量 n ≈ 0.088 mol）。状態Bの温度は TB = pBVB/nR = 1.20×10⁵ × 0.0030 / 0.733 = 360 / 0.733 ≈ 491 K になる。

仕事は p–V 図の面積だ。A→B では圧力が 1.10×10⁵ Pa から 1.20×10⁵ Pa まで直線で上がるので、仕事は台形の面積 W = (1.10×10⁵ + 1.20×10⁵)/2 × (0.0030 − 0.0020) = 1.15×10⁵ × 0.0010 = 115 J になる。内部エネルギーの増加は、ヘリウムは単原子気体なので ΔU = (3/2)nRΔT = 1.5 × 0.733 × (491 − 300) = 1.5 × 0.733 × 191 ≈ 210 J。吸熱は Q = ΔU + W = 210 + 115 = 325 J だ。


次へ ↓ ②B→C：ピストンを固定して冷やす

② B→C：ピストンを固定して冷やす

ピストンを h = 0.30 m の位置で固定し、300 K まで冷やす。体積は V = 3.0 L のまま変わらないので、圧力は pC = nRT/V = 0.733 × 300 / 0.0030 = 220 / 0.0030 ≈ 0.733×10⁵ Pa まで下がる。大気圧 1.0×10⁵ Pa よりも低い。だからピストンは留め具で固定しておかないと、大気に押されて下がってしまう。

体積が変わらないので、気体のする仕事は W = 0 だ。内部エネルギーの変化は ΔU = (3/2)nRΔT = 1.5 × 0.733 × (300 − 491) = 1.5 × 0.733 × (−191) ≈ −210 J。熱は Q = ΔU + W = −210 J で、210 J の熱を出したことになる。ステップ①で増えた内部エネルギー 210 J が、ちょうどここで戻る。

この場面の力のつり合いに注意しよう。気体の力は pCS = 0.733×10⁵ × 0.010 ≈ 733 N まで下がったのに、大気圧の力 1000 N、重力 100 N、ばねの力 100 N の和は 1200 N のままだ。差の 467 N は留め具が支えている。ピストンが固定されている場面では、力のつり合いは成り立たない。


次へ ↓ ③C→A：等温圧縮で戻る

③ C→A：等温圧縮で戻る

留め具を外し、ピストンを手で支えながらゆっくり戻す。冷やして温度を 300 K に保つので、これは等温変化だ。体積は 3.0 L から 2.0 L まで減り、圧力は p = nRT/V = 220/V で上がっていく。V = 2.0 L では p = 220/0.0020 = 1.10×10⁵ Pa で、ちょうど状態Aに戻る。

等温変化の仕事は W = nRT ln(VA/VC) = 0.733 × 300 × ln(2.0/3.0) = 220 × ln(2/3) = 220 × (−0.405) ≈ −89.2 J だ。負の仕事は、気体が圧縮された（外から仕事をされた）ことを表す。等温変化なので内部エネルギーの変化は ΔU = 0、熱は Q = ΔU + W = −89.2 J で、89.2 J の熱を出したことになる。

サイクル全体の正味の仕事は、W = 115 + 0 + (−89.2) = 25.8 J だ。吸熱は A→B の 325 J だけなので、効率は η = 25.8 / 325 ≈ 7.9% になる。熱の合計も確かめよう。Q = 325 − 210 − 89.2 = 25.8 J で、正味の仕事とぴったり一致する。サイクルでは、吸った熱と出した熱の差が、正味の仕事になる。


次へ ↓ ④罠：正味の仕事と効率

④ 罠：正味の仕事と効率

p–V 図を描くと、サイクルは A→B（右上がりの直線）、B→C（下向きの垂直線）、C→A（等温線の曲線）の 3 本で囲まれる。囲まれた面積が正味の仕事 25.8 J だ。A→B の台形の面積 115 J から、C→A の等温線の下の面積 89.2 J を引いたものが、囲まれた面積になる。

罠は 3 つある。1 つ目は、A→B を等圧変化だと思い込むことだ。ばねが縮むので圧力は 1.10×10⁵ Pa から 1.20×10⁵ Pa まで上がる。pA × ΔV = 110 J はまちがいで、正しくは台形の面積 115 J だ。2 つ目は、B→C で「圧力が下がったから仕事がある」と思うことだ。体積が変わらなければ仕事は 0 だ。3 つ目は、効率の分母に正味の熱（25.8 J）や吸熱と放熱の合計を使ってしまうことだ。効率は「正味の仕事 / 吸熱」で、吸熱は A→B の 325 J だけだ。放熱（210 J と 89.2 J）は分母に入らない。


次へ ↓ ⑤まとめ・罠の確認

⑤ まとめ・罠の確認

この問題の橋渡し量は圧力 p と体積 V だ。ピストンの力のつり合い p(h) = p0 + mg/S + k(h − 0.20)/S が、p と V の関係を決める。A→B は加熱で p も V も上がり、W = 115 J、Q = 325 J。B→C は体積一定で W = 0、Q = −210 J。C→A は等温圧縮で W = −89.2 J、ΔU = 0、Q = −89.2 J。正味の仕事 25.8 J、効率 約 7.9% だ。

切り分けの要は、場面ごとに「何が一定か」を確かめることだ。A→B では何も一定ではない（p も V も T も変わる）。B→C では V が一定、C→A では T が一定だ。何が一定かをまちがえると、仕事も内部エネルギーも熱も、全部まちがう。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) pB = 1.20×10⁵ Pa、TB ≈ 491 K、W = 115 J、ΔU = 210 J、Q = 325 J。(2) pC ≈ 0.733×10⁵ Pa、W = 0、ΔU = −210 J、Q = −210 J。(3) W = −89.2 J、ΔU = 0、Q = −89.2 J、正味の仕事 25.8 J、効率 約 7.9%。もとになった単体モデル：気体＋ピストンは 第7問：気体＋ピストン、熱サイクルは 第16問：熱サイクル・熱機関、ばねは 第5問：ばねのつり合い、内部エネルギーは 第22問：分子運動論 で確かめられる。
