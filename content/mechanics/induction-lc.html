組み合わせ問題L：誘導＋LC回路

問題：100 回巻き、面積 S = 0.010 m² のコイルに、電気容量 C = 100 μF のコンデンサをつなぐ。コイルを貫く磁場 B（裏向き）が、0 から 0.40 T まで 0.20 s かけて一様に増えた。(1) この間に生じる誘導起電力と、コンデンサにたまる電荷・エネルギーを求めよ。(2) 磁場が増え終わったあと、コンデンサをコイル L = 0.10 H だけの回路につなぎかえた。電荷と電流はどのように時間変化するか。周期と最大電流を求めよ。(3) コンデンサの電荷が初めて 0 になるのは、つなぎかえてから何 s 後か。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v1.9、inductionLC 型）が下の JSON データから計算して描く。電流の矢印は方向だけの固定長 60 px で、電流の大きさは数字で示す。q–t グラフと i–t グラフは q(t) = Q cos ωt、i(t) = −I₀ sin ωt から計算して描く。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。磁場が増えている間は電磁誘導だけ、増え終わったあとは LC 振動だけを使う。場面をつなぐのは、コンデンサにたまった電荷だ。

時間系（どの回路か）橋渡し量この場面で解くこと
磁場が増える間（0 → 0.20 s）コイル＋コンデンサ—誘導起電力 V = 2.0 V（ステップ①）
磁場が増え終わったときコンデンサ電荷 Q = 200 μCためた電荷とエネルギー U = 0.20 mJ（ステップ①）
つなぎかえたあとコンデンサ＋コイル（LC 回路）電荷 Q = 200 μCLC 振動：周期 約 0.020 s、最大電流 約 63 mA（ステップ②）

磁場が増えている間だけ誘導起電力が生まれ、コンデンサが充電される。磁場が増え終わると誘導起電力は 0 になり、コンデンサにたまった電荷が LC 振動のスタートになる。2つの場面で使う法則はまったく違う。

コイルを貫く磁場（裏向き）が増えると、誘導電流が流れる。向きは、増える磁場を打ち消す向き（レンツの法則）だ。ここから下へ、1本ずつ足していく。

次へ ↓ ①コンデンサに電荷をためる

① コンデンサに電荷をためる

1回巻きあたりの磁束の変化は、ΔΦ = ΔB × S = 0.40 × 0.010 = 4.0×10⁻³ Wb。100 回巻きのコイル全体では、ファラデーの法則から誘導起電力は V = NΔΦ/Δt = 100 × 4.0×10⁻³ / 0.20 = 2.0 V。磁場が増える速さ ΔB/Δt = 2.0 T/s が、そのまま起電力の大きさを決める。

この起電力でコンデンサが充電される。たまる電荷は Q = CV = 100×10⁻⁶ × 2.0 = 200 μC。ためたエネルギーは U = (1/2)CV² = (1/2) × 100×10⁻⁶ × 4.0 = 0.20 mJ。電荷が橋渡し量になって、次の場面（LC 振動）へ渡される。


次へ ↓ ②スイッチを切り替えて LC 振動

② スイッチを切り替えて LC 振動

磁場が増え終わったあと、コンデンサをコイルだけの回路につなぎかえる。コンデンサの電荷がコイルに流れ、コイルに電流が流れると、今度はコイルが電流の変化を妨げる（自己誘導）。電荷と電流が行き来して、振動がはじまる。

LC 回路の角振動数は ω = 1/√(LC) = 1/√(0.10 × 100×10⁻⁶) = 1/√(1.0×10⁻⁵) ≈ 316 rad/s。周期は T = 2π/ω ≈ 0.020 s、振動数は f = 1/T ≈ 50 Hz。最大電流は、エネルギー保存 (1/2)LI₀² = (1/2)CV² から、I₀ = V√(C/L) = 2.0 × √(100×10⁻⁶ / 0.10) = 2.0 × 0.0316 ≈ 63 mA。コイルのエネルギー (1/2)LI₀² = 0.20 mJ は、コンデンサのエネルギーとぴったり一致する。

この ω は、ばねの単振動 ω = √(k/m) と同じ形をしている。コンデンサの電荷 Q がばねの変位 x、コイルのインダクタンス L が質量 m、1/C がばね定数 k に対応する（組み合わせ問題D：LC＋単振動も見てみよう）。


次へ ↓ ③q と i の時間変化

③ q と i の時間変化

つなぎかえた瞬間を t = 0 とすると、電荷は q(t) = Q cos ωt、電流は i(t) = −I₀ sin ωt と時間変化する。t = 0 では q = 200 μC（最大）、i = 0。電荷が減りはじめると電流が流れ、T/4 ≈ 0.0050 s 後には q = 0 になり、電流が最大の 63 mA になる。エネルギーは、コンデンサの (1/2)q²/C からコイルの (1/2)Li² へ移っている。

T/2 ≈ 0.010 s 後には q = −200 μC（極板の ＋− が逆転）、T ≈ 0.020 s 後に q = 200 μC に戻る。q と i のグラフは、位相が π/2（T/4）ずれている。ばねの単振動で、変位と速度のグラフが π/2 ずれているのと同じだ。


次へ ↓ ④罠：磁場が変わらなくなると V=0

④ 罠：磁場が変わらなくなると V=0

誘導起電力は、磁場の大きさではなく磁場の変わる速さ ΔΦ/Δt で決まる。B が 0.40 T のまま変わらなくなると、ΔΦ/Δt = 0 になり、誘導起電力は 0 V になる。B が大きくても、変わらなければ起電力は生まれない。

逆に、同じ 0.40 T まで 0.10 s（半分の時間）で増やすと、ΔΦ/Δt は 2 倍になり、V = 4.0 V、たまる電荷も Q = 400 μC になる。起電力は「どれだけ増えたか」ではなく「どれだけ速く増えたか」で決まる。


次へ ↓ ⑤まとめ・罠の確認

⑤ まとめ・罠の確認

この問題の罠は2つある。1つめは、磁場が大きいことと起電力が大きいことを混同することだ。起電力は ΔΦ/Δt で決まり、B が変わらなければ V = 0 だ。2つめは、LC 振動の場面でも誘導起電力 V = 2.0 V がずっとあると思ってしまうことだ。つなぎかえたあとは、コンデンサにたまった電荷 Q = 200 μC がスタートで、電磁誘導の式はもう使わない。

切り分けはこうだ。磁場が増えている間はファラデーの法則で V = 2.0 V を求め、Q = CV で電荷をためる。つなぎかえたあとは、電荷 Q = 200 μC を橋渡し量にして、LC 振動の式で周期 約 0.020 s と最大電流 約 63 mA を求める。電荷が初めて 0 になるのは T/4 ≈ 0.0050 s 後だ。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 誘導起電力 V = 2.0 V、電荷 Q = 200 μC、エネルギー U = 0.20 mJ。(2) ω ≈ 316 rad/s、周期 約 0.020 s、振動数 約 50 Hz、最大電流 約 63 mA。(3) 電荷が初めて 0 になるのは T/4 ≈ 0.0050 s 後。もとになった単体モデル：電磁誘導は 第32問：電磁誘導、LC 振動は 組み合わせ問題D：LC＋単振動 で確かめられる。
