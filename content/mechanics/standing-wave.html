第14問：定常波・共鳴

問題：(1) 長さ L = 1.0 m の弦を両端で固定し、波の速さ v = 200 m/s とする。基本振動と n = 2、3 の倍音の振動数と、節・腹の位置を求めよ。(2) 長さ L = 0.85 m、音速 v = 340 m/s の気柱について、開管と閉管の基本振動数と倍音を求めよ。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js）が下の JSON データから計算して描いている。波形は節・腹の位置から計算され、赤い線が波形、赤い短い縦線が節、赤い点が腹だ。節はつねに動かない点、腹はもっとも大きく振動する点だ。

はじめに：定常波は「動かない波」

弦を弾くと、波は両端で反射して往復する。行きの波と帰りの波が重なると、ある点はつねに動かず、ある点は大きく振動する、動かない形の波になる。これが定常波だ。動かない点を節、もっとも大きく振動する点を腹という。節と腹の位置は、弦の長さと端の条件だけで決まる。波が進むのではなく、形がその場で振動しているだけだ。

ここから下へ、倍音の番号を上げながら確かめていく。

次へ ↓ ①基本振動

① 基本振動（n = 1）：f = 100 Hz、節は両端、腹は中央

両端固定の弦では、両端は動けないので節になる。基本振動では、弦の長さ L が半波長の 1 個分だ。波長は λ = 2L = 2.0 m、振動数は f = v / λ = 200 / 2.0 = 100 Hz。節は両端の 0 m と 1.0 m、腹は中央の 0.50 m だけだ。図の赤い点が腹、赤い短い縦線が節だ。


次へ ↓ ②倍音

② 倍音：n = 2 で 200 Hz、n = 3 で 300 Hz

両端固定の弦の振動数は fn = nv / 2L だ。n = 2 では f = 2 × 200 / 2.0 = 200 Hz、節は 0 m、0.50 m、1.0 m、腹は 0.25 m と 0.75 m。n = 3 では f = 300 Hz、節は 0 m、0.33 m、0.67 m、1.0 m、腹は 0.17 m、0.50 m、0.83 m。番号 n が上がると、半波長の個数が n 個になり、節は n + 1 個、腹は n 個になる。腹の位置が変わることに注意しよう。n = 1 の腹だった中央 0.50 m は、n = 2 では節になっている。


次へ ↓ ③開管

③ 開管：両端が腹、f = 200, 400, 600 Hz

開管（両端が開いた気柱）では、両端は空気が自由に出入りできるので腹になる。弦と同じく fn = nv / 2L だ。L = 0.85 m、v = 340 m/s なので、基本振動は f = 340 / (2 × 0.85) = 200 Hz、2 倍音は 400 Hz、3 倍音は 600 Hz。図の両端に赤い点（腹）がある。弦と違って、端が腹になるのが開管だ。


次へ ↓ ④閉管

④ 閉管：奇数倍音だけ、f = 100, 300, 500 Hz

閉管（片端が閉じた気柱）では、閉じた端は空気が動けないので節、開いた端は腹になる。基本振動では、管の長さ L が 1/4 波長分だ。f1 = v / 4L = 340 / (4 × 0.85) = 100 Hz。次は 3 倍音の 300 Hz、5 倍音の 500 Hz で、偶数倍音は出ない。200 Hz や 400 Hz は閉管の共鳴振動数ではない。ここが罠だ。閉管に弦や開管の式 f = nv / 2L を使うと、200 Hz を答えてしまう。端の条件を先に確かめること。


次へ ↓ ⑤まとめ

⑤ まとめ：境界条件が倍音を決める

定常波の問題は、まず端の条件を決める。固定端・閉じた端は節、自由端・開いた端は腹だ。次に、長さ L の中に半波長（弦・開管）か 1/4 波長（閉管）が何個入るかを数える。それが振動数の式になる。波の速さ v と長さ L だけでは決まらない。端の条件が違えば、同じ L でも出る振動数が変わる。共鳴とは、振動数がこの条件に合ったときに、波が大きくなることだ。


次へ ↓ 完了にする

完了にする

ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) 弦は fn = nv/2L で 100, 200, 300 Hz。節は n = 1 で両端、n = 2 で 0, 0.50, 1.0 m、n = 3 で 0, 0.33, 0.67, 1.0 m。(2) 開管は 200, 400, 600 Hz、閉管は 100, 300, 500 Hz。波の重ね合わせの考え方は 第8問：ヤングの干渉、振動の考え方は 第11問：単振動・振り子 でも使う。
