組み合わせ問題AA：斜面上のばね振り子＋摩擦

問題：傾き θ = 37°（sinθ = 0.60、cosθ = 0.80）の斜面の上に、ばね定数 k = 100 N/m のばねが斜面に沿って固定されている。ばねの下端に質量 m = 1.0 kg の小物体をつけた。斜面と小物体のあいだの動摩擦係数は μ = 0.25 で、最大静止摩擦力も同じ大きさとする。重力加速度は g = 10 m/s² とする。小物体をつり合い位置の中心から斜面に沿って 0.20 m 伸ばして静かに放す。(1) つり合い位置を求めよ。(2) 振幅がどのように減っていくかを求めよ。(3) 小物体が止まるまでの時間と、発生する熱を求めよ。(4) 粘性抵抗の場合とどうちがうか。

このページは上から下へだけ進む。図は各ステップの中にあり、図を見て、チェックして、次へ進むだけ。上の図まで戻る必要はない。

図は手書きの座標ではなく、図描画シミュレータ（assets/js/figure.js v2.7、slopeSpringFric 型）が下の JSON データから計算して描く。力の矢印は 3 px/N（重力 10 N は 30 px、ばねの力 6.0 N は 18 px）で決める。振幅のグラフは、横軸が時間、縦軸がつり合い位置の中心からの変位だ。

はじめに：切り分けマップ

組み合わせ問題は、いきなり全部を解かない。まず時間で切り、系で切る。つり合いを求める場面と、振動する場面と、止まる場面では、使う考え方がちがう。3つをつなぐのは、つり合い位置と振幅とエネルギーだ。

時間系（何を見るか）橋渡し量この場面で解くこと
はじめ（静止）小物体（斜面上）—つり合い位置は幅がある（はじめに）
放して振動する小物体＋ばねつり合い位置の中心 0.060 m力のつり合いで中心を求める（ステップ①）
振幅が減る小物体＋ばね振幅 0.20 m → 0 m半周期ごとに 0.040 m ずつ減る（ステップ②）

重力 mg = 10 N のうち、斜面に沿った成分は mg sinθ = 10 × 0.60 = 6.0 N、斜面に垂直な成分は mg cosθ = 10 × 0.80 = 8.0 N だ。垂直抗力は 8.0 N で、摩擦力の最大値は μN = 0.25 × 8.0 = 2.0 N になる。この 2.0 N が、振幅を減らしていく。

つり合い位置は、ばねの力が重力の斜面成分 6.0 N と等しくなるところで、自然長からの伸びは x0 = 6.0 / 100 = 0.060 m だ。ここから下へ、1つずつ確かめていく。

次へ ↓ ①つり合い位置：幅がある

① つり合い位置：幅がある

つり合い位置は、1 点ではない。摩擦力は 0 から最大値 2.0 N まで、向きも含めて調節できる。だからばねの力が mg sinθ − F = 6.0 − 2.0 = 4.0 N から mg sinθ + F = 6.0 + 2.0 = 8.0 N のあいだなら、どこでも静止できる。自然長からの伸びに直すと、x = 4.0 / 100 = 0.040 m から x = 8.0 / 100 = 0.080 m までの 0.040〜0.080 m の幅だ。

この幅の中心は x0 = 6.0 / 100 = 0.060 m で、ここではばねの力 6.0 N が重力の斜面成分 6.0 N とちょうどつり合うので、摩擦力は 0 だ。図の玉は、この中心に置いてある。重力 10 N を分解すると、斜面成分 6.0 N と、斜面にめり込む成分 8.0 N になる。2 本の和が重力になることを、矢印の長さで確かめよう。

つり合い位置を自然長とまちがえないこと。自然長ではばねの力は 0 だが、重力の斜面成分 6.0 N が残るので、玉は自然長では止まれない。止まれるのは、ばねが 0.040〜0.080 m 伸びたところだけだ。


次へ ↓ ②振幅は等差数列で減る

② 振幅は等差数列で減る

玉が動いているあいだ、摩擦力はつねに動きと逆向きに 2.0 N ではたらく。玉が上向きに動くとき、摩擦力は下向きで、ばねの力と重力の斜面成分のつり合いは x = (6.0 + 2.0) / 100 = 0.080 m にずれる。玉が下向きに動くときは、摩擦力は上向きで、つり合いは x = (6.0 − 2.0) / 100 = 0.040 m にずれる。動く向きが変わるたびに、振動の中心が 0.040 m ずれる。

そのため、振幅（中心 0.060 m から測る）は、半周期ごとに 2F/k = 2 × 2.0 / 100 = 0.040 m ずつ減る。0.20 → 0.16 → 0.12 → 0.08 → 0.04 → 0 m と、等差数列で減っていく。等比数列ではない。1 周期では 0.080 m ずつ減る。

周期は、摩擦がなくても同じだ。ω = √(k/m) = √(100/1.0) = 10 rad/s、T = 2π/ω ≈ 0.63 s、半周期は T/2 ≈ 0.31 s になる。摩擦力は一定なので、振動の速さは変わらない。変わるのは振幅だけだ。


次へ ↓ ③エネルギーと熱

③ エネルギーと熱

はじめのエネルギーは、つり合い位置の中心から測って (1/2)kA² = (1/2) × 100 × 0.20² = 2.00 J だ。玉が止まればエネルギーは 0 になる。なくなった 2.00 J は、全部熱になる。摩擦力がする仕事が、熱に変わるからだ。

動いた距離を確かめよう。各半周期の移動距離は、隣り合う振幅の和だ。0.20 + 0.16 = 0.36 m、0.16 + 0.12 = 0.28 m、0.12 + 0.08 = 0.20 m、0.08 + 0.04 = 0.12 m、0.04 + 0 = 0.04 m。合計は 1.00 m になる。摩擦力 2.0 N × 1.00 m = 2.0 J で、はじめのエネルギー 2.00 J とぴったり一致する。

はじめに中心を通るときの速さも、エネルギーで求められる。(1/2)mv² = 2.00 − 2.0 × 0.20 = 1.6 J から、v² = 3.2、v ≈ 1.8 m/s になる。摩擦がなければ v = √(2 × 2.00 / 1.0) = 2.0 m/s だった。摩擦で 0.40 J だけ減っている。


次へ ↓ ④止まるまで

④ 止まるまで

振幅は 5 半周期でちょうど 0 になる。0.20 → 0.16 → 0.12 → 0.08 → 0.04 → 0 m。止まるまでの時間は、5 × T/2 = 5 × 0.31 s ≈ 1.57 s だ。有限の時間で、きっぱり止まる。

止まる場所は、つり合い位置の中心そのものだ。振幅が 0 になれば、玉は中心にいて、ばねの力 6.0 N と重力の斜面成分 6.0 N がつり合う。摩擦力がなくても止まれる場所だ。だから止まったあとは、もう動かない。

もし初めの振幅が 0.040 m の倍数でなければ、どうなるか。たとえば 0.18 m から放すと、0.18 → 0.14 → 0.10 → 0.06 → 0.02 m と減り、0.02 m のところで止まる。0.02 m の点では、ばねの力と重力の斜面成分の差がちょうど 2.0 N で、最大静止摩擦力と等しい。中心でなくても、つり合いの幅の端なら止まれる。


次へ ↓ ⑤罠：クーロン摩擦と粘性抵抗

⑤ 罠：クーロン摩擦と粘性抵抗

罠は、摩擦を「速さに比例する抵抗」と思い込むことだ。空気抵抗のような粘性抵抗では、振幅は指数関数で減る。0.20 → 0.12 → 0.073 → 0.045 → … と、等比数列で減っていく。いつまでたっても 0 にはならず、玉は永遠に小さく振動し続ける。止まることはない。

クーロン摩擦（乾いた面どうしの摩擦）では、摩擦力は速さによらずつねに 2.0 N だ。だから振幅は直線で減り、有限の回数で 0 になる。図の青い線がクーロン摩擦、赤い破線が粘性抵抗だ。はじめのうちは粘性抵抗のほうが速く減るように見えるが、クーロン摩擦だけが 5 半周期で 0 に届く。

もう一つの罠は、つり合い位置を 1 点だと思うことだ。摩擦があるばね振り子では、つり合い位置は 0.040〜0.080 m の幅がある。振幅が 0 になったからといって、玉がかならず中心に止まるとは限らない。幅の端でも止まれる。振幅の減り方が直線か指数か、つり合い位置が点か幅か。この 2 つが、クーロン摩擦と粘性抵抗の見分け方だ。


次へ ↓ 完了にする

完了にする

切り分けマップで時間と系を切ったことも、ここまでの5つのチェックに入っている。5つ全部にチェックしたら、完了にできる。

答え：(1) つり合い位置は 0.040〜0.080 m の幅、中心 0.060 m（中心では摩擦力は 0）。(2) 振幅は半周期ごとに 0.040 m ずつ、等差数列で減る：0.20 → 0.16 → 0.12 → 0.08 → 0.04 → 0 m。T ≈ 0.63 s、T/2 ≈ 0.31 s。(3) 5半周期、約 1.57 s で止まる。動いた距離 1.00 m、熱 2.0 N × 1.00 m = 2.0 J。はじめのエネルギー 2.00 J がそっくり熱になる。(4) 粘性抵抗なら振幅は指数で減り、いつまでも止まらない。もとになった単体モデル：斜面は 第1問：斜面上の物体、ばねは 第5問：ばねのつり合い、単振動は 第11問：単振動・振り子、斜面とエネルギーの組み合わせは 組み合わせ問題K：斜面＋摩擦＋エネルギー で確かめられる。
