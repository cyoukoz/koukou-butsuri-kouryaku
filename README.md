# 高校物理攻略

高校物理が全く分からない人が、東大クラスの難問を楽に解けるようになるための学習サイト。

## サイトの肝

公式を覚えるだけでは問題は解けない。一番大事なのは **「問題を、公式が使えるモデルに置き換える力」**。
特に力学では、図が与えられたときに、そこに働く力を正確に図示できる力を徹底的に鍛える。

## 学習の流れ（すべての問題で共通）

1. **モデル化** — 何を対象にするか決める（例：梯子そのもの）
2. **力の図示** — 対象に働く力を、向きと作用点を間違えずに描く
3. **公式の適用** — モデルができてから、はじめて公式を使う

公式の導出も、記憶の助けとして扱う。暗記で止まらない。

## 技術方針

- 静的サイト（ビルド不要）。`index.html` を開くだけで動く
- 公開：最終的にはさくらインターネット
- ユーザーデータはサーバに保存しない
  - IndexedDB（IDB）を使う。**バージョンは 1 で固定**し、ファイル置き場として使う
  - 個人データはファイル出力（エクスポート）可能、ファイルからの読み込み（インポート）も可能
- IDB の設計は `assets/js/idb.js` の先頭コメントを参照

## 構成

```
/
  index.html
  /assets/js/
    idb.js            # IDB固定バージョンのラッパー（ファイル置き場）
    export-import.js  # エクスポート / インポート
  /content/
    mechanics/
      ladder.html     # 第1問：梯子の力の図示ドリル
```

## 使い方

1. このリポジトリを GitHub に作る（名前の案：`koukou-butsuri-kouryaku`、公開）
2. この `site-starter` の中身をリポジトリのルートに置く
3. ブラウザで `index.html` を開く（GitHub Pages やさくらインターネットでも同じファイルが動く）
